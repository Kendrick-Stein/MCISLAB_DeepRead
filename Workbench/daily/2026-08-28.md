# 🔪 今日总结

今天 10 篇精读几乎都在做同一件事：把聚合层的成败信号拆成可训练、可测量的中间量。OraRL 的 decoupled advantage 修正 inversion、TTPO 的 label-free test-time 更新、AutoSaddler 把 harness 自动化的增益归到 selection 而非 diagnosis、TrapVLA 用 residual steering 把被淹没的稀疏动作偏移捞出来——四条不同赛道，共同前提是"看总成功率既训不好也测不出来"。另一条线是环境与评测本身成为贡献：PAWBench 给 world model 补上分布级公理这块空白，UrbanGround 让所有模型在长程城市任务上塌到 0–3.8%，RLHEV 把游戏开发当作 spatial 域的 RLVR 环境。唯一的 👀 是 AgenticDataACE，taxonomy 有真洞察但零实证演示。

### RLHEV
- **Title**: Agentic Game Development as a Verifiable Trajectory Data Engine for Scaling World Models
- **Institutes**: InfRec / Cardinal AI Lab, UC Berkeley, HKUST, NUS (HPC-AI Lab)
- **Source**: [link](https://arxiv.org/abs/2608.25518)  📰 HF Daily ⬆️ 123   **📒 论文笔记**: [[2608-RLHEV]]
- **核心**: 论断很锋利：world model 的瓶颈不是视频数据和算力，而是缺一条像 compiler 之于 code agent 的 grounded reward channel。解法是把 game development 当作 spatial 领域的可验证 RL 环境——engine 提供 collision/physics/navmesh 级 dense 检查，开发者的 accept/reject 提供全局信号，两者按 0.65 human + 0.35 engine 混成 RLHEV reward 做 post-training；AWoMo agent 跑 propose-render-verify-repair-review 循环，把 accepted trace 编码成训练数据。自建 UnitySceneBench（200 例）上 best-of-eight primary score 0.681，领先最强 baseline +0.098；720 实例下 generation 0.8197 vs Engine-based RLVR 0.7934。
- **锐评**: Problem formulation 是全文最值钱的部分——"feedback channel 稀缺"这个重述配上 compiler/developer 双层 verifier 类比，precision 远超一般 position paper。但标题喊 "scaling"，交付的却是 200 例自建 benchmark + 720 训练实例的 controlled study，而且号称 "data engine" 却全文不报 trajectory 产出量（多少 games、多少 hours？没有），scaling 属性纯属期票。更尴尬的是循环性：跨引擎和生成侧评价靠 MLLM-as-a-judge——用 fuzzy judge 来论证"摆脱 fuzzy proxy"，自己拆自己的台。Embodied 数字分布也可疑：+0.79% R2R 就是噪声，+48.43% D4RL 大得离谱，中间缺 baseline 起点和方差说明。还有一个关键 ablation 缺席：engine 查结构、human 查语义，两路信号训出的能力本质不同，却没做 human-only 对照。加分项是 Appendix C 罕见地坦诚——主动承认 engine reward 可被 game、结果只是 diagnostic，这份自知之明比多数灌水强。
- **Rating**: `3` 🔥 ，"game development = spatial 领域的 RLVR 环境"这个 framing 值得整条 world model post-training 路线认真消化，尽管实验只够 diagnostic、scaling 承诺还是空头支票。

### Apodex 1.1
- **Title**: Apodex 1.1: Scaling Agentic Intelligence for Complex Work
- **Institutes**: Apodex AI
- **Source**: [link](https://arxiv.org/abs/2608.23283)  🔥 HF Trending ⬆️ 200   **📒 论文笔记**: [[2608-Apodex11]]
- **核心**: 75 人 tech report，把目标定义为 working capability（长程、可验证、以 completed work 为度量单位），沿 Environment Scaling（file/search/code 三类可验证环境族）与 Agentic Coordination Scaling（Agent Team：Task Board finalization gate、asymmetric verification、adaptive effort）两条轴扩展，AgentOS 持久 runtime 承接状态与 provenance，训练用 SFT + PIVOT-RL（hindsight 定位轨迹 pivot、保留有效 prefix、带 corrective hint 的局部续写做 credit assignment）。397B 主模型 + Agent Team 在 FrontierFinance 54.3、FrontierScience-Research 63.3 取表内最高，MathArena 口径越过 IMO 2025/2026 与 USAMO 2026 参考线（36.5/30.5/26.5 vs 35/29/25）；但 GDPVal、APEX-Agents、HLE、BioMysteryBench 与两个 coding benchmark 全面落后 Claude Opus 5，coding 差 12-21 点。35B Mini 是效率主张的载体：Agent Team 下 FrontierFinance 50.2 领先所选对比表。
- **锐评**: 先说值钱的：这是少数把"环境验证纪律"写成可操作规程的 tech report——file world 被评分量必须代码可重推导、code world 在 sandbox 里红队测试"不干活能否骗到 reward"且评分与 solver 隔离、失败轨迹反向诊断环境构建错误；PIVOT-RL 也是 trajectory-level reward 粗粒度问题的干净机制表述，方向对。再说包装术：abstract 只吆喝 35B Mini，397B 主模型藏到 Sec 4.5 才露面；"leading performance band despite smaller model"建立在对手参数量不公开的前提上（报告自认），而领先的恰好只有两个表，其余七个 benchmark 全线落后。唯一全面碾压外部模型的 FrontierSearchBench 是自建 41 任务、自定 scorer——任务分布对自家训练分布的偏置无从核查，这条领先不作数。GDPVal 与 Opus-5 的 APEX-Agents 数字全是 Apodex harness 内部复现，harness 差异双向污染可比性。最硬的伤是零组件 ablation：两条"scaling 轴"、PIVOT-RL、AgentOS 各贡献多少完全无法分离，ReAct vs Agent Team 是唯一系统级对照，因果叙事停在设计论证层面；外加线上产品启用 Evidence-Grounded Synthesis 而离线评测不含，用户体感与报告数字是两个系统。诚实的地方倒要点名表扬：内部复现逐条标注、HDS6 非 matched ablation 自己招了、performance-band 措辞自我限定——比多数 frontier report 的遮掩体面。
- **Rating**: `3` 🔥 ，benchmark 叙事有选择性且零 ablation，但环境验证纪律与 PIVOT-RL 是 agentic RL 基础设施的高信息量样本，与 vault 的 step credit assignment 和 harness 设计两条线直接对话。

### PAWBench
- **Title**: PAWBench: How Far Are We from Probabilistically Aligned World Modeling?
- **Institutes**: Shanghai Jiao Tong University, Shanghai AI Laboratory, Krea AI, Hugging Face, Tongyi Lab, The University of Hong Kong, Shanghai Innovation Institute
- **Source**: [link](https://arxiv.org/abs/2608.27345)  📰 HF Daily ⬆️ 75   **📒 论文笔记**: [[2608-PAWBench]]
- **核心**: 把 world model 评测从"单条视频像不像"升级到"重复采样的分布对不对"：同一初始观测 + 动作下，模型应恢复所有可能结局（support alignment）并按正确概率分配（probability-mass alignment）。50 个物理场景分双 track——25 个有解析参考分布的 PAW-Calibration（TVD）+ 25 个可枚举结局的 PAW-Coverage（support recovery），每模型每场景 K=50 次 rollout 由 Gemini 3.5 Flash 判终态。11 个系统无一全面达标：Calibration 最佳 Cosmos 3 Super I2V（TVD 20.5），Coverage 最佳 LTX-2.3（71.7%），且平均 TVD 31.2 远超 matched Monte Carlo 基线的 8.33，证明差距不是采样噪声。三类干预（prompt / 噪声耦合 C2C / LoRA）全都修不好 state-conditioned 的分布失准。
- **锐评**: 这是近期 world model 评测里少见的问对了问题的工作——planning 下游要的就是结局分布，此前没人系统测过。排除性论证也硬：MC 基线定量干掉"有限采样"这个最顺手的辩解，causal vs non-causal 对照（pencil tilt 反应不足、Galton board 上贴文字反而分布漂移）把失准钉到机制层面。但三处要扣：其一，judge 是 Gemini 3.5 Flash，而 §5.1 自己证明了 VLM 家族分布失准（TVD 34.8–42.3），用失准的 VLM 测别人的分布失准，81.3% 人类一致率还只在 888/1,500 的"双方都给明确标签"子集上成立——判定链条的系统偏差没有完全封死。其二，口径陷阱：Coverage/TVD 均值只算通过 readout gate 的场景，LTX-2.3 的 71.7% Coverage 是踩着 Calibration SPR 24% 的地板拿的，单指标引用会严重误导。其三，Calibration 参考分布靠对称性假设，真实世界里"ground-truth 分布已知"的场景本就稀少，benchmark 扩展性天花板不高。另有一个论文自己没算清的账：C2C 只改采样端就让 TVD 也降了（LTX-2.3 30.1→19.9），说明相当一部分"失准"其实是采样多样性坍缩而非分布学错——"探索 vs 分布"的归因切分本该更定量。
- **Rating**: `3` 🔥 ，给 world model 评测补上了分布级公理这块真空白，且干预实验把"现有手段修不好"变成了明确的 open problem，judge 循环依赖是唯一实质软肋。

### UrbanGround
- **Title**: UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City
- **Institutes**: Shanghai Jiao Tong University, National University of Singapore, Meituan, The Chinese University of Hong Kong, Shanghai University, University of Oxford
- **Source**: [link](https://arxiv.org/abs/2608.27456)  📰 HF Daily ⬆️ 70   **📒 论文笔记**: [[2608-UrbanGround]]
- **核心**: 用香港政府全域 3D 地图 + 3D 行人网络在 Unity 里搭了一个物理约束、连续闭环的真实尺度城市 sandbox，让 MLLM agent 以第一人称移动，测"局部感知能否组合成空间行动"。810 个人工验证实例沿五级梯度递进（局部理解 → 显式导航 → 隐式探索 → 多任务规划 → 动态交互），10 个前沿模型全测。结果两极分明：可见地标识别可靠（Claude-Opus-5 VR 91.3%），但长程导航全体崩溃在 0.0-3.8%，道路封闭后 SPR 最高才 46.7%，行人碰撞率全员 76-90%。结论是局部原子能力不能组合为持续 goal-directed 行为，错误累积且无纠正。
- **锐评**: 环境构建是真功夫——政府地理数据 + 连续碰撞几何，直接把采样视点跳转那一代街景导航评测（离散点瞬移、无物理接触）扫进历史；五级梯度设计也聪明，能精确定位组合在街区尺度断裂，比一个笼统的 end-to-end 成功率有诊断价值得多。每个实例都由人类在同样 100 步限制内验证可完成，堵死了"任务本身不可行"的借口，0.0-3.8% 的长程崩溃因此格外扎实。但三处硬伤：其一，交互式地图工具就在动作空间里，长程照样全崩，是不会用工具还是地图与第一人称观察对不齐？论文不拆分，等于把最有信息量的问题留在桌上；其二，PCR 76-90% 全模型高度趋同，更像离散 move 步长的接口 artifact 而非模型空间能力信号（笔记明确标注此为推测、论文无 ablation），拿它当能力结论要打折；其三，只测 prompted 开箱模型，一个带空间记忆 scaffold 的 baseline 都没有，"当前 MLLM 不行"与"问题本身多难"之间完全没有探索——纯诊断不给药方，失败分类停在现象层。另外单一高密度立体城市（香港），对网格状低密度城市的外推纯属未知。代码链接仅核实论文有此声明，repo 内容未验证。
- **Rating**: `3` 🔥，环境基建是实打实的代际升级，长程 0-3.8% 的全体崩溃是罕见的干净负结果，缺 scaffold 上限探测是唯一让它离满分有距离的地方。

### OraRL
- **Title**: Annotations as Rollouts: Efficient and Scalable Reinforcement Learning for Video MLLMs
- **Institutes**: Nankai University (VCIP); Northwestern Polytechnical University; Institute of Automation, CAS; NKIARI Shenzhen
- **Source**: [link](https://arxiv.org/abs/2608.20492)  🔥 HF Trending ⬆️ 102   **📒 论文笔记**: [[2608-OraRL]]
- **核心**: structured video 任务（temporal interval、box、mask、trajectory）的 RL 有个尴尬事实：on-policy rollout 几乎采不到与精确 annotation 一致的输出，group 里没有正样本 anchor，而 GT 明明就在手里。OraRL 把 annotation 序列化成 response 格式，作为第 9 条 oracle rollout 注入 GRPO group，关键一步是 decoupled advantage——oracle 不参与 on-policy baseline 均值计算，只拿一条 detached advantage。配合 sign-balanced pruning（只反传 4/9 条），训练开销降到 SFT 的 2.2×（GRPO+CoT 是 4.9×），全程 answer-only。同 init/数据/预算下 62.7 > GRPO 60.3，tracking/segmentation/temporal grounding 七类任务全面提升（GOT-10k AO 78.2 vs OneThinker-8B 73.0）。
- **锐评**: 全文最值钱的是 advantage inversion 的量化解剖：naive 把 GT 混进 group 会抬高 baseline，22.4% 的正 advantage rollout 被翻成负、8.3% 的 group 失去全部正样本，最终 naive injection（55.4）反而比不加 GT 的 GRPO（60.3）更差——这是"直觉修法为何 break"的教科书级反例，也直接解释了为什么 LUFFY-style off-policy guidance（54.7）同样翻车：专家轨迹的价值不在混入，而在不污染 on-policy baseline。方法只动 advantage 计算，不改 reward、不加模型，简洁得体。但摘要级 headline 全要打折：VSI-Bench 73.1 吊打 GPT-5 55.0 是三重口径注水——proprietary 分数来源与是否开 thinking 未说明、最强开源近邻 LLaVA-OneVision-2-8B 已 70.9（真实增量 2.2 点）、in-domain post-training 打 zero-shot 通用模型本就不对等，旁证是 out-of-mix 的 MMSI/MindCube 上 47.7 仍输 Grok-4 和 GPT-5；"130 ms vs 4,780 ms" 的推理加速是 post-TTFT decode 口径，video prefill 主导下端到端只有 24.3 s vs 29.0 s，约 16% 而非 37×。另外 answer-only 是双刃剑：route planning 单项 47.4 远低于 Gemini-3-Pro 61.9，砍掉 CoT 的账在 reasoning-heavy 任务上自家表格就能看到。数据 scaling 曲线的端点数字仅存在于图像中未能核查，只能当方向性证据。方法本身只适用于 annotation 可序列化为唯一 response 的任务，开放式生成不迁移。
- **Rating**: `3` 🔥 ，advantage inversion 的失败分析 + decoupled estimator 是干净的机制贡献，headline 数字的注水不影响同条件对比里的真实增益。

### AutoSaddler
- **Title**: AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces
- **Institutes**: Microsoft、KAIST、POSTECH、SUSTech
- **Source**: [link](https://arxiv.org/abs/2608.23041)  🔥 HF Trending ⬆️ 60   **📒 论文笔记**: [[2608-AutoSaddler]]
- **核心**: 把 agent 外部 harness（prompt / tool / middleware 三层）的改进形式化为 offline learning：在 train/dev/test 任务切分上迭代跑 Diagnosis-Patch → Reflection → Evolution 三个 session，从执行 trace 对比失败与成功 run 挖根因、生成限定在三层内的结构化 patch，靠 dev-set 过滤 + EvoDAG 记账保证更新不 regress。GAIA2 / SWE-Bench Pro / Terminal-Bench 2.0 上较各自 base harness +9.0 / +9.6 / +10.0 pp，TB2 上还压过人工 expert-tuned 的 Terminus KIRA 2.5 pp，且只用 147 条 trace（约 Meta-Harness 的 1/10）。
- **锐评**: 这篇最值钱的不是 +9 pp，是两个诊断性发现。其一，ablation 排序说明瓶颈根本不在"能不能生成 patch"——去掉 generalization-aware selection 直接掉 11.4 pp，是诊断深度（-4.2）和结构约束（-5.1）的两倍多，即自动 harness 优化的死穴是过拟合个别轨迹，dev-set 过滤才是命门。其二，无结构约束时 LLM 生成的 patch 91.5% 塌缩成纯文本编辑，几乎不碰代码，这一个数字就解释了 GEPA 这类 prompt 优化器为什么天花板低。成本口径（147 vs 1,400 traces）也少见地可审计。但三处不能放过：优化 agent 与被优化 agent 同为 Claude 家族，cross-model 只验了 Opus→Haiku 同门方向，作者在 Appendix R 自承对 self-referentiality 未设约束——换 GPT/Qwen 是否成立完全未知；"durable" 的证据仅限优化过程内的 dev/test 泛化，没有任何部署后分布漂移下的持久性证据，标题这个词是超前消费；expert 人工基线只在 TB2 有，GAIA2/SBP 的 +9 pp 打的是没人认真调过的默认 harness，含金量要打折。另外代码是 "will be available" 的 aka.ms 短链，当前是否真开放未验证。
- **Rating**: `3` 🔥 ，selection > diagnosis 的 ablation 排序和 91.5% Steering 塌缩是能改写 harness 自动化认知的机制发现，虽然 "durable" 和同家族自指两处 claim 需打折。

### TTPO
- **Title**: TTPO: Test-Time Policy Optimization
- **Institutes**: Zhejiang University, Alibaba Group
- **Source**: [link](https://arxiv.org/abs/2608.27448)  📰 HF Daily ⬆️ 67   **📒 论文笔记**: [[2608-TTPO]]
- **核心**: Test-time training 没有 ground truth，majority-vote 伪标签一错就腐蚀整个监督信号。TTPO 抓住一个不对称统计：即便伪标签本身是错的，与它不一致的 rollout 仍有 ~79% 自己就是错的——于是把两侧拆开处理：一致侧用自条件化 teacher（伪标签当 privileged info 拼进上下文）做 forward-KL 蒸馏，不一致侧用 GRPO 施加负 reward，各配 token 级筛选。无标签 TTPO 在五个竞赛 benchmark 上追平有 ground-truth 的 OPSD（1.7B: 40.1 vs 39.7），TTT 设置下把 Qwen3-1.7B 三 benchmark 平均从 38.0 拉到 45.2，全面超过 TTRL（40.2）。
- **锐评**: 这是少见的"一个观察撑起整个方法"的干净工作，且 ablation 真能自证：反转分配（惩罚正样本、蒸馏负样本）直接崩到 37.2、低于 base——增益来自不对称方向本身，不是多算了几遍。全文最有信息量的是 Figure 5：用 ground truth 做 routing 反而更差，因为难题上 GT 正样本近零、分支饥饿，这把"伪标签只是 GT 的廉价替代"的默认叙事整个翻转了。但三处必须扣分：其一，abstract 把 +25.2~+36.4 与 TTT 结果并排，前者其实是 OpenThoughts 训练 + non-thinking 评测的另一口径（non-thinking base 只有 9.5~20.3，起点低数字自然大），摆明是挑最大的数当门面；其二，TTT 报 "peak checkpoint across 100 steps"——挑 peak 本身就需要测试标签，部署时根本做不到，这是 TTRL 系的通病但不能装看不见；其三，宣称的 ~85% 伪标签错误率与 base 37.8% 的 pass@1 有明显张力（maj@64 不该比 pass@1 差这么多），测量口径论文没写清，笔记已列为待复核项。方法的隐含假设是错误答案高度分散、不聚成单一吸引子——数学竞赛恰好满足，但迁移到 GUI grounding 这类误点集中在少数干扰元素上的域，79% 这条统计很可能不成立，负分支会变成集中误罚。
- **Rating**: `3` 🔥 ，79% 不对称观察 + 反转崩盘 ablation + GT-routing 反转是真 insight，label-free TTT 追平有标签蒸馏的结果扎实；口径包装和 peak-checkpoint 协议是污点但不动摇核心结论。

### GameWAM
- **Title**: GameWAM: A World Action Model for Video Games
- **Institutes**: Fudan University, LIGHTSPEED, Independent Researcher, Tsinghua SIGS
- **Source**: [link](https://arxiv.org/abs/2608.26200)  📰 HF Daily ⬆️ 38   **📒 论文笔记**: [[2608-GameWAM]]
- **核心**: 并行 Video/Action DiT 用 flow matching 联合生成未来观测与可执行键鼠轨迹，per-timestep mode router 处理 gameplay/GUI 两套动作分布，"预测 P 步执行 E 步" 的 block-cycle 加层级 cross-cycle memory 撑长时程。MCU 800+ Minecraft 任务上 ASR All 46.6 超最强 baseline Game-TARS 的 42.5，且成功 episode 步数更少。更有意思的是副产品：发现并因果定位了 LASI——固定 conditioning 下 sampled action source 的低频 DCT 成分系统性控制生成的粗粒度相机运动（swap 低频 modes 后 94.8% trials 跟随 donor，置零消除 99.25% 相关方差），闭环复用同一 source 会累积成持续偏转和原地打转。
- **锐评**: 这篇的真金不在刷榜而在两处。其一，去掉 future-video 监督平均掉 15pt（50.7→35.7）——"视频生成对 policy 有实质贡献"的正面定量证据在 world model 文献里罕见，比一打 offline FVD 曲线值钱；mode routing 相对统一动作分布 +12.4pt，坐实了异构控制不能单一分布硬吞。其二，LASI 的三步频域干预（关联→swap→zeroing）是可直接搬去检查任何 diffusion/flow action head 的诊断工具，噪声源不是无害的 diversity 来源而是隐藏控制通道，这个发现超出本文本身。但账也要算清：主结果的严格可比口径只有 ASR All 46.6 vs 42.5（+4.1pt），"Mini 全表最高"对没报 Mini 的 Game-TARS 不成立；方差 ±25~±39、Mini 每任务才 10 runs，GUI 类 All（60.0）反高于 Mini（43.0）暴露子集分布不齐，单一平均数经不起细看。"first WAM" 全靠 "native gameplay + GUI control" 的域限定续命——DreamZero 早做了 joint video+action closed-loop，论文自己也引了。参数量、DiT 初始化、算力全未披露，reproducibility statement 写得漂亮但正文一个数字不给。去掉层级记忆平均才掉 4pt 且 Embodied 反升 5pt，这个复杂组件多半没值回票价。LASI 缓解是每步重采样的规避而非修复，论文倒是诚实承认了。另外此处 "GUI" 是游戏内 inventory/菜单，往 OS 级 computer-use 迁移纯属想象空间。
- **Rating**: `3` 🔥 ，主结果 +4.1pt 只算扎实不算惊艳，但 video 监督 15pt ablation 和 LASI 频域因果诊断是能迁移到 diffusion-head VLA / GUI agent 的真 insight，值得读方法之外的第 5.5 节。

### TrapVLA
- **Title**: TrapVLA: Trapping Vision-Language-Action Models in Configured Failure Modes
- **Institutes**: Sun Yat-sen University, Pengcheng Laboratory, The University of Hong Kong, Jiangxing Intelligence
- **Source**: [link](https://arxiv.org/abs/2608.26578)  📄 arXiv   **📒 论文笔记**: [[2608-TrapVLA]]
- **核心**: 把 VLA 后门从"让任务失败"升级成"指定怎么失败"——训练期投毒后，一句读起来完全正常的指令前缀就让策略在抓取/放置阶段按预设的空间偏移或时序提前失手，不带前缀时 clean SR 几乎不掉。四种 failure mode 由偏移向量参数化共存于同一模型，TrapEngine 靠回放专家演示 + 几何元数据合成目标轨迹，Target Residual Steering 用 clean/backdoor 配对的动作残差解决"143 步里只有 23 步要改"的稀疏监督问题。Trap-LIBERO 上 OpenVLA-OFT 的 AVE 达 94.1–98.9，真机 π0.5 + ROKAE 上 97.0 / 99.2。ONION 默认阈值只揪出 148 条触发指令里的 4 条，零样本 LLM judge 检出率 0.0%。
- **锐评**: problem formulation 是真的好，好在它精准地掀翻了 embodied 安全的两根支柱：聚合层看成功率回归（98.4→96.8 的掉幅本身就在种子噪声里，等于无分辨力）和运行时看异常轨迹（诱导失败在运动学上完全合法）。输入侧也被堵死，ONION 2.7%、LLM judge 0.0%、NLL 最大只涨 0.24，同义词替换后 C-ASR 只掉 0.8–1.6 pp——触发词黑名单这条路可以直接放弃。这些数字是真硬。但方法贡献的稳健性就另说了：换到 π0.5，Vanilla-T 95.3 对 TrapVLA 95.8，Spatial 上 94.2 对 96.1，TRS 的增益基本蒸发。作者拿 action expert 的连续 action flow 圆了一句，但这句归因等于承认——在 flow-matching 策略上攻击者用最朴素的后门训练就够了，TRS 是给 discrete-token 架构打的补丁，不是一个跨架构的方法贡献。更要命的是全文最响的那句叙事——诱导失败"behaviorally plausible、难以察觉"——零实验支撑：没有任何 human study 去测操作员会不会把这些失败归因为模型能力不足，C-ASR 只验证末端落在 3cm 容差内，跟"看起来自然"是两件事，而 3cm 偏移在真机上到底是掉落还是仅位姿不佳，论文也没量化下游物理后果。威胁模型也得打折：TrapEngine 要能在同源环境重放、拿到目标物与放置点 ground truth、还要人工过滤不可行轨迹，这是外包采数/外包微调的供应链场景，不是往公开数据集塞几条脏样本；不过 2 张 H100 就能训完，对有数据访问权的一方成本近乎为零。实验规范性上，单 seed 42、无误差棒，Table 12 里投毒比例 0.5 处 C-ASR 塌到 10.2 又在 0.7 回升到 86.8，作者拿这条非单调性论证"注入难度不只是数据量问题"——同样能由单种子训练不稳定解释，论证强度接近于零。最后一处空缺是防御：全文不提任何缓解方案，也无 ethics statement，检测实验只做了两种最弱的输入侧基线，fine-pruning、激活聚类这类经典权重扫描一个没试，配对指令差分测试（同一观测下加/不加前缀比动作分布）更是 TRS 自己训练时就在用的信号，作者绕开了最可能有效的探测手段来宣告"难以检测"——这让"隐蔽性"这个 claim 的证据基础比 ASR 数字看起来要薄得多。
- **Rating**: `3` 🔥 ，问题提得对、检测规避与真机证据够硬，值得防御方认真对待；但方法在 π0.5 上几乎无增益、"难以察觉"无人评测、防御侧只挑软基线打，是一篇 threat framing 强于技术贡献的攻击论文。

### AgenticDataACE
- **Title**: What Makes Good Agentic Data? An ACE Lens on Data Generation for LLM Agents
- **Institutes**: Huawei Technologies、Shanghai Jiao Tong University、Northwestern University、Harbin Institute of Technology (Shenzhen)、Shenzhen Loop Area Institute
- **Source**: [link](https://arxiv.org/abs/2608.27260)  📰 HF Daily ⬆️ 56   **📒 论文笔记**: [[2608-AgenticDataACE]]
- **核心**: 华为诺亚+SJTU 的框架式 survey，回答"什么是好的 agentic 训练数据"。把任意 agentic data 拆成公共对象 d=(E,q,τ,v)（环境规格、任务信号、交互轨迹、可选 verifier），生成范式按"先锚定哪个因子"组织成 forward（E→q→τ）、reverse（task/trajectory/structure-first）与 self-evolving cross-cutting，而非按 tool-use/GUI/SWE 应用域各说各话。质量目标形式化为 Accuracy 硬约束下最大化 learner-relative Complexity 加 Diversity 的约束优化（ACE lens），并整理出 4+7+6 的机制库与一份失效模式清单（verifier gaming、factorized generation drift、LLM judge 继承 generator 假设）。
- **锐评**: 在 survey 灌水成灾的当下，这篇的两个组织选择是真本事：learner-relative complexity（Eq. 10，C_z=1−solve rate）把"难度"从数据静态属性改成数据×学习者的关系属性，直接枪毙了拿 horizon/步数当 universal difficulty score 的行业惯习；accuracy 合取门"难度不能补偿无效性"给 pipeline 设计排出了可执行的优先级。跨域同构性也确实被挖出来了——OS-Genesis 的 GUI 轨迹反推和 tool-graph realization 落进同一个格子，这是 domain-centered survey 结构性给不出的。但硬伤同样清楚：其一，ACE 三字直接承继自作者自家 ToolACE（共同作者 Xingshan Zeng、Weiwen Liu，Evidence Ledger C10 已核），本质是把自家 function-calling pipeline 经验事后加冕为领域普适框架，forward generation 的 LLM 合成环境一支基本在引自家谱系，reward shaping、off-policy 数据复用这类不以"生成"为中心的数据问题被裁剪出坐标系。其二，Eq. 8 是纯概念形式化——λ_C、λ_D、g_z 全无估计方法，作者没用这个目标做任何一次重排或 meta-analysis 来演示 lens 有判别力，"moving band 预测数据效用"这个框架的核心可检验命题一个实验都没跑（两个能力不同的模型做 per-instance solve-rate 分桶训练即可初验，成本不高，但论文没做）。其三，无配套 repo/paper list（C12），survey 的工程可用性打了对折。词汇表是好词汇表，但一个从未被用来做过任何预测的框架，目前只是漂亮的记账系统。
- **Rating**: `2` 👀 ，taxonomy 有真洞察、learner-relative complexity 值得进 mental model，但零实证演示加自家 lens 加冕，是"该读一遍存档"而非"改变做法"的工作。
