# 今日总结

这轮 3 天窗口抓到 54 篇候选；arXiv API 当场 429，所以候选主要来自 HF、OpenAlex 和 CVF。真正值得新增沉淀的不是又一批 VLA/CVF backfill，而是两条 runtime 设计信号：**verifier 可以从 hidden test oracle 转向 evidence-grounded sub-agent**，以及 **long-horizon memory 应被定义成 bounded typed contract，而不是无限 transcript**。

本轮精读 [[Papers/2606-Dockerless]] 和 [[Papers/2607-AgenticSTS]]。前者给 AFE 的 verifier/reward-source 设计提供了代码域强例子；后者提醒我们，agent-facing runtime 的核心问题不是“给更多上下文”，而是规定每一步可见证据的类型、边界和可消融性。

## 论文点评

### Dockerless
- **Title**: Dockerless: Environment-Free Program Verifier for Coding Agents
- **Source**: [arXiv](https://arxiv.org/abs/2606.28436)  **论文笔记**: [[2606-Dockerless]]
- **核心**: 用 question generation + read-only repository sub-agents + final judge 取代 per-repository Docker test execution。它不是简单 LLM scorer，而是让 verifier 主动读代码、找 location / behavior / test evidence / edge cases，再把证据聚合成 correctness score。Dockerless-RL-9B 在 SWE-bench Verified / Multilingual / Pro 上到 62.0 / 50.0 / 35.2，接近 test-execution RL。
- **锐评**: 这篇最有用的不是 SWE 分数，而是 verifier 设计范式：隐藏 oracle 之外还有一条 evidence-grounded reward route。硬伤也很清楚：它强依赖 reference patch 生成问题，训练标签仍来自 test execution，所以不是“无测试 correctness”。但作为 AFE 的 verifier analogue 很扎实：让 verifier 子代理只读状态并产出可审计证据，比直接暴露 hidden success label 更像研究问题。
- **Rating**: `3` Foundation。

### AgenticSTS
- **Title**: AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents
- **Source**: [arXiv](https://arxiv.org/abs/2607.02255)  **论文笔记**: [[2607-AgenticSTS]]
- **核心**: 在 Slay the Spire 2 上定义 bounded memory contract：每一步 prompt 从 L1 protocol、L2 schema、L3 rules、L4 episodes、L5 triggered skills 重新组合，不追加 raw transcript。固定 A0 下 L5 skill cells 6/10，baseline 3/10，但作者明确承认 p≈0.37，只能读作 directional。论文释放 298 条轨迹、frozen snapshots、prompt records 和分析脚本。
- **锐评**: 难得的诚实 long-horizon agent paper。它没有把小样本吹成显著胜利，而是把 memory interface 做成可复现实验表面。对 GUI/CUA 的启发很直接：runtime 不应该只是塞满历史，而要定义 typed evidence packet。弱点是任务是单一 text-readable game，视觉 grounding 和真实 GUI side effects 都没覆盖；但 formulation 值得借。
- **Rating**: `3` Foundation。
