# 🔪 今日总结

今天最值钱的东西全是负性结果。ContinualSkillBench 加了一个此前没人加的 ICL 对照，把「显式 skill library 有用」这个自演化 agent 领域的默认假设打成空账——允许写 skill 的 0.602 对只留上下文的 0.605，净贡献在总量上不可分辨；MerchantBench 则在 365 天电商模拟里发现 agent 在没有 deadline 的环境中会自己停下来（滚动窗口活跃率最低 10.6%），16 个 frontier 配置有 6 个跑输一条「下架滞销品」的规则基线。

方法侧则集体乏力：PCSD 的 +6.2pp 折算成 128 条里多成功 8 条，CofactVLA 拿每任务 1 个 episode 的 LIBERO-Plus 去撑 1.2pp 的 SOTA 排序，MobileWAM 的真机数字全是 5% 的整数倍且从未披露 trial 数——三篇的统计预算都撑不起各自的 headline claim，真正会活下来的是它们顺手报出的消融负结果。WorldProxy 是一篇零实验的 taxonomy position paper，其头号主张（按 agent 增益而非生成保真度验收 world model）四个月前已出现在共享作者的 prior art 里且未被致谢。

## 论文点评

### ContinualSkillBench
- **Title**: ContinualSkillBench: Can LLM Agents Truly Evolve Their Capabilities?
- **Institutes**: Institute for Artificial Intelligence, Peking University; Beijing Institute for General Artificial Intelligence
- **Source**: [link](https://arxiv.org/abs/2608.03874)  📰 HF Daily ⬆️ 11   **📒 论文笔记**: [[2608-ContinualSkillBench]]
- **核心**: 把 agent 的 skill 自演化搬进「5 个 domain × 100 个按技能依赖排序的连续子任务」里评测，对照每题从零开始的 Independent baseline。Sequential 在 15 个 model–domain 组合里 14 个提升 normalized reward，宏平均 +0.078（相对 +16.9%）。但真正的看点是那个消融：允许显式增改 skill 库的 Sequential（0.602）和只保留上下文与 judge 反馈、禁止写 skill 的 pure ICL（0.605）几乎完全打平。也就是说 Independent→Sequential 的 +0.136 里，能归给「显式技能抽象」的部分在总量上不可分辨。附带一个观察：GPT-4o 生成 384 条 skill 平均质量 5.68，GPT-5.3-Codex 只生成 205 条但平均 7.94。
- **锐评**: 这篇的价值全在那个 ICL 对照上，而且它是这一整条线里少见的、设计上真把两个混杂因素拆开的工作——self-evolving agents 文献报了三年的 Sequential-vs-Independent 差，天然把「上下文滞留」和「技能抽象」焊在一起，这篇一刀切开，得到的是空账。这是能被引用的负性结果，也应该成为今后 skill-evolution 工作的强制对照项，正如 RAG 必须对 long-context。结构验证也做得比同类 benchmark 体面：用不看序列位置的 Qwen3-32B 独立标注 core skill、10,000 次置换检验、报了 Holm 校正后**不显著的那 5 个**组合，没有把「我们的任务有依赖」当既成事实。
  但论文自己的解读和自己的数字之间有明显裂缝。第一，主表每格只跑一次，全文零方差、零误差棒、零重复运行——Appendix C 那个 seed 42 是标注器的，不是主实验的。在这个前提下，作者把 Opus 4.7 × Math 的 **−0.008** 写成一个 finding（「该模型无法从经验受益」），而 15 格 raw Δ 里有 3 格落在 ±0.01 内，这就是在噪声上讲故事。讽刺的是核心论断反而不受影响：0.605 vs 0.602 差异极小，恰恰就是「不可分辨」本身。第二，normalized reward 只在两侧都产出有效输出的**交集**上算，等于把任一侧失败的题从分母里删掉，而它偏偏是唯一支撑「14/15」的指标——GPT-4o × Law 那格 raw −0.006 / norm +0.070 直接反号，且笔记复核显示该格只有 EM +0.050、Rubric −0.051 两列在动，**符号翻转纯由交集筛选决定分母**，没有任何子项改变方向。全文没报交集子集大小，读者无从判断被剔的题是不是恰好 Sequential 崩得更多。这是我最想看而没有的一张表。第三，也是最难看的一处：论文写「显式 skill 把 Healthcare 的 Programmatic 从 0.250 提到 0.500」，笔记逐格核对后是 Independent 0.500 / ICL 0.250 / Sequential 0.500——参照系被悄悄换成了 ICL，真相是**ICL 把这格砍了一半，显式 skill 只是没掉下去**，一次 regression 的避免被写成增益，且未披露参照系切换。Law 同形（Seq = Ind = 0.800 < ICL 0.900），Finance 是三格里唯一 Seq 超过 Independent 的，还只跟 ICL 打平。配合 Rubric 那三格里两格的领先只有 +0.011 和 +0.002（第三位小数），论文用来论证「ICL 与显式 skill 结构不同、各有所长」的两条腿基本是站不住的——真实结论就是纯粹的打平，作者显然不愿意这么写。
  剩下的：「弱模型倾向碎片化 skill」这条因果链是在**两个模型点**上拟合的，Opus 4.7 被完全排除在 skill 库统计外，而且这两点还同时在代际（2024 vs 2026）和能力上有差；质量分由 GPT-4.1-mini 打，作者自己在 Figure 3 说明里都承认这类统计 "do not directly establish skill utility"，那就别拿它做因果叙事。子项 Δ 的分母全程未知——Programmatic +0.583、EM −0.500 这种数字可能就是一两道题的翻转，论文却把它们写进 evaluator-类型分析。任务全部来自公开 benchmark（AIME、GAIA、LegalBench、OlympiadBench），零去污染讨论，在 Office/Math 那些 Independent 已逼近 1.000 的格子上天花板效应会直接压掉可观测 Δ。还有 Table 1(c) 与 Appendix F Table 7 同一条实验（Opus × Healthcare Seq）对不上：EM 0.929 vs 0.926、norm 0.662 vs 0.635——norm 差 0.027，跟论文报道的多数 Δ 同量级，无任何说明；好在 Table 2 与 Table 1(b) 逐格一致，是孤例不是系统性错误。最后两条 evidence boundary 说清楚：§4.2 那组 evaluator 子项 Δ（Numeric +0.416、Rubric −0.192 等）和 Appendix C 的结构验证细节数字（Phase 1 的 3 万条候选、各 domain 复用率、Mathematics 三窗口不显著）**未纳入任何一轮独立核查**，属 not-checkable，引用前自己去查；code 链接那个 `gtynnn060110-hash` 账号形态上像临时匿名号，只核实了链接印在脚注里，repo 内容与可访问性未验证。
  一句话：一个设计正确、执行单薄、解读过度的 benchmark。它证明的比它想证明的少，但它证伪的东西恰恰是这个领域最需要被证伪的——skill library 有用这个默认假设，举证责任该还给提出方了。
- **Rating**: `3` 🔥 ，ICL 对照是 self-evolving agents 线上目前最干净的证伪设计，单次运行+过度解读拉低了执行分，但「skill library 净贡献不可分辨」这个负性结果的引用价值压过所有瑕疵。

### MerchantBench
- **Title**: MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations
- **Institutes**: Alibaba Group, State Key Lab of CAD&CG · Zhejiang University, School of Software Technology · Zhejiang University, School of Software and Microelectronics · Peking University, College of Computer Science and AI · Fudan University
- **Source**: [link](https://arxiv.org/abs/2607.28956)  📰 HF Daily ⬆️ 87   **📒 论文笔记**: [[2607-MerchantBench]]
- **核心**: 把 long-horizon agent 评测搬进一个 365 天、按小时推进的卖家侧电商模拟，商品目录取自 1688 的 98,843 条真实商品与逐日需求轨迹，agent 通过 26 个工具在约 730 个决策窗口里经营一整年。设计上的真正卖点是 mixed-latency：上游供应商异常即时可见，而退款/差评等下游结局在订单创建时就预先抽定、延后数日才揭示，再经店铺评分的陡峭阶梯把单品售后失败扩散到整个商品组合。8 模型 × 2 框架 × 3 次重复共 48 run，最强配置（Qwen3.7-Max+Hermes，59.46k RMB）只有 3 名无经验人类均值（217.61k）的 27.3%，且 16 个配置里有 6 个跑输一条"下架滞销品 + 按日报补位"的规则基线（24.48k）。附带产出 SWR——滚动 30 天窗口活跃率的最小值。
- **锐评**: 环境设计有品味，claim 层却漏得厉害。先说好的：SWR 取**最小值**而非均值是全文最聪明的一笔，"前三个月猛干后九个月躺平"被终局分数掩盖的失败模式，一个数字就量化了（人类 100%、rule-based 100%、LLM 低至 10.6%）；rule-based 打败 6/16 个 frontier 配置这行数据比 headline 的 27.3% 硬得多，却被塞在表格末尾。现在说坏的。**headline 的人类对照根本不干净**：agent 走 26 个工具的文本 API 且历史一到 160k token 就截到 30k，人类走一个专门造的 dashboard、在 5 个自然日里操作、天生带完整外部记忆。标题写 Long-Term Coherence，这个对照却分不开 coherence 和界面带宽——让人类走同一套工具接口再跑一次，一个实验就能拆，作者没做。**排名本身不成立**：n=3，冠军配置 CV 55.1%，59.46 的散布轻松盖住 GPT-5.6 Sol 的 52.93，论文自己承认"按模型跨框架平均则 GPT-5.6 Sol 第一"——同一张表两个第一名；而"论文报告了显著性检验/置信区间"这条在笔记 Evidence Ledger 里标为 **unsupported**（C30，verifier 全文+附录检索确认零 p 值、零置信区间），却仍以 "the best LLM configuration" 写进摘要。**simulator 只验证了输入侧**：真实商品、真实需求轨迹、按履约信号校准的事件概率都没问题，但从动作到结果的映射是一套手工常数——隐藏弹性 ε_i 全文没交代来源，评分阶梯（跌破 3.80 打八折、跌破 3.30 只剩 35%）的陡峭程度直接决定了"售后失败会不会滚雪球"，也就直接决定了人机差距的形状。产出侧对照（模拟营收/订单 vs 真实商家）在笔记里同样标为 **unsupported**（C17），且**连 limitations 一节都没有**。Strategic Coherence 这半边只有事后挑出来的具名轨迹（第 104 天放弃、47→3 个挂牌、误记第 285 天为终点），生动，但没有发生率、无法证伪——把一个真被操作化的指标（SWR）和一套事后分类学捆着发，分类学会白嫖指标的可信度。还有两处方法瑕疵值得单拎：两框架上下文管理策略不同（ReAct 硬截断 vs Hermes 自摘要），且 summarizer 就是被评模型自己——弱模型给自己写越来越烂的状态摘要，在数据上和"agent 逐渐失去意图"完全同形，这给全文最扎实的 Operational Coherence 结果留了个未排除的替代解释；Hermes 相对 ReAct 的 +53.3% 一口气动了代码执行/planning/memory/skill/上下文五件事，零组件隔离，附录 I 还显示三个模型压根不碰代码工具——所谓"框架增益"在不同模型上根本不是同一件事，这是 harness bundle 归因问题在 benchmark 侧的翻版。对比 StuLife 就看得更清楚：人家做了 perfect-context oracle（同类任务 98.18%），把瓶颈干净钉在记忆与主动性上；MerchantBench 没有任何等价条件，所以"模型根本不懂电商经营"这个平庸解释始终没被排除。
- **Rating**: `2` 👀 ，环境和 SWR 值得偷，但人类对照混入界面变量、n=3 零检验、simulator 产出侧未验证，三处叠加让 headline claim 撑不住——真正的收获是"agent 在没 deadline 的环境里会自己停下来"这个负面结果。

### SkillJack
- **Title**: SkillJack: Persistent Skill Backdoors in Self-Evolving Agents
- **Institutes**: Tencent Zhuque Lab
- **Source**: [link](https://arxiv.org/abs/2608.03509)  📰 HF Daily ⬆️ 19   **📒 论文笔记**: [[2608-SkillJack]]
- **核心**: 已有的 agent 投毒（AgentPoison / MINJA / MemoryGraft）都作用在"检索"这一步——恶意记录被召回进上下文才生效，清空记忆就等于清除攻击。本文把观测点前移到"转换"：往经验语料里塞一条用 backup / error recovery / charity 之类功能外壳包装的轨迹，self-evolving agent 自己的 experience-to-skill 流水线就会把它蒸馏成独立存储的 skill。在 SkillX 与 Anything2Skill 上、150 条 AppWorld 格式合成轨迹里，同一个 LLM judge 对原始轨迹判恶 98.5%、对抽取出的 skill 只剩 11.4%；派生 skill 在 56.2% / 89.2% 的攻击任务上被路由选中并触发违规判定，删掉源轨迹后仍有 80.0% 存活。作者自己声明所有 ASR 都是路由层代理量（正则 + LLM judge），不是真实执行。
- **锐评**: 问题切分是对的——"清空记忆 = 清除攻击"这条被所有记忆投毒工作默认的前提，第一次被显式拿出来测，而且落到工程上的推论（provenance 必须随派生制品传播、撤销必须覆盖后代）不依赖本文任何一个数字，只依赖"skill library 与经验语料分离存储"这个架构事实。可惜主结果撑不起主张。**98.5% → 11.4% 根本不是受控比较**：65 条轨迹被拆成 264 条 skill，平均 1→4 的分解粒度本身就会稀释每条制品里的恶意信号，judge 读完整轨迹和读碎片压根不是同一个问题。要排除粒度混淆只需把 264 条拼回轨迹级再判一次，几百次调用的事，没做，摘要却照样用 "the pipeline launders the attack" 的因果口吻。更糟的是 DeepSeek-v4-flash 一身四职——抽取器、路由器、judge、agent 全是它，所谓"逃逸"里有多少只是模型认为自己写的 docstring 是良性的？换一个 judge 家族跑一组就能排除，成本远低于已花掉的 3,047 次调用。路由那两个数字更是纸糊的：A2S 的 30 条 skill bank **100% 来自投毒输出**，SkillX 库里 305/356 是投毒 skill——"89.2% 攻击任务命中恶意 skill"和"95.0% 干净任务也命中"其实是同一件事的两种说法，后者恰好把前者的成因写在脸上；真实部署里投毒 skill 是极小比例，这是极端 base rate 下的上界，不是攻击效力。而且 305 条投毒 skill 怎么从 505 条里选的、框架化与直白各占多少，全文（含附录）没交代。数据集是作者自写的，正则签名（`steal`、`exfiltrat`、`unauthorized.*transfer`）几乎就是直白措辞的同义词表，那一路结果方向注定，真正独立的只有 LLM judge 一路。persistence isolation 那 80.0% 与其说是发现不如说是架构推论——两个存储，删一个当然不删另一个，§3.1 直接写成了定义；有信息量的是残余 20% 去哪了（同库同任务，源没了为什么少 8 个百分点），论文一句没提，何况 n=25 时那就是 2 个任务。D3 < D2 的反结果建在 15 个任务的 2 次触发上，却被命名为 defense coordination hypothesis 写进 Discussion 当"防御不可单调叠加"的依据；作者自己说需要预注册实验，那就更不该拿它下结论。全文单模型、单次运行，无种子、无方差、无置信区间，C7/C8/C9/C12/C17 的分母是 15/20/25/32/6——单个任务值 4 到 25 个百分点，任何排序差异都别当真。**最亮的反而是被作者当次要证据的两条**：A2S DOC 对直白恶意轨迹抽取率 0%、对框架化 41.5%，这是抽取器行为的二元差异，混淆因素比 SkillX 那组少得多，比主结果更有说服力；以及元数据消融——只看代码时 judge 判恶 36.7%，补上良性 skill 名和 docstring 反而降到 10.0%，给它看得越多它判得越松。后者的价值超出这篇论文本身：任何拿 LLM judge 当 skill 准入闸门的系统，都在用一个由攻击者间接控制的字段（名字和 docstring 由抽取器根据投毒轨迹生成）做安全决策。诚实度也确实高于这个子领域平均——ASR 自标为代理量、干净任务假阳率全程报、A2S 签名从 16 扩到 54 自认是事后调参、D3 劣于 D2 的反结果没埋。但和 [[2512-MemoryGraft]] 是同构毛病：证据停在路由层，主张写在 attack-success 层，中间只有一个 n=6 的代码生成核验搭桥。这条攻击文献线的通病就是在离"证明危害"还差一步的地方停下，然后用最终目标的词汇给代理指标命名。
- **Rating**: `2` 👀 ，问题边界选得好、provenance 结论可立即落地，但核心落差存在未排除的粒度混淆、judge 与被测系统同源、路由率建在近乎全投毒的 skill 库上——是"存在这个现象"的存在性证据，不是效力估计。

### PCSD
- **Title**: PCSD: Persistent Consistency for Self-Distillation in Agentic Reinforcement Learning
- **Institutes**: 未标注（arXiv HTML 无 affiliation）
- **Source**: [link](https://arxiv.org/abs/2608.01837)  📰 HF Daily ⬆️ 37   **📒 论文笔记**: [[2608-PCSD]]
- **核心**: Agentic RL 只有轨迹级 reward，on-policy self-distillation 用一个"多看了检索 skill 的冻结自我副本"当 teacher，逐 token 给出 log-prob gap 作为 dense 监督。PCSD 的全部主张是换掉这个 gap 的统计量：不用单点 δ，而用它在前向局部窗口内的"持续性"——指数衰减聚合（α=0.8）+ 方差自适应窗长（1–8）+ 负斜率单边衰减 + sigmoid 门控，加权 NLL 与 GRPO 联合优化（λ=0.01）。Qwen2.5-3B / Qwen3-1.7B 上 ALFWorld Overall 90.6 / 59.4，对 GRPO +15.6 / +13.3，对最强蒸馏基线 SDAR +6.2 / +5.5；WebShop Score 85.0 / 78.9。所有数字单次运行、无方差，评测集 128 条 episode。
- **锐评**: 先说唯一真正干净的地方：SDAR 与 PCSD 在超参表里完全同参（λ=0.01、β_gate=5.0），共享 student、teacher skill、训练预算与评测协议，差别被压缩到 sigmoid 里喂单点 δ 还是 δ̄——84.4→90.6 确实只归因于统计量替换，这比同类论文规矩。可惜地基是纸糊的：全文零多 seed、零标准差、零显著性检验，Overall 唯一相容于分母 128，于是 +6.2pp = 128 条里多成功 8 条，1.7B 的 +5.5pp = 7 条；按二项独立近似只有约 1.5σ / 0.9σ，且这还没计入 agentic RL 训练侧臭名昭著的 run-to-run 方差。消融更狼狈：Fixed N=4 与完整版差 3 条 episode，λ 从 0.005 挪到 0.01 差 4 条——"三组件互补"这句话的证据力度就是三条 episode。而 λ 从 0.005 扫到 0.05 造成 7.0pp 摆动，比论文声称的任何单组件贡献（2.3–7.8pp）都不小，单个超参的敏感度直接吞掉了组件归因。per-category 那六列更该被整体作废：对 Look 列反推，OPSD 41.7%（5/12 倍数）、GRPO+OPSD 82.4%（14/17）、Vanilla 11.1%（1/9）、PCSD 63.6%（7/11）穷举后不存在 ≤200 的公共分母，Clean 列同样——各方法根本不在同一批实例上，正文当亮点吹的 "Pick2 47.4→100.0" 是七到三十几个样本上的不同实例对比，不能用。方法侧则是典型的启发式堆叠：8 个手工超参、四机制串联，`N_max=8` 从哪来全文无据；附录那段 bias–variance 分解对任何滑动平均都成立，说明的是"长窗降方差"，压根没有支持"持续性=可信度"这个核心假设——真正该做的实验便宜到离谱：直接测 δ 序列的自相关长度，看真实优势与采样噪声是否可分。更根本的是自蒸馏的死穴：噪声不持续，系统性错误恰恰持续，当检索 skill 错误但内部自洽时，持续性判据会比单点加权更用力地把它写进权重；论文自己的 teacher-quality 对齐实验 ρ=0.174/0.052（几乎不相关）已经说明权重和 teacher 真实质量耦合极弱，却没写进 limitation。失效条件也完全空白——证据就在自己表里：GRPO+OPSD 在 3B 上 +6.2、在 1.7B 上 −14.1（32.0 vs GRPO 46.1），同一份 dense 监督在小 backbone 上重伤，论文只用"optimization interference"一句糊过去，全文最有信息量的对比被浪费。另外 SEED（同一 backbone、基线数字逐格相同、作者疑似重合）被引而不比，且其 ALFWorld 91.8 / WebShop 88.5 都高于 PCSD——**此条依赖笔记中标为 not-checkable 的跨论文对照（C25），本轮未独立核实**，但"best among all baselines"的射程被限定在自选基线集内这一点是清楚的。无代码、无开销报告（teacher 每 token 一次额外 forward 的成本完全不明）、无 limitations 章节，超参表里还挂着一个从未出现在结果表的 `Skill-SD`。真正值得留下来的不是它的方法而是它的诊断：SDAR 的权重变化与 teacher 置信度变化呈 ρ=−0.489 的**负相关**——teacher 变差、权重反而变大，这是对整族"token 间归一化竞争加权"方法的可迁移负面发现，比 +6.2pp 有价值得多；配套的 teacher-quality 扰动探针成本极低，可以直接拿来体检 vault 里所有 teacher-weighted 蒸馏方法。这条线缺的不是第五个平滑机制，而是把"teacher 在哪儿可信"从 log-prob 自洽性换成环境可接地的信号——不然加权再精细，量的仍然是模型跟自己有多一致。
- **Rating**: `2` 👀 ，方法是又一次"换更复杂的权重统计量"的增量迭代且主结论落在 8 条 episode 的噪声里，但 SDAR 权重反向相关的诊断和那个廉价探针值得单独记一笔。

### WorldProxy
- **Title**: Quo Vadis, World Modeling? Towards Interactive World Proxies for Continually Improving Agents
- **Institutes**: Shanghai AI Laboratory, Zhejiang University, National University of Singapore
- **Source**: [link](https://arxiv.org/abs/2608.02713)  📰 HF Daily ⬆️ 29   **📒 论文笔记**: [[2608-WorldProxy]]
- **核心**: 一篇 20 人署名、216 条引用、零实验的 position paper，主张把 world model 重新定义为 **Agent-Centric World Proxy**：用 agent 主动发起的 interaction step $\ell$ 替代物理时间步 $t$、用 information transition 替代 state transition，于是 dynamics、spatial、execution、memory、skill、reward/verification 六类模块都被收进同一个 $\hat{s}_{\ell+1}=\mathcal{WP}(s_\ell,u_\ell^{\mathcal{F}})$。再与"对 agent 介入深度"三级（L1 推理期提示 / L2 训练期信号 / L3 共演化）交叉出 6×3 = 18 格设计空间（Table 6），16 格填了代表系统，Spatial×L3 与 Reward×L3 留空并称之为 "invitations"。全文真正的落点是验收标准：world model 该按"让查询它的 agent 变好多少"打分，而不是按生成保真度。
- **锐评**: 立场是对的，但这个立场不是它的。头号主张——从 prediction-centric 到 decision-centric 验收——在 4 个月前的 [[2604-AgenticWorldModel]] 里就是 Sec 6.1 的节标题，摘要里白纸黑字写着 "decision-centric evaluation principles"；本文 Open Challenge 4 讲同一件事时引了 [91,127,87] 三篇 benchmark，唯独没引 [31]，全文只引 [31] 两次，都是借它的 L1–L3 阶梯。两篇共享 Lingdong Kong 与 Wei Chow，两人都在本文的 Writing & Editing 名单里。这不是抄袭，是定位不诚实：它把自己相对 prior art 的差异摆在"两根轴正交"上，而它最有说服力的那句话恰恰是旧的。更糟的是术语碰撞——同一批 L1/L2/L3 标签，Chu 那套指 world model 的内在能力（Predictor/Simulator/Evolver），本文指对 agent 的介入深度，作者用 "rhyme without being identical" 打了个诚实的 hedge，然后照样复用标签，半年后没人分得清谁的 L3。
  分类学的问题更硬。全文 inclusion / exclusion / screening / PRISMA 全部零命中，没有语料规模、没有筛选标准、没有一个从语料导出的数字（C9、C10）——对照 Chu et al. 自述 "synthesize over 400 works"，差距很明显。所以六类和三级是作者拍的，不是从证据里聚出来的；Table 6 只能当检索索引用，不能当领域地图读。而且这个框架**没有 falsifier**：$\mathcal{S}$ 装 "physical state, observation, memory, knowledge, execution result, verification, guidance, and more"，于是 retriever、reward model、code interpreter、LLM judge 全都是 World Proxy。全文只在 Memory 一节做过一次排除（"An ordinary static memory store is not necessarily a World Proxy"），这条纪律没推广到另外五类，Table 3 那五条 criteria 从头到尾没排除过任何一个具体系统。最刺眼的是 Memory×L1 格填了 CoALA——一篇认知架构的概念框架论文，此前任何用法下都不是 world model。**什么都装得下的分类，什么也预测不了。**
  切分同样没被辩护：Execution vs Dynamics 的理由是"数字 vs 连续物理"，那是领域差别不是功能差别；Spatial 本质是"动作为相机位姿"的 Dynamics；Memory vs Skill 的"过去发生过什么 vs 现在能做什么"在实践中就不成立——skill library 本来就是从经验蒸出来的，所以 Skill×L3 只能把 Skill×L1/L2 用过的 Voyager 和 CASCADE 再抄一遍，这本身就是该格没有独立内容的自白。L3 整列都虚：2 格自认为空，Dynamics×L3 靠 2022 年的 DayDreamer 顶着（标准 MBRL 在线训练，根本没有独立于常规 MBRL 的 proxy→agent 蒸馏），Skill×L3 靠复用填。作者把空白写成 "invitations"，但从没区分"没人做"和"这么切本来就不成立"——而且既然没有系统检索，连"没人做"这个前提都没被验证。
  引用精度也为 20 人 / 216 引的体量付了钱：**Evidence Ledger 里 C1 是确证的 `contradicted`**——文中把 I-JEPA [5] 与 V-JEPA 2 [6] 举为 "in raw pixels" 预测的例子，与 "learned latent space [194]" 对举，可这两篇恰恰是 joint-embedding latent 预测的代表作，V-JEPA 2 自述其控制变体就是 "latent action-conditioned world model"，而 [194] 只是一篇 latent space 综述、根本不是某个预测模型；文献表里真正的 pixel-space 例子（FitVid）反而闲置。方向整个写反了。同一类松弛还有 C5（DreamGym 的 "preference pairs" 归属错，DPO 在原文只是 baseline）、C2（把 [31] 的 L3 "predictions fail against new evidence 时自主修正" 软化成 self-reflection，还把它的第二根轴 governing-law regimes 整个略去）。另外 C7 那句 "Today agents rarely make that judgment well" 只有一篇 2026 preprint 撑着，且那篇测的是"何时调用 world model"而非"是否信任 proxy 输出"——断言比证据强了一档，这条按台账只能当作**未被充分支撑**读，不能当结论引。
  值得肯定的只有 Open Challenges 那一节，四条都提得准，尤其 "同一个让高风险探索变安全的 sandbox 也打开了新的攻击面"——这话库内有硬证据（[[2607-BadWAM]] 黑盒视觉扰动让 LIBERO 从 96.5% 掉到 43.1%）。把 memory / skill / reward 也当"世界的一部分"来代理，确实是有用的视角切换，它逼人问一句：花在像素级 rollout 上的力气，是不是本该花在更便宜的反馈通道上（[[2607-SeerGuard]] 一个 8B 语义二分类就解决了"会不会出错"）。但这些洞见活在散文里，不在分类学里。
  一句话总结这个方向的病：world model 领域在 20 个月内出了三套互不兼容的顶层切法（Ding et al. / Chu et al. / 本文），没有一套把切法降级成可测量的东西——**taxonomy-heavy, evidence-light**。这篇能被引用的方式只有一种：术语表 + 阅读入口 + 两个稀疏格当选题指路牌。任何经验结论都不能挂在它身上。
- **Rating**: `2` 👀 ，Open Challenges 和"按 agent 增益验收"的视角切换值得读，但头号主张是共享作者的 prior art 且未致谢、分类学无检索协议无 falsifier、还留了一处确证的 JEPA 引用方向性错误——当词汇表看，别当地图用。

### MobileWAM
- **Title**: MobileWAM: Bridging World Action Models to Mobile Manipulation with Chain-of-Foresight
- **Institutes**: Tsinghua AIR, SJTU, HKUST(GZ), 复旦, 人大, Li Auto 等（12 家挂名）
- **Source**: [link](https://arxiv.org/abs/2608.04657)  📄 arXiv   **📒 论文笔记**: [[2608-MobileWAM]]
- **核心**: 把 video-diffusion World Action Model 从固定底座 tabletop 搬到 whole-body mobile manipulation：Wan 系视频 DiT 主干 + 轻量 action expert 做 layerwise joint attention，action expert 的 FFN 换成 shared/locomotion/manipulation 三专家软路由，再挂一条只在训练期存在的 Chain-of-Foresight——RNN 式串行链，第 k 步去噪第 k 个未来 latent 并把 belief 传给下一步，梯度经四个 backbone tap 层反压主干。靠不对称 attention mask（没有任何 video token 看得到 action token）保证推理时把 CoF 和 video 分支整条删掉，backbone 退化为可缓存的 current-frame encoder，单周期 938 ms 对 Motus 4950 / LingBot-VA 8126。ManiSkill-HAB SetTable 均值 73.0%，真机 ARX Lift2 五任务 55/35/25/20/15% 对同数据微调的 π0.5 35/25/10/10/0%。
- **锐评**: 这篇的价值全在 Table 3，主表那个 73.0 反而是最不值钱的部分。"并行未来监督 +2.1 / MLP 串行 **−3.9**（46.3 低于完全不加 foresight 的 50.2）/ transformer 串行 +8.0"——愿意把打脸自己的中间步写进正文的论文不多，而这条负结果说的事比主结果重要：串行化不是免费午餐，瓶颈过窄时链上表示塌缩，被污染的 belief 会经梯度反噬共享主干。配上 Table 4 全 30 层拼接 37.1 vs 均匀 4 层 58.2，两条指向同一命题——辅助头与主干的接口形状比监督信号的量级更决定成败。Table 6 拿"软路由三专家 58.2"对"按动作维度硬拆两专家 44.6–48.8"也是干净的对照，附录承认主导专家权重只在 0.4–0.6、无塌缩，比那种"两条独立通路各司其职"的直觉叙事诚实。
  但 claim 侧的水分不少。**"first systematic adaptation"被自己的 Related Work 当场拆穿**——同文写着 ABot-M0.5 "explores WAMs with latent actions"，那正是 mobile manipulation 的 WAM（C19），真实边界只是"不用 latent action 中间层、不用点云、不用特权监督、单阶段"。SOTA 口径同样要打折：AnchorVLA 的 64.0 只覆盖六项，被略去的 Open Drawer 恰好是 MobileWAM 高于自身均值的那项，共有六项重算是 69.9 对 64.0，差距从 +9.0 缩到 +5.9；而 Related Work 引了 SG-VLA 却把它排除在主表外，那篇在同 benchmark 上同样报 0.73（切分不同不能直接减，但读者有权知道为什么不进表）。真机那五个数字全是 5% 的整数倍，高度提示每任务 20 trial，可论文自始至终没写 trial 数、也没写采了多少条示教（C14）——15% 对 0% 就是 3 次成功对 0 次，Wilson 区间大幅重叠，"优势随 horizon 增长"这个 central claim 建在不可核的样本量上。abstract 写 "strong generalization"，附录写评测 episode 在**训练分布内**随机化初始条件（C15），这词该删。更麻烦的是 Table 3–6 那个 58.2 同时被标为"+ Transformer-style CoF"（递增列暗示不含 MoE）和"MoE (ours)"（暗示含 MoE）（C8）：含 MoE 则 CoF 的 50.2→58.2 混进了 MoE 贡献，不含则 Table 6 的 MoE 对照根本没有 MoE——两种读法归因完全相反，全文没澄清。参数量除自身 ≈6.5B 外一个 baseline 都没报（C28），π0.5 对 6.5B Wan 主干在真机上比的到底是"WAM 配方"还是"更大的视频预训练主干"，从原文无法区分。§4.5 那组"我们的预测遵守近大远小"纯肉眼判读、零量化指标（C18）——这里其实不必苛求 FVD，但用一张没测过的定性图去解释"CoF 为何有效"，就是拿未测量的中间变量做因果归因；真正撑得住机制的是 Table 3，不是 Figure 3。belief"承载物理状态前推"这个说法同理，全文没有任何从 belief 解码状态的探测实验，机制叙事又一次跑在测量前面。顺带，≈6.5B 跑不动车载算力，真机实际是两张 A800 远程推理、图像走 Wi-Fi（C17）——"938 ms"是服务器数字，不是机器人上的数字。所有 evidence 状态只是 source-verified（原文确实这么写），无独立复现，且 ± 是评测 run 级 std 而非训练 seed，任何"更高"都不含统计显著性。
- **Rating**: `2` 👀 ，范式移植而非新机制、"first"被自家 Related Work 打脸、真机证据密度低到不可核；但 Table 3/4/6 那三条负结果（MLP 递归比不加更差、全层拼接远劣于稀疏取样、硬拆专家劣于软路由）是真货，会比 73.0 活得更久。

### CofactVLA
- **Title**: CofactVLA: Deconfounding Vision-Language-Action Models via Counterfactual Intervention
- **Institutes**: Tsinghua University
- **Source**: [link](https://arxiv.org/abs/2608.04396)  📄 arXiv   **📒 论文笔记**: [[2608-CofactVLA]]
- **核心**: 把 VLA "看见什么抓什么、无视指令" 的毛病写成一条 backdoor path，用一条把语言 mask 掉的前向分支当作"纯视觉偏置"的参照，然后在两处做减法：动作层把 factual velocity 里与该参照共线的分量投掉再放大残差（OPG，γ=2），特征层把两分支协方差差的正特征空间从 KV 里减掉（CCR，β=0.15，层 [15,16]）。底座 π0.5 微调 6K step，标准 LIBERO 均值 98.5%、LIBERO-Plus 零样本 total 69.1%、AgileX PiPer 真机标准 90.8% / 作者自设 OOD 75.8%（π0.5 为 71.0% / 23.5%）。全程不加数据、不加模块，只改推理与特征路径。
- **锐评**: 动机那半页写得比方法好——把 CFG 标量外插在机器人控制里的代价说成"执行不安全"而非"画质下降"，这是对的。可惜方法名和方法本身对不上：`v_causal = v_cond + γ·v_⊥` 里 `v_uncond` 只用来定义一个投影方向，从头到尾没被减出去，两者近似正交时直接退化成 `(1+γ)·v_cond` 纯放大。这不是"去混淆"，这是方向性锐化。作者还声称正交化"保证轨迹严格落在有效动作流形内"——附录四小节证明全部服务于 CCR，OPG 侧零定理零界零度量，而 §4.5 自己观测到 γ=3 掉点并解释为"过于激进的投影扭曲了动作流形"。声称的保证被自己的 sensitivity 曲线当场拆台。CCR 那边更尴尬：Theorem 1 整个挂在 Assumption 2（contrastive eigengap）上，没有任何谱图或经验检验，连 top-k 的 k 和阈值 ε 都没报，换来的增益是 97.0→97.5——在每 suite 10 episode 的预算下约合 400 次 trial 里多成功 2 次。附录 A.1.4 Step 2 更是把 `d_v`/`d_c`/`d_o` 三个符号指同一个量、标题写 `S_O` 而结论是 `S_C`，子空间身份都写反了，而这恰好是 Theorem 1 唯一的证明步骤；加上 §3.2 把 `p_uncond` 印成 `p(A|T)`（正好和"语言被 mask"反过来）、CCR 展开在 Counterfactual/Contrastive 之间摇摆——单看每处是校对，合起来是"因果形式化是装饰不是承重"。评测更是致命：LIBERO-Plus 每任务跑 **1 个 episode**，却拿去支撑 69.1 vs 67.9 的 1.2pp 排序，作者还写 "over 10 episodes to ensure statistical reliability"，这句话跟它想保证的东西方向相反。Table 2 里列了 π0（53.6）却没列自己的底座 π0.5，于是那个 "+15.5pp" 里混着底座升级和方法两件事。分轴看最难堪：全文论点是"把语言的因果作用还回来"，可 Language 扰动轴 71.8 输给 OpenVLA-OFT_m 的 81.0 达 9.2pp，Camera 44.7 输 π0-Fast 20pp，69.1 全靠 Robot 和 Layout 这两条离语言最远的轴撑起来——这个分布本身就在说：起作用的是某种一般性鲁棒化，不是去混淆。真正有分量的是真机：四任务各 100 trial，OOD 下 π0.5 是崩塌式失败（0/25/29/40，Task II 从 100% 直接归零）而 CofactVLA 稳在 67–83 的窄带，这个"方差收窄"的形状比 +52.3pp 的均值差更有信息量。可它恰恰是全文唯一**没有任何组件消融**的部分——唯一的 CCR/OPG 消融跑在分布内的标准 LIBERO 上。真机 rig 已在、协议已定，补这个消融的边际成本极低，而它是唯一能把机制主张和"一般性鲁棒化"分开的实验，作者偏偏没做。另外 π0.5 真机 baseline 是否在同样约 400 条轨迹上按同样步数微调，全文一字未提，那个 23.5% 的塌陷值就未必是"缺去混淆"造成的。还有：双分支意味着每个 denoising step 多跑一次前向，对以控制频率为硬约束的 VLA 是实打实的代价，throughput/FLOPs/显存/推理时间全文零命中；一个号称零额外数据、只改推理路径的方法，代码也没开源。倒有一处值得偷师——Table 3 让 Add/Sub/CAG/OPG 共享同一条 counterfactual 分支，把"额外计算量"控成常量，这是审所有 dual-branch guidance 类工作都该要求的对照，多数同类论文只报"有 guidance vs 无 guidance"，那对照同时改了计算量和算子。
- **Rating**: `2` 👀 ，真机 400 trial 和 OOD 崩塌对比是真材料，但方法名与算子不符、理论承重墙未验、仿真评测预算撑不起 SOTA 断言、头条 OOD 结论零消融——留作"LIBERO 系评测预算不足以支撑 SOTA 断言"这一 pattern 的数据点比留作方法条目更有价值。
