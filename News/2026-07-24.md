### Claude Sonnet 5 发布：agentic 能力下探到中端价位
- **source**: [Anthropic News](https://www.anthropic.com/news/claude-sonnet-5)（2026-06-30）
- **what**: Anthropic 发布 Sonnet 5，定位"最 agentic 的 Sonnet"：浏览器/终端工具使用、自主运行。OSWorld-Verified 上多个 effort 级别超过 Sonnet 4.6（后者更新后为 78.5%），部分任务接近 Opus 4.8；BrowseComp 中等 effort 下成本效益显著。发布价 $2/$10 每百万 token（8 月底后 $3/$15）。
- **so-what**: computer-use 前沿能力的价格在快速下移——OSWorld ≈78% 级别的 backbone 现在是中端定价。这直接影响 CUA 研究的 baseline 选择与"训练专用 GUI 模型 vs 调用通用前沿模型"的成本权衡（CUA-Survey §9.1/§9.9 的 industry 数据点）。注意 78.5% 是厂商自报口径，environment/step budget 未披露。
- **action**: 关联 [[Topics/CUA-Survey]]（§9.1 provider 格局，留待下轮 survey 维护并入，不在本 skill 直接改）

### Redeploying Fable 5：出口管制风波与 jailbreak 严重度共识框架
- **source**: [Anthropic News](https://www.anthropic.com/news/redeploying-fable-5)（2026-06-30）
- **what**: Fable 5/Mythos 5 于 6 月 9 日发布后，Amazon 研究员发现可绕过安全防护用于漏洞利用演示，美国政府 6 月 12 日实施出口管制暂停访问；6 月 30 日解除，7 月 1 日恢复。Anthropic 训练了新安全分类器（拦截该类绕过 >99%），并与 Amazon/Microsoft/Google 制定 jailbreak 严重度评估的业界共识框架。
- **so-what**: 前沿模型因安全事件被政府强制下线再重新部署，这是首例；"jailbreak 严重度分级"若成为业界标准，会影响 agent 安全评测的 protocol 设计（CUA-Survey §8.9 safety 评测的上游语境）。
- **action**: 无（政策/治理线索，非研究证据）

### AllenAI Shippy：生产级 agent 的工程经验
- **source**: [HuggingFace Blog](https://huggingface.co/blog/allenai/shippy-tech-blog)（2026-07-15）
- **what**: AllenAI Skylight 团队复盘海事监测 agent Shippy（服务 70+ 国家 300+ 机构，backbone Claude Opus 4.6）：soul（system prompt）/skills/config 三分离便于版本控制审计；用确定性 CLI 包装 API 而非让 agent 直接调 API；每会话独立 K8s 沙箱；agent 级实时工作流评测（Harbor 框架）而非静态模型 benchmark。
- **so-what**: 与我们刚并入 CUA-Survey 的 skill 线互证：生产系统同样把 skill 作为独立于模型的可版本化资产管理，且"确定性工具吸收 agent 非确定性"与 Resource2Skill 的 sandbox gate、SKILL.nb 的验收闸门是同一设计哲学的工业侧表达。agent 级评测取代模型级评测也呼应 CUA-Survey §8 的 deployment-oriented evaluation 走向。
- **action**: 关联 [[Papers/2606-Resource2Skill]]、[[Topics/CUA-Survey]]（§9.10 部署经验的佐证线索，非 peer-reviewed 证据）

### LeRobot v0.6.0：world model policy 与 reward model 进入主流机器人库
- **source**: [HuggingFace Blog](https://huggingface.co/blog/lerobot-release-v060)（2026-07-07）
- **what**: LeRobot v0.6.0 以 "Imagine, Evaluate, Improve" 组织：3 种世界模型策略（VLA-JEPA 潜空间预测 / LingBot-VA 自回归视频-动作 / FastWAM 免推理时生成）、5 种 VLA（GR00T N1.7、MolmoAct2 等）、reward model API（Robometer 基于 100 万条轨迹预训练、TOPReward 零样本 VLM 奖励）、6 个新仿真基准（LIBERO-plus 约 10,000 个扰动变体）。依赖减少 40%、数据加载提速 2 倍。

### ScarfBench：企业级 Java 迁移 agent benchmark，最强 agent 行为成功率 <10%
- **source**: [HuggingFace Blog](https://huggingface.co/blog/ibm-research/scarfbench)（2026-06-30）
- **what**: IBM 开源的跨框架迁移 benchmark（Spring/Jakarta EE/Quarkus）：34 个应用、204 个迁移任务、151K 行代码、1,331 个专家测试。验收分编译/部署/行为三级，最强 agent 行为成功率不足 10%，且编译成功率 ≫ 部署 ≫ 行为。
- **so-what**: "编译通过≠行为正确"的三级验收梯度与 CUA 领域 verifier 分层（step-level vs task-level vs 状态核验）是同构问题；<10% 的行为成功率再次说明长程 agent 任务的瓶颈在可验证性而非代码生成。
- **action**: 无（若后续有配套论文可 digest）
