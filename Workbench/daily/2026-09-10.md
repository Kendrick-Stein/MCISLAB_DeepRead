# 🔪 今日总结

今天八篇里有五篇在做同一件事：把原本要模型内化的东西搬到模型外面的一层——Show-Harness 把动作语义交给 interpreter，Programmable World Model 把世界状态交给可执行引擎，2AM 把任务记忆交给上层 Agent，Ecdysis 把可靠性交给 runtime harness，AgentGrad 把 credit assignment 交给一次真实干预。好处一致：那一层可检查、可改写、可跨 backbone 移植；代价也一致——五篇都把新加的那一层当自变量报告，却没有一篇跑出能把它单独隔离的对照（WMRL 缺 anchor-only 臂、NeoHorse-1 三个核心机制零消融、Programmable WM 零 ablation、Ecdysis 缺同预算的单条 gate、2AM 缺"不插 Agent"的基线）。最该带走的反而是两条负性结果：Show-Harness 的 Fig. 10 证明起作用的不是 VLM 懂 `MV_FWD` 的语义，而是上下文里那份 token→物理效果的确定性说明书；Ecdysis 的基线证明逐条自演化会把调好的人工 harness 改坏（51.67→46.67，10 格里 7 格绝对下降）。

## 论文点评

### Show-Harness
- **Title**: Show-Harness: Just a VLM Agent Can Play Robots
- **Institutes**: Show Lab, National University of Singapore
- **Source**: [link](https://arxiv.org/abs/2609.10522)  📰 HF Daily ⬆️ 132   **📒 论文笔记**: [[2609-ShowHarness]]
- **核心**: 把机器人控制重写成一组离散语义动作单元（`MV_FWD`/`ROTATE_CW`/`GRASP`/`DONE`），VLM 每步只选一个，再由 embodiment-specific interpreter 确定性地落成一小段有界 6-DoF 位姿更新——语义归模型、度量归解释器。同一接口既让 frontier VLM 零样本控真机，也让 Qwen3.5-2B 用 rank-64 LoRA（约 3% 参数、单卡 H200 两小时）学同一动作空间。十个真机 pick-and-place 任务上 ZS 89.0% / FT 86.0%，对照 π₀.₅ 39.0%、GR00T 35.0%、最强 agentic baseline RATS 57.0%。附带 GUMI：同一语义空间的 GUI 前端，人和 agent 用同一套按键采 policy-ready 数据，不需要遥操作硬件。
- **锐评**: 全文最值钱的不是那张 89 vs 39 的主表，是 Fig. 10 的 2×2：任意符号 + 文字写明的方向约定 19/20，几乎追平语义名 + 约定的 20/20；只给符号不给约定崩到 1/20，模型自主探测出的映射仅 23.3% 正确。这条结果干净利落地**拆了论文自己的 framing**——起作用的不是"VLM 天然理解 `MV_FWD` 的语义"，而是"上下文里有一份 token→物理效果的确定性说明书"。这对 GUI agent 的动作空间之争是可迁移的外部证据：别纠结抽象层级，先把每个操作的效果显式写死。
  硬伤在主对比。所有演示都是 GUMI 在 2 cm 量化空间里采的，π₀.₅ / GR00T 训练用的连续轨迹是**从这批量化动作反向转换回去的**（C14）。作者称之为 controlled comparison——受控的是数据内容，不是数据形态，而形态恰恰是 VLA 吃饭的东西：你喂它阶梯状、无人类遥操作节律的轨迹，然后宣布范式胜利。缺的那组实验一目了然：真·遥操作演示训 VLA vs GUMI 演示训 Show-Harness。没跑，所以 39.0 vs 89.0 里有多少是范式、多少是数据不对口，拆不开。
  成本也没对齐。ZS 每步调一次 Gemini-3.1 Pro（50 步上限），π₀.₅ 是控制频率上的一次前向；论文只给了一处 3.4× wall-clock，对 VLA baseline 的 per-episode 延迟/成本只字未提，"outperforming representative VLA paradigms"就这么把量级差的推理预算吞了。2 cm 步长意味着准静态运动，而最接近动态的 tennis ball 恰好是 ZS 最弱的两列（8/10、7/10）——范式边界大概率就在需要连续速度调制的地方。所谓 cross-task 是 5 物体 × 2 容器的 pick-and-place 变体，换的是组合不是任务结构；±xyz + 绕轴旋转的词表能不能表达 wiping、pouring、compliant insertion，论文的 limitation 只承认没测 humanoid 和灵巧手（C19），对动作词表的表达力边界避而不谈。统计上每任务 10 trials、多数子实验 20 trials、无 error bar 无重复 run，ZS 89 vs FT 86 在 n=100 下就是噪声；ZS 一支绑死闭源 API，Fig. 7 自己承认表现随底座漂移，这些数字明年不可复现。
  两处必须点名的 evidence boundary：**C5（步长 2→1 cm：正文 ZS 60→82 / π₀.₅ 18→62，Fig. 6 柱标却是 60→80 / 15→60）和 C8（视频 in-context FT 95%，Fig. 6 两根柱都标 90）在论文内部文图矛盾，Ledger 已判 contradicted**，引用时只能并列两个来源，不能当结论用。另外 Table 2 的 Cross-Environment 均值分母根本不一致——ZS 的 100.0 只覆盖 4 行 80 trials，FT 的 88.0 覆盖 5 行 100 trials，按共有四行重算 π₀.₅ 是 50.0、GR00T 是 42.5（C3），被拉低的偏偏是唯二真跑了 sim-to-real 的两个 baseline。"ZS 100 > FT 88"和"π₀.₅ 40 < CaP-X 52.5"都是分母假象，那一格里唯一干净的事实是：sim-only 训练下 FT 13/20 而两个 VLA 全灭。最后，GUMI 作为独立贡献一个数都没测——没有采集吞吐对比、没有数据质量对比、没回答"2 cm 量化是否毒害下游连续策略"，而这正是上面那条数据形态隐患的另一面。
- **Rating**: `3` 🔥，主表的对比不干净、数字有两处自相矛盾，但 action-space ablation 是近期少见的把功劳定位到具体成分上的实验，且结论直接可迁移到 GUI agent 的接口设计。

### WMRL
- **Title**: Scaling Automatic Research Agents via World Models
- **Institutes**: University of Illinois Urbana-Champaign, Amazon
- **Source**: [link](https://arxiv.org/abs/2608.12564)  📰 HF Daily ⬆️ 431   **📒 论文笔记**: [[2608-WMRL]]
- **核心**: AutoResearch agent 的 RL 训练里，generation 可以 batch、edge cost 近零，而每个候选方案的 environment execution 要独占 sandbox 真跑一遍，成本随 trajectory 数线性涨——execution 先撞墙。WMRL 用一个与 agent 共用 backbone、只靠 prompt、全程冻结的语言模型读代码直接预测 leaderboard percentile 顶替真执行，只保留约 10% 的 group 双打分作 anchor，再用 isotonic regression 在线重标定（OD）+ 逆方差加权融合两路梯度（IVD）。MLE-Dojo/DSBench 上 4B 把 883 GPU-h 压到 286（3.1×）、9B 把 1174 压到 349（3.4×），两个 benchmark 均值同时高于同规模真执行 GRPO；不带校正的纯 world model 则在四列上全面低于 GRPO。理论侧 Theorem 4 声称偏差按 $1/(1+T/T_0)$ 收缩，但其前提 Assumption 6 要求 world model 的偏差是真分的单调畸变。
- **锐评**: 最值钱的不是方法是**问题拆解**——"generation 可 batch、execution 不可 batch"把一句笼统的成本抱怨变成了有明确攻击面的不对称性，顺带把"贵在奖励获取"这件事讲清楚了。工程对照也选得干净：world model 与 agent 共用 backbone（C15）直接掐死"收益来自隐式蒸馏更强模型"，留出任务一律大于同类所有训练任务（C16）顺手测了外推，IVD 归约成单参数 $\rho=1+\hat\eta^2/\hat\eta^2_{\rm cal}$ 不引入自由超参（C10）。真正该被抄走的是 $\hat\eta^2$ 的**自审计性质**：代理信号一失真残差就变大、anchor 权重自动升高、梯度回落到真执行 group，系统退化回普通 GRPO 而不是继续学坏信号——混合比例是被测出来的，不是拍脑袋定的。
  然后是硬伤。**Assumption 6 把最危险的失效模式直接假设掉了**（C13）：$b(\tau)=\phi(r(\tau))-r(\tau)$ 且 $\phi$ 非降，意味着最大化 $\mathbb{E}[\hat r]$ 就是最大化真分的单调变换，policy 在原理上**无法** hack world model。可学习奖励代理之所以危险，恰恰是因为它们的错误与 policy 能搜索到的结构相关——某个被高估的库调用、某种让预测分变高的写法——这类偏差是 $\tau$ 的函数而非 $r(\tau)$ 的函数，一维 isotonic 标量映射根本看不见。论文 related work 老老实实引了 reward over-optimization 的文献，定理却精确地覆盖了把这现象删掉之后的世界。$\hat\eta^2$ 是探测器不是校正器，还只能探测到落在 anchor group 上的那部分 gaming。
  **更致命的是缺一条对照臂：等算力下的 anchor-only GRPO。** Table 3 的四行全部同时吃两路信号，只切换校正开关，所以没有任何实验能回答"只用那 10% 真执行 group、完全不接 world model，能到多少"。而笔记挖出的 C23 让这个替代解释极不牵强：**OD 单开就已在四列全部超过真执行 GRPO**（15.7/28.1/19.4/31.7 对 15.2/25.7/18.8/31.2），IVD 在其上只再加 0.7–2.2。如果绝大部分收益来自那张用**真执行数据**拟合的重标定映射，那真正干活的是 anchor 流，world model 只是个方差缩减先验——这正是全文最核心的因果归因，而它没有被任何实验隔离出来。Evidence Ledger 里 30 条 claim 确实全部 source-verified，但 ledger 自己写明了"source-verified 仅表示 primary source 这么写"；"world model 顶替 environment 带来了收益"这条因果 claim 不在 30 条之列，因为**没有实验能支撑它**。这才是本文真正的 evidence boundary。
  配套的诊断也整块缺失：全文零训练曲线。Theorem 4 的核心动态主张是偏差地板随 $T$ 收缩，全部实证支撑是消融表的四个末态数字。更离谱的是，一篇全部前提建立在"这个代理信号够准"上的论文，**从未报告 world model 自身的预测质量**——与真分的相关系数、rank correlation、$\hat\eta^2$ 的训练轨迹，一个都没有。最该给的两张图恰好都不在。
  **头条比较建议整条丢弃**：Kimi-48B-A3B 的 8.1/17.3 连**未训练**的 Qwen3.5-9B（9.6/23.9）都不如、DSBench 上与未训练 4B（17.1）持平（C5）；Nemotron 一侧差距只有 +1.1/+1.1 且对方在 MLE-Img、DS-Regress、DS-Other 三个类目更高（C6）；A3B/A12B 是 MoE 激活参数，按激活算是 4B-dense 对 3B-active、9B-dense 对 12B-active，论文全文没给激活参数说明就让 abstract 写"48B and 120B"（C25）。这不是笔误，是包装。GPU-hour 的账也对不上——笔记的推算（非论文陈述）显示 286−269=17 与 10–12.5% 真执行份额应有的 61–77 差 3.5–4.5 倍，而论文从不把 GPU-hour 拆成 generation/execution/world-model 三块；加速比是头号卖点，账却不给对。加上一堆内部口径不一致：abstract 吹 3–4× 而实测上界只到 3.36×（C27）、anchor 比例 10% 与"每步 8 group 至少 1 个真执行"的 12.5% 下限打架（C28）、DSBench 写排除 15 个但分项和是 16（C29）、LIBERO 的 +2.9 与 +3.8 用了两个不同基线（C30）。
  另外两条要压住：一，**"自动化实证研究"这个标题比设置深得多**——每条 trajectory 至多 4 轮交互、每轮 4096 token、单次执行 1200 秒，任务池刻意取每类**数据量最小**的竞赛（C16/C17）。在这个规模上从代码预测 percentile 当然可行；换成 24 小时的 MLE-Bench run，结果依赖训练动力学和超参运气，论文 Discussion 自己承认了这条边界，而任务选取规则恰好把它最小化掉了。二，**VLA 那节讲的根本不是同一个故事**：LIBERO rollout 仍在仿真器里真跑，Robometer 替换的只是**奖励标注器**（末端稀疏成功 → 逐帧 dense progress，C20），执行瓶颈一点没动，Table 2 里也确实一个 GPU-hour、一个加速比都没有；OOD 还只是同任务的未见初始状态（C21），真执行 GRPO 相对 SFT 才涨 0.9 分（基线低得可疑）。这节证明的是"两个校正在融合 dense 学习奖励与 sparse 真值时有效"，跟主线是两码事。最后，统计强度撑不起 1 分量级的结论：14 个 MLE 留出任务分三类、60 个 DSBench 分四类，avg@8 但无种子重复、无 error bar，+1.1/+1.6 这种数字落在噪声里。
- **Rating**: `3` 🔥 ，问题拆解与 anchor 自审计设计值得直接抄进自己的 agentic RL pipeline，但读的时候把 abstract 的"超 48B/120B"和 3–4× 全部划掉，只认相对同规模 GRPO 的四个数字，并牢记缺 anchor-only 对照臂意味着"world model 到底有没有贡献信息"至今无实验回答。

### NeoHorse-1
- **Title**: NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness
- **Institutes**: TokenRhythm Technologies, Infinigence AI, Tsinghua University, Peking University, CUHK, Visionplus Capital, WX Capital, Alibaba Group
- **Source**: [link](https://arxiv.org/abs/2609.08183)  🔥 HF Trending ⬆️ 389   **📒 论文笔记**: [[2609-NeoHorse1]]
- **核心**: 线上 routing harness 为每个 user turn 记下"预测需要多强的能力 / 实际派了哪档 / 后续发生了什么"，作者主张这份记录本身就是一份免费的难度标签——同一个 routing score 被用来给 SFT 排三阶段课程、给 on-policy distillation 挑起始上下文、并按能力短板决定下一轮数据配比。语料是 10^5–10^6 条真实部署轨迹，经去重、结构校验、六维语义评估三道闸。十个 benchmark 宏平均 4B 从 58.94 升到 64.87、9B 从 65.60 升到 69.04。论文自陈只跑完一轮 evaluation–selection–update，标题里的"recursive"从未真正执行。
- **锐评**: 真正值钱的是那条观察——router 为了计费和延迟，每天都在免费生产 curriculum learning 花大价钱买的难度标签；作者还多走一步，拒绝用"实际服务的档位"当标签（掺了用户覆写和服务可用性），改用请求重估 capability demand。这个区分干净、可迁移、成本近零，是全文唯一称得上 taste 的地方。问题是论文完全没有证明这条信号有用：课程排序没对照随机顺序，OPD 没对照纯 SFT，能力导向配比没有任何形式的对照（C11）。Section 5.2 仅有的两组受控实验回答的是"数据从哪来"和"数据有多少"——这两个问题即使全部成立，也撑不起标题里的 routing 与 curriculum。主表的 +5.93 / +3.44 完全可以只是"拿高质量真实 agent 轨迹做 SFT+蒸馏"的普通收益。更难看的是 Table 3 的参照系：论文报的 +6.26 是相对 Toucan，但 Toucan 那一轮把模型从基座 69.31 打到 64.32（τ² 掉 10.75、BFCL 掉 6.25），而 routing-harness 相对基座只有 +1.26，其中 HumanEval 一项就贡献 +1.83，其余四项净负、BFCL 还掉 3.82（C15、C27）——数字全对，但全文没有一处提到对照组低于基座，于是一个"我们的数据几乎没提升、公开数据明显有害"的结果被写成了"我们的数据明显更好"。这是参照系选择问题，不是笔误。9B 的结果反过来咬论文自己：非 agentic 四项平均只有 +1.28，LiveCodeBench 与 IFBench 与基座**精确相等**（65.14 / 66.33），IFEval 还退 0.37（C7）——增益随基座变强而衰减，而 RSI 的整个卖点恰恰是增益要能跨代累积。VitaBench 承担的权重与它的证据强度严重不匹配：它是两个尺度上单项增幅最大者（+10.50 / +11.00），却偏偏是只跑一次、且 user simulator 与 judge 双双换成 DeepSeek-V4-Flash 的那一个（C9、C10），单项吃掉 9B 全部增益的 32%；把它和已经饱和的 HumanEval（同表 Gemma-4-12B-it 已 100.00）一起打折，9B 的故事就只剩 PinchBench 与 QwenClawBench，而这两项恰好跑在作者自家 OpenSquilla harness 上（C19）——注意这只是一个**未被检验的混淆因素**，4B 上用原生 harness 的 WorkBuddy 涨了 9.79，不支持这个猜想，不能当结论写。可复现性接近零：学习率、batch size、GPU 数、训练 token 量全无（C22），OPD 的 teacher 是哪个模型、K 取多少也没写（C21），甚至没说清发布的权重是"仅 SFT 课程"还是"SFT+OPD"的产物。最后，"RSI"在本文的全部落点只是"用 deficiency profile 改下一轮数据配比"这一步，而第二轮才是所有难题所在——更新后的 checkpoint 回 harness 会改变 routing 分布本身，进而改变课程标签与配比依据，这个自指循环是否收敛、会不会把语料推向模型已擅长的区域，论文连一个方向性预测都没给。Ledger 里 25 条 claim 全部 source-verified，但 source-verified 只意味着论文确实这么写，不意味着结果被独立复现过。判决：数据通路是真新东西，方法论证据是空的；标题该叫 "Agentic Post-Training on Deployment Traffic"，"Recursive Self-Improvement" 是个命名不是结果。
- **Rating**: `3` 🔥 ，真实付费流量作为演化语料 + "router 预测即免费难度标签"这条观察在 vault 里是独一份，值得读；但读的是那条信号设计，不是那几个百分点。

### Programmable World Model
- **Title**: Programmable World Model
- **Institutes**: Alaya Lab, National Taiwan University, National Yang Ming Chiao Tung University
- **Source**: [link](https://arxiv.org/abs/2609.10540)  📰 HF Daily ⬆️ 82   **📒 论文笔记**: [[2609-ProgrammableWM]]
- **核心**: 把 video world model 一刀劈成两半：一个轻量 engine 按 coding agent 写出的可执行 world program 维护 canonical state（实体/属性/关系/规则），pretrained video model 降级为纯 renderer，中间用 state-augmented 3D OBB 相连——OBB 在目标相机下被确定性编译成 identity / semantic / direction 三张 pixel-aligned control map，驱动挂在冻结 LingBot-World-v1 上的 Structured Spatial ControlNet。health / inventory / faction 这类没有视觉表现的变量由引擎显式维护，off-screen 实体不再随视角消失。自建 CombatStateBench（50 clip）上 Count Accuracy 94.00、State Accuracy 98.00，对照 LingBot-World-V2 的 40.75 / 8.00 与 YUME 的 32.00 / 58.00。真正的思想在 Sec 2 的 training–inference asymmetry 论证，而全文零 ablation、零 limitations、零附录。

- **Rating**: `3` 🔥 ，Sec 2 的 training–inference asymmetry 是值得长期引用的一条真 insight，state–rendering 彻底解耦也与"把世界逻辑吸进生成模型"的主流反向——但证据链弱到只能当 preview 读：所有数字信本文措辞、不信 programmability 这个结论。

### 2AM
- **Title**: 2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation
- **Institutes**: KU Leuven, Meituan Inc., Flanders Make@KU Leuven
- **Source**: [link](https://arxiv.org/abs/2609.11308)  📄 arXiv   **📒 论文笔记**: [[2609-2AM]]
- **核心**: 把 long-horizon manipulation 的 task memory 全部放在上层多模态 Agent 里，底层 Action Model（Qwen3-VL-4B + flow-matching expert）只吃当前双路 RGB 和 robot state，episode 内无状态；两层之间的接口是「subtask language + 可独立缺失的 2D grasp/place/move 点」，监督从 demonstration 标注确定性反推，训练时加 condition dropout、坐标高斯噪声和时间抖动来适配不完美 steering。LIBERO-Mem 十任务上拿到 76.29% completion / 63.00% relaxed SR / 11.83% strict SR。对齐口径下相对自建 π0 复现 completion +5.50、relaxed +25.58，但 strict SR 从 12.25 掉到 11.83。真正扛结论的是 language-only 消融：只去掉 2D 点，三项指标塌到 7.25 / 19.42 / 53.72。

- **Rating**: `2` 👀 ，问题提法和接口设计值得跟进，但对齐口径下的净增量只有 completion +5.5 / strict −0.4，Agent 侧黑箱、单次点估计、无代码让所有 claim 都只能当假设读。

### AgentGrad
- **Title**: AgentGrad: Intervention-guided Prompt Optimization for Multi Agent Systems
- **Institutes**: Korea University, KAIST, Meta AI, UNIST
- **Source**: [link](https://arxiv.org/abs/2609.08572)  📰 HF Daily ⬆️ 89   **📒 论文笔记**: [[2609-AgentGrad]]
- **核心**: 把 MAS prompt optimization 的"谁该改"从 LLM critic 打分换成真做实验：对每个失败样本按逆执行序逐个给单个 agent 注入含 ground-truth 的 hint，谁的单点修正能把 reward 拉到 r_max 谁就是 target agent。更关键的是顺手白赚一个 pseudo-label——同一输入下原始输出 ŷ 与注入后输出 ỹ 的差就是 agent 级监督，textual gradient 因此不再需要显式 loss。再由 aggregator LLM 把语义相近的 sample-level gradient 聚成 semantic minibatch 抽象成一条泛化梯度，替代 TextGrad/GEPA 的随机分组拼接。五个 MAS benchmark 上 GPT-5-mini 平均 +11.76（GEPA +9.24），wall-clock 平均 136 分钟、约为 GEPA 的 1/2.5。
- **锐评**: 核心 idea 是真的好，好在它把 credit assignment 锚回了可证伪的反事实：注了 hint 之后 reward 到没到 r_max，是环境说了算，不是某个 critic 自评说了算——这一刀就绕开了 SEED 那类 gate 被 hack 的老毛病。而 pseudo-label 那一步比 target identification 更根本，干预不只告诉你"谁该改"，还告诉你"该改成什么样"，把跨流水线的信用分配压成一次局部 input-output 对照；Figure 4 里 minibatch improvement ratio 0.51→0.87 正是这个机制的直接指纹，而且作者诚实披露了 STGA 会把它从 0.87 换回 0.72 去买泛化——这种自曝负指标比五张全胜表可信得多。硬伤在下面。**第一，"两个 backbone 五个 benchmark 全面 SOTA"是 overclaim，Evidence Ledger 判为 contradicted**：Qwen3-8B/IFBench 上 TextGrad 42.52 > AgentGrad 41.42，论文自己的表格还给 TextGrad 加了粗，正文和表格互扇耳光，真实战绩是 10 格赢 9 格。更该骂的是同一格藏着全文最有信息量的负性结果——GEPA(37.53) 和 MIPROv2(40.08) 双双跌破 no-PO 基线 40.82，"弱 backbone 上 prompt 优化可能有害"，作者一字未提。**第二，成本口径是全文最脆的一环**：sequential intervention 每个失败样本最多跑 N 次系统执行，Algorithm 1 调的就是同一个 rollout 函数，但论文从未说明这些干预是否计入预算 B。Figure 3 横轴就是 rollout 数，口径不明则"1,000 rollout 达 70% vs GEPA 6,000"根本不是同一把尺子；2.5× 那个数还是两列均值之比（2.47），按论文自己"vs. next-best"五个数取平均只有 2.24，且 PUPA/MATH 的 next-best 压根不是 GEPA。**第三，基线可信度存疑**：GPT-5-mini 的 IFBench 与 MATH 上 TextGrad 连 standard error 都与 no-PO 基线逐位相同（Table 5 的 IFEval/OlympiadBench 同样），这是一次更新都没被接受的退化运行，论文既不说明也不排查，而这两格实打实地把 AgentGrad-vs-TextGrad 的平均差距推高了。迁移实验的"五格全胜"也要打折：按报告的 SE 只有 IFEval 一格领先超过双方 SE 之和，EX-FEVER 领先次优者仅 0.22，PUPA-TNB 的 +2.87 还小于 GEPA 自己的 ±3.11。适用边界也比标题窄得多，"Multi Agent Systems"在本文实际等于固定拓扑顺序流水线，"改一个 agent 就够"在有交互回路或并行分支的系统上会直接失效；而 hard case（走完 n=1 仍无解的失败）占比论文一次都没报——这个数字如果大，主表增益就带着幸存者偏差。最后，13 页、无附录、无代码、无 prompt，预算 B、D_train/D_val 规模、各 benchmark 的 agent 数 N 全部缺席，连 Table 3 的 vanilla 零点都没定义（HotpotQA 67.89 与 Table 1 TextGrad 同值但 SE 不同），方法依赖四类 LLM 调用却一个 prompt 都不放——所有数字只能当作者报告值。
- **Rating**: `2` 👀 ，干预式归因这个 formulation 值得抄进自己的 credit assignment 工具箱，但 SOTA claim 被自家表格证伪、干预开销不入账、TextGrad 基线有退化运行、零复现材料，够 frontier 不够 foundation。

### Ecdysis
- **Title**: Ecdysis: Efficient and Effective Training of Runtime Harnesses for LLM Agents
- **Institutes**: Chengdu Institute of Computer Applications CAS, University of Chinese Academy of Sciences, Beijing Institute of Technology, Beijing University of Technology, Yangtze Delta Region Institute of Tsinghua University, Jiaxing Key Laboratory of AI and Cyber Resilience
- **Source**: [link](https://arxiv.org/abs/2609.11677)  📄 arXiv   **📒 论文笔记**: [[2609-Ecdysis]]
- **核心**: 把 harness 自演化的更新粒度从"每条失败改一次"改成"每轮改一次"：一轮内所有失败轨迹先聚成跨任务 failure pattern，再由 Analyst/Critic/Engineer 两轮辩论加 Moderator 出一份结构化修改 spec，只调一次 coding agent 落地，训练集总分严格提升才接受。动机是 failure attribution——单条失败分不清是模型毛病还是 harness 缺陷，逐条修会把 harness 焊死在当前模型上，作者用 `ΔH = t·ΔH_model + (1−t)·ΔH_harness` 把这件事形式化。5 个 LLM × 2 个 τ²-Bench 子集上平均 59.33% 对 Self-Evolution 46.67%、人工 harness 51.67%，训练最快 1.84×。所有 harness 只用 Qwen3-8B 演化，直接搬给另外四个模型复用。
- **锐评**: 这篇最值钱的数字不是作者吹的那个。三种演化方法都从同一份人工调好的 Human-Aug harness 起步，跑完 SE 从 51.67 掉到 46.67，10 格里 7 格绝对下降，Pass@3/Pass^3 同向——"让 coding agent 看着失败改 harness"在这个设置下是净负收益，起点越好越容易被改坏。论文把这当动机一笔带过，之后再没回头看，属于把自己挖到的金子当土埋了。真正硬的证据也不是 59.33 这个平均值，而是 10/10 个 τ² 格全部高于人工 harness、跨 8B 到 230B 四个模型家族符号全对——可惜论文一句都没用它论证。硬伤在后面。第一，AgentBench 那一块整块不可解释：w/FDCR 对五个模型给出完全相同的 90.00/90.00/90.00，AVG = Pass@3 = Pass^3 意味着每个模型都在同样的 18/20 上三次全对、2 题三次全错，而 Llama-3.1-8B 的 Direct 只有 5.00。最自然的解释恰好是论文自己诊断 SE 时写的失效形态——把训练任务答案升格成全局 runtime constraint，harness 里编了答案，用哪个模型就不重要了。论文零评论，而这块占了 headline 平均的三分之一。第二，SE 这个基线很可能是被基建拖垮而非被范式拖垮：τ²-Retail 上 SE 只有约 67% 的 coding-agent 调用正常完成，Ecdysis 100%，SE 的时间/成本/准确率三项全在含三分之一失败调用的 run 上测的，论文当"发现"报告而不重跑；更要命的是它的 SE 把一轮内 n_i 条编辑未经单独验证串行累积成一个候选统一评估，是"限流"和"逐条 gate"两者里最差的组合。"每条失败改一次但每条单独 validate"这个更强的 SE 从没被测过，于是"跨任务复现性有效"和"少改几次就有效"根本分不开——一次最便宜的消融，没做。第三，t 是全文因果主干也是证据最弱的一环：那个分解式是定义不是推导，不约束任何可观测量；t = 60.0% vs 45.5% 来自作者对自己 run 的人工标注，无样本量、无 codebook、无第二标注者、无一致性指标，45.5% 与 5/11 这类分母相容，按现有报告不可证伪。论文 §3.1 老实写了"cross-task recurrence 只是 inductive bias 不是因果归因证明"，abstract 和 conclusion 立刻就没守住。abstract 的宣传同样是挑着说的：18.56% 是并入 AgentBench 后的相对增益不是百分点（τ² 单独算反而是 27.1%，说明这块不是在抬高结论而是纯粹脏），"up to 1.84×"只是 w/FDCR 在 τ²-Airline 的最好情况——同配置 AgentBench 只有 1.03× 等于没加速，而论文自己的最大加速 3.23× 属于不带 FDCR 的配置。"降低推理开销"也只对 SE 成立：10.16M 比 Direct 的 8.70M 多 16.7%，每轨迹 118.69s 与人工 harness 的 118.53s 没区别；训练省钱那侧 τ²-Retail 上 w/FDCR 输入 token 反比 SE 多，省的是 95.42% vs 89.35% 的 cache hit rate，不是少干活。自洽性也不干净：Table 10 与 Table 7 在同一 (Qwen3-8B, AgentBench, harness) 上给出 91.67/100/85 与 85/85/85 两套数，caption 不说哪个 split；"Final Evaluation Tokens"两处定义不同、数字差约 3 倍；Tables 1/2/13 的 ± 全文从未定义（C22 标 unsupported），所以任何"落在误差内"的判断都做不了。每格 20 题 × 3 trial、分辨率 1.67pp，每个（method, dataset）只演化一次，无 seed、无重复 run、无噪声带、无 Limitations 节——而并排的 HarnessDev 实测同 commit 重跑噪声带是 ±4.75 分，Ecdysis 的 FDCR 增量正好 4.67pp。覆盖面也窄：全是带 user simulator 的对话式 tool-use，没有 coding/SWE/GUI/长程环境，harness 只试了 Life-Harness 一份，"按轮聚合优于逐条"是范式性质还是这份代码结构的性质，未测。
- **Rating**: `2` 👀 ，"自演化的默认方向是把 harness 特化到当前模型"这个观察和 SE 跌破人工起点的负性结果值得记住并搬到 GUI/computer-use harness 上检验，但核心机制 claim 靠一个手标的 t 撑着、关键消融（同预算单条证据）缺席、三分之一的 headline 建在不可解释的 90/90/90 上。
