# 🔪 今日总结

今天的主线是 **RL 训练信号的复用与边界**：Direct-OPD 证明 weak teacher 的 RL 增量可以当 implicit reward 搬给 strong student（正面），GRPO-Null 用 18 组受控实验证明已 mastered 任务上 GRPO 没有学习信号（反面）——一天之内读到同一命题的正反两面，比各自单独读值钱得多。另一条线是导航/操作 foundation model 的工业级配方（ABot-N1 的 pixel-goal 接口、EgoSteer 的 9.6K 小时数据引擎），共同毛病是工程硬、归因软：零 ablation 或脏对比。VisualAccessBoundary 则给 VLM CoT 提供了一个干净的因果结论：推理链不回看图像，瓶颈在 perceptual readout。

## 论文点评

### Direct-OPD
- **Title**: Weak-to-Strong Generalization via Direct On-Policy Distillation
- **Institutes**: SIA-Lab (Tsinghua AIR × ByteDance Seed), Tsinghua University, Peking University
- **Source**: [link](https://arxiv.org/abs/2607.05394)  📰 HF Daily ⬆️ 96   **📒 论文笔记**: [[2607-DirectOPD]]
- **核心**: RLVR 每换一代 base model 就要重付一次天价 RL 账单，本文想在 1.5B 小模型上跑 RL、把成果搬给更强的大模型。直接蒸馏 weak teacher 的分布会把 strong student 拖下水（R1-Distill-7B 56.7% 被 51.3% 的 teacher 拖到约 50%），所以 Direct-OPD 改为只迁移 teacher **RL 前后两个 checkpoint 的 log-ratio**——按 DPO 恒等式反向读出的 implicit reward——在 student 自己的 on-policy rollout 上做 RL，KL 锚在 student 初始化而非 teacher。三个起点已高于 post-RL teacher 的 student 全部上涨：Qwen3-1.7B AIME24 48.3→58.3（+10.0）、R1-Distill-7B 56.7→63.1，迁移成本仅 8×A100 跑 4 小时；两个独立 teacher 的 RL 增量还能串行叠加（58.3→63.8）。
- **锐评**: idea 是真干净——"蒸分布的差分，不蒸分布本身"一句话讲清，student 已强于 teacher 仍能 +10 分，这才是 weak-to-strong 该有的样子，不是又一篇换皮蒸馏。最有信息量的 ablation 是 2K token 截断训练能泛化到 16K 完整 rollout，且 top-k overlap 不升照样涨分，说明学的是 reward 结构不是 teacher 的输出模式。但硬伤同样扎眼：其一，related work 对 proxy-tuning / Emulated Fine-Tuning / Weak-to-Strong Search 集体装瞎——tuned/untuned 小模型 log-ratio 当 steering 信号是 2024 年就有的玩法，本文真正的增量只是"训练时蒸馏 vs decoding 时加偏移"，结果最该打的 proxy-tuning baseline 一个没比。其二，评测寒酸到只有 AIME 24/25 两套各 30 题的纯数学卷，Qwen3-4B AIME25 的 +3.2% 在 30 题×32 samples 的方差下约等于多对一道题，且主表连 vanilla OPD 的数字都不给，只藏在 Fig.1 的 motivating 曲线里。其三，token 级 reward 隐含 teacher/student 词表对齐，全部实验窝在 Qwen 家族内部，跨 tokenizer 能不能用绝口不提。工程价值是实的，学术包装注了水。
- **Rating**: `3` 🔥 ，方法极简、真 weak-to-strong、算力账算得过来，值得跟进复现；但引用缺口和数学单科评测意味着结论边界远比 abstract 吹的窄。

### ABot-N1
- **Title**: ABot-N1: Toward a General Visual Language Navigation Foundation Model
- **Institutes**: AMAP CV Lab (Alibaba 高德)
- **Source**: [link](https://arxiv.org/abs/2607.10383)  📰 HF Daily ⬆️ 82   **📒 论文笔记**: [[2607-ABotN1]]
- **核心**: 高德的 VLN foundation model 技术报告：slow system（Qwen-3.5-4B）低频输出 CoT + 两个图像空间锚点（affordance pixel 管"往哪走"、target pixel 管"目标在哪"），fast system（Qwen-3.5-2B + QFormer）高频解码连续 waypoint，两者异步耦合。这个 pixel-goal 接口把 point-goal / instruction-following / object-goal / POI-goal / person-following 五个任务塞进一个 checkpoint，30M 样本预训练 + 仅对 slow system 做 GRPO。R2R-CE Val-Unseen 上 SR 70.9 / SPL 67.5 全面 SOTA，自建 ABotN-POIBench 上到店率 77.3%（+35pt），自建 PointBench 室内/室外 SR 95.4%/92.9%，并在四足机器人上 10Hz 全在板部署。
- **锐评**: 好的部分要认：pixel goal 是全文最干净的设计——用图像锚点做 slow-fast 通信天然免疫坐标漂移，还顺手把 object-goal 的 search/approach 解耦落了地，OVON DTG 从 1.44m 砍到 0.82m、PointBench 最难档 +22.7pt 都是这个设计的直接证据；R2R-CE 只用三个固定相机 RGB（无 depth 无 odometry）打赢一票 depth+odom 方法也够硬；每张表都带单任务变体 ABot-N1† 对照、正迁移 claim 有数据，比多数 generalist 报告老实。但硬伤同样扎眼：**全文零组件 ablation**——CoT 拿掉会怎样、pixel goal 换坐标会怎样、GRPO 前后涨了几个点，一律没有，所有 "gain 归因于 X" 都是讲故事；两个最大的数字（77.3/92.9）出自**自建 benchmark，且通篇未声明训练与评测场景隔离**，而对照的 GNM/ViNT/NoMaD 全是 zero-shot，+35pt 里有多少是 in-domain 数据红利根本无从判断；真机部署偷偷换了一套模型（4B+2B 缩水成 2B + 306M DiT），还只给定性 episode，"real-world confirms generalization" 站不住；CoT 本身没有任何 reward 和忠实性检验，所谓 interpretability 更像装饰。另外 person-following 的 Collision Rate 从 7-12% 恶化到 17.9%，safety 显然没进 fast system 的优化目标。与 NavFoM / StreamVLN 这类单系统的本质区别就在显式 pixel 中间表示——方向对，但证据链配不上 claim 的音量。
- **Rating**: `3` 🔥，pixel-goal 统一接口 + 工业级数据引擎值得所有做 VLN 的人精读，尽管 ablation 缺失和自建 benchmark 的可比性问题让它更像肌肉展示而非严谨论证。

### EgoSteer
- **Title**: EgoSteer: A Full-Stack System Towards Steerable Dexterous Manipulation from Egocentric Videos
- **Institutes**: Institute for AI, Peking University; PKU-PsiBot Joint Lab; University of Pennsylvania
- **Source**: [link](https://arxiv.org/abs/2607.09701)  📰 HF Daily ⬆️ 8   **📒 论文笔记**: [[2607-EgoSteer]]
- **核心**: PKU-PsiBot 把 "egocentric human video → 双灵巧手 VLA" 做成了一个真正的 full-stack 系统：EgoSmith 四阶段管线（DPVO+Any4D 4D 重建，吞吐比 HaWoR 快 9×）把 12 个数据集清洗成 9.6K 小时预训练数据；核心设计是统一的 R^48 相机系相对 state-action 表示（每手腕部 SE(3) + 15D 指尖关键点），让 human 预训练和 187h 真机后训练共享同一动作空间；模型是 Qwen3-VL 2B + DiT flow-matching action expert，外加一个只在训练期存在、预测未来 DINOv3 特征的 world-model expert。9.6K 预训练 + 真机后训练 + 3 轮 DAgger 后，在 RealMan 和 AgiBot-G1 两个 embodiment 的 40 个任务上拿到 75% 平均成功率，预训练数据量 0K→9.6K 呈 log-linear scaling。
- **锐评**: 先说好的：这是 human-video-pretraining 方向少见的每一层都有可核查工程指标的工作——44.5% MFU、9× curation 吞吐、training-time RTC 消 chunk 停顿，以及最值钱的那条 scaling 曲线和 noisy-data ablation（不清洗直接掉到 33%，"curation 比堆数据重要"第一次有了正面证据）；18 步 40 秒的 box folding 用 120 demos 做到 75% 是真硬的数字。但毛病同样扎眼。第一，π0.5 22% / Being-H0.5 39% vs 自家 74% 的对比是脏的——作者自己在正文承认 baseline 的动作表示、分辨率、部署优化全都不一致，这 52 个点里有多少是"9.6K 小时数据的功劳"根本无法归因，还只敢在"10 个较简单任务"上比。第二，全部 ablation 在 1K 小时预训练的小 setting 下做（完整版才 44%），WM objective 那 +13 点在 9.6K 全量下是否还成立，一个字没提。第三，few-shot 实验拿 Diffusion Policy 在 18 步长程任务上的 0% 当对照纯属打稻草人，缺同级 VLA few-shot 对照。第四，标题里的 "Steerable" 名不副实：所谓 steerability 就是语言指令跟随，五级层次指令连逐级定义都没给全，compositional/unseen 各 4 个任务撑不起这个词；真正的最大增量其实是 DAgger（22.5%→62.5%），说明离开 human-in-the-loop 修正这套系统的裸成功率相当难看，75% 的 headline 里藏着 8.3 小时定向补课的功劳。
- **Rating**: `3` 🔥，对比实验脏、"steerable" 是营销词，但统一动作表示 + scaling 证据 + 全栈工程细节让它成为这条路线目前最完整的参考配方。

### GRPO Null WebAgent
- **Title**: A Learning-Rate-Gated Failure of GRPO in a Small Language and Vision-Language Model Web Agent: A Controlled Null and Its Mechanism
- **Institutes**: Independent Researcher, Monash University, University of Chinese Academy of Sciences, Shenzhen University of Advanced Technology, Pusan National University
- **Source**: [link](https://arxiv.org/abs/2607.12640)  📄 arXiv   **📒 论文笔记**: [[2607-GRPONullWebAgent]]
- **核心**: 在 MiniWoB 上对 Qwen3-VL 4B/8B 跑 18 组受控 GRPO 实验（变 learning rate / KL / seed / init / clip），发现对 SFT 已掌握的 11 个任务没有任何统计可信的提升——最好的 arm 仅 +3.6 点（McNemar p=0.50），且 learning rate 呈单调门控：低 LR 无操作、中 LR (1e-5) 可信变差 15 点、高 LR (2e-5) 崩到 0%。Positive control 在有 sampling headroom 的任务上同一 pipeline +22 点（p=0.007），证明 null 不是代码坏了。机制上给出 double dissociation：中 LR 的 degrade 是晚层 effective rank 崩塌（layer 35 从 9.2 → 1.2），graft 回 attention 或 MLP 就能恢复到接近 SFT；高 LR 的 collapse 反而 rank 升高但 readout 全毁，任何单组件修复都无效。
- **锐评**: 方法论是示范级的——paired McNemar + task-clustered bootstrap + 等价性检验 + 6 个 training seed 复现，这套统计纪律在 agentic RL 论文里几乎绝迹，positive control 的设计更是直接堵死"你 pipeline 坏了"这条最容易的反驳。degrade/collapse 的双解离（局部可 graft 修复 vs 分布式不可修复）是真发现，weight movement 不预测失败这一点尤其反直觉。但硬伤同样明显：标题级 claim "GRPO 不注入技能"建立在**已 mastered 任务**上——binary reward 下 group 内几乎无 variance、advantage 趋零，这本来就是 RL 理论上没有学习信号的 regime，null 有一半是重言式；自己的 positive control +22 点恰恰证明有 headroom 时 GRPO 就是有用，真正有争议的场景（部分掌握、long-horizon、组合泛化）一个没测。外部效度更是窄到危险：MiniWoB 是 2017 年的玩具环境，单模型家族，对 WebArena/OSWorld 级别的结论外推力为零；机制部分 4B 成立到 8B 就 break，作者自己承认 checkpoint 少、噪声大。号称 release 全套统计与 interpretability 测量，却没给出代码链接。跟 MobileGUI-RL、UI-R1 那批报正收益的工作本质区别在于：它不是又一篇 +X%，而是给"RL 何时不会有用"划边界——这类 controlled null 社区确实稀缺。
- **Rating**: `2` 👀 ，统计方法论值得所有做 agentic RL 的人抄作业，但核心结论半个重言式、场景太玩具，看方法不必信标题。

### VisualAccessBoundary
- **Title**: Visual Access Boundaries in Vision-Language Model Reasoning
- **Institutes**: The University of Tokyo (Matsuo Lab)
- **Source**: [link](https://arxiv.org/abs/2607.12815)  📄 arXiv   **📒 论文笔记**: [[2607-VisualAccessBoundary]]
- **核心**: 提出 Visual Access Sweep——沿 layer 深度和 generation 时间两个维度硬屏蔽生成 token 对 image token 的 attention，测出维持精度所需的最小访问区域（Visual Access Boundary）。在 Qwen2.5-VL 和 InternVL3 共 6 个配置上发现：CoT 把生成长度拉到 Direct answering 的约 50 倍，所需视觉访问边界却只差 ≤2 层——推理链根本不在"反复看图"，而是在对早期层已写入 hidden states 的视觉信息做延长的语言计算。进一步发现 CoT gain 与 perceptual readout 精度正相关：把 ground-truth 属性以文本喂给模型后所有属性的 CoT gain 都恢复一致，说明瓶颈在感知提取而非推理本身。
- **锐评**: 这篇的方法学品位值得表扬——精准打中已有 attention 观察性研究的死穴："attention magnitude does not establish necessity"，然后用因果干预正面回答。对照实验是模范级的：null-sink 排除 attention 重分配 artifact、query-text block 排除晚期重读通道、tolerance 四档扫描下 |Δℓ| ≤ 1，加上 probe-vs-decode gap（linear probe 能从 hidden states 高精度恢复 angle/size，模型自己却 decode 不出来）这个最有行动价值的发现——VLM reasoning 的短板在视觉属性的可解码性，不在推理长度。但硬伤同样明显：任务全是 attribute counting 和 GQA yes/no 这种"一眼看完再算"型任务，结论"CoT 不需要回看图像"几乎被任务设计预定了——作者自己都承认 iterative visual inspection 类任务不在评估范围，而 visual search、multi-hop grounding、"think with images" 恰恰是这个 claim 唯一值得检验的战场，等于在最安全的地方宣布了胜利。此外干预只切断 direct attention 一条通道，residual stream 未受控，"直接访问不必要"不等于"晚期不使用视觉信息"；机制解释（early binding vs. front-loading）完全开放；cross-attention 架构只有一个 pilot；代码未开源。跟 prior work 的本质区别是从相关性观察升级到必要性干预，这一步是真贡献——只是结论的外推半径被任务选择卡得很死。
- **Rating**: `2` 👀 ，干预方法干净、对照严谨，但在最不需要迭代看图的任务上证明"不需要迭代看图"，结论半径有限，等它在 visual search 类任务上被复现（或翻车）再说。

### AgentReadyWeb
- **Title**: Designing Agent-Ready Websites for AI Web Agents: A Framework for Machine Readability, Actionability, and Decision Reliability
- **Institutes**: Independent Researcher (Canada); Université Paris Cité
- **Source**: [link](https://arxiv.org/abs/2607.12056)  📄 arXiv   **📒 论文笔记**: [[2607-AgentReadyWeb]]
- **核心**: 把 web agent 失败的锅从 agent 侧甩回网站侧：提出 "agent-ready website" 三维度框架（Interpretability / Executability / Decision Reliability），本质是 JSON-LD、Schema.org、aria-label、MCP 等既有标准的打包分类。作者自建一对内容完全相同的合成电商网站（baseline 商品数据埋在 JavaScript 里 vs agent-ready 版暴露 JSON-LD + 语义标注 + 证据页），用 browser-use 跑 GPT-4.1 / Gemini 2.5 Flash / Grok-4 Fast 三模型 × 5 任务 × 300 runs：严格成功率 89.3% vs 49.3%，平均步数 -30.4%，prompt token 最高省 40.5%。
- **锐评**: 问题是真的，证据是自己搭的靶子。Baseline 刻意把商品数据全埋进 JS——这是手工制造的最坏情况，而真实电商站（Amazon、Shopify 系）早就普遍带 schema.org 标注，所以那个 +40 pp、以及 Task 2/3 上 23%→100%、17%→93% 的惊人提升，很大程度是打稻草人打出来的。更致命的是无 ablation：JSON-LD、aria-label、证据页等改动全部打包上阵，三维度框架各自贡献多少完全不可知——框架的分类学立身之本没有任何实证支撑，只是叙事结构。统计上也有硬伤：temperature=0 下同 cell 重复 10 次几乎是同一条轨迹，把 300 runs 当独立样本做 χ² 是在给 p 值注水。任务指令未公开、网站规模未报告、无代码，复现无门；连 llms.txt、NLWeb 这些最直接的 agentic web 前作都没引，文献功课不及格。全文唯一值得留的数字是 token 效率——结构化数据省 18.7%–40.5% token，这对"网站侧优化有真金白银的推理成本收益"是个有用的数据点；作者在 Limitations 里自认 "proof of concept rather than full validation"，倒是诚实。
- **Rating**: `1` 💤 ，方向踩在 agentic web 风口上，但自建靶子 + 零 ablation + 不可复现，结论只剩"结构化数据对 agent 有用"这句业界共识——看一眼 token 数字即可，框架不必记。
