## 论文点评

### Agentic Abstention
- **Title**: Agentic Abstention: Do Agents Know When to Stop Instead of Act?
- **Source**: [arXiv](https://arxiv.org/abs/2606.28733)  **论文笔记**: [[2606-AgenticAbstention]]
- **核心**: 将 abstention 从 single-turn QA 扩展到 web / terminal / QA agent 的 sequential decision：agent 可以继续 ACT，也可以 ANSWER 或 ABSTAIN，关键是何时停止。构造 28K+ benchmark，显示多数系统及时停止能力很弱；CONVOLVE 用少量轨迹蒸馏 stopping rules，将 Llama-3.3-70B WebShop timely recall 从 26.7 提到 57.4。
- **锐评**: 这是 AFE 方向很值得读的一篇。它把“别再乱点/乱搜了”从经验抱怨变成可度量问题，比单纯提高 task success 更接近真实 agent 可靠性。短板是 benchmark 仍有构造痕迹，CONVOLVE 可能学到 benchmark-specific heuristic；但“stop/clarify/declare-unresolvable”必须成为 runtime action，这个结论很稳。
- **Rating**: 3 - Foundation。

### LUMOS
- **Title**: LUMOS: A Semantic Operating-System Layer for Accessibility-Grounded AI Agents
- **Source**: [arXiv](https://arxiv.org/abs/2606.30697)  **论文笔记**: [[2606-LUMOS]]
- **核心**: 把 Windows UI Automation、DOM 和 accessibility tree 转成 compact semantic blueprint，让 LLM 基于 stable element id、role、value、bounds 和 action affordance 选择 constrained visible action。主张 screenshot agent 不该默认从像素重建 OS 已知语义。
- **锐评**: 想法和 AFE 完全同频：non-oracle semantic affordance 可以降低 token、latency 和 coordinate uncertainty。但目前只是 short technical report，case study 停在 Notepad / Windows Search，作者也承认没有 benchmark result。它更像值得借鉴的 interface spec，而不是已验证方法。
- **Rating**: 2 - Frontier。
