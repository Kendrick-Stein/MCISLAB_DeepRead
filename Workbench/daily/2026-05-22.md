### AI for Auto-Research
- **Title**: AI for Auto-Research: Roadmap & User Guide
- **Institutes**: NUS, NTU, Zhejiang University, CUHK
- **Source**: [link](https://arxiv.org/abs/2605.18661)  📰 HF Daily ⬆️ 64   **📒 论文笔记**: [[2605-AIAutoResearch]]
- **核心**: 首个端到端 AI 科研全流程分析（Creation / Writing / Validation / Dissemination），揭示 $15 可生成论文但 frontier LLM 仍会捏造结果、漏关键错误、无法可靠判断 novelty。识别可靠辅助与不可靠自主的阶段依赖边界：结构化、检索驱动、工具中介的任务可靠，genuinely novel ideas / research-level experiments / scientific judgment 脆弱。提供 taxonomy、benchmark suite、tool inventory、cross-stage design principles 和 practitioner playbook。
- **锐评**: **这是 2026 年 AI 科研自动化的必读全景图**。$15 生成论文 vs. 主流会议接收标准的 gap 量化了"能做"和"做好"的鸿沟，比空喊"AI 要革新科研"的论文有价值一万倍。**阶段依赖边界的识别是核心贡献**——"结构化任务可靠、genuinely novel 脆弱"这个结论有大量实证支撑（April 2026 前的系统性调研），比单篇 AI Scientist 论文的 anecdotal evidence 可信得多。**但三个地方可以更深**：(1) Benchmark suite 只提了存在性，没给具体任务定义和 baseline 数字，可操作性打折扣；(2) "greater automation obscures failure modes" 这个观察很关键但展开不够——什么样的 human-in-the-loop 设计能在保持效率的同时暴露失败？(3) Cross-stage design principles 偏 high-level，缺少"如果要构建一个 AI 科研系统，第一步应该自动化哪个环节"的 actionable roadmap。**Practitioner playbook 是亮点**，但 project page 维护质量决定了这篇论文的长期价值——如果只是 arXiv 一发了事，那就浪费了这个框架的潜力。
- **Rating**: `4` 🔥🔥，首个全流程、实证驱动的 AI 科研能力边界分析，识别了可靠辅助 vs 不可靠自主的阶段依赖性，是理解 AI 科研自动化现状的必读文献

### CHI-Bench
- **Title**: CHI-Bench: Can AI Agents Automate End-to-End, Long-Horizon, Policy-Rich Healthcare Workflows?
- **Institutes**: Ohio State, CMU, Salesforce AI, UIUC, Penn State
- **Source**: [link](https://arxiv.org/abs/2605.16679)  📰 HF Daily ⬆️ 52   **📒 论文笔记**: [[2605-CHIBench]]
- **核心**: 首个医疗保险长程工作流 benchmark，跨 prior authorization / utilization management / care management 三域，每个任务需 agent 在 20 个医疗 app（87 MCP tools）中扮演多角色、执行多轮对话、遵循 1290+ 文档的 policy handbook。30 个 agent 配置中最佳仅 28.0% 任务成功率，strict pass@3 无一超 20%，单 session 执行全部任务成功率暴跌至 3.8%。
- **锐评**: **这是 2026 年最狠的 agent reality check**。28% 最佳成功率不是"还不错"，而是"七成任务根本做不了"，strict pass@3 <20% 说明就算给三次机会、挑最好的，五次里还有四次翻车。3.8% 单 session 成功率更是把"long-horizon agent 已解决"的幻觉打得粉碎——policy-dense + multi-role + irreversible 三重约束下，现有 agent 架构根本扛不住。**Benchmark 设计的三个硬核之处**：(1) Policy density 真实（1290+ 文档不是摆设，每步决策都要 grounded），(2) Multi-role composition 强制 agent 理解角色切换和 handoff protocol（不是单一视角的线性任务），(3) Multilateral interaction 要求 agent 主动发起多轮对话而非被动响应（peer review / patient outreach 都是双向博弈）。**但有两个遗憾**：(1) 只给了 best-of-30 的聚合数字，没按 harness / model / domain 三维分解 failure mode——到底是 harness 设计问题、模型 reasoning 能力不足、还是医疗 domain 特有的难点？(2) 87 MCP tools 的 action space 设计没细说，tool 粒度、error handling、state consistency 这些都会影响成功率，但论文没给 ablation。**最有价值的不是数字本身，而是暴露的三个系统性问题**：policy grounding 在长链推理中的 drift、multi-role context 的 interference、irreversible action 的 risk aversion。这三个问题不解决，agent 就永远困在"demo 好看、实战拉胯"的怪圈里。
- **Rating**: `4` 🔥🔥，首个 policy-dense + multi-role + irreversible 的真实工作流 benchmark，28% 成功率狠狠打脸"agent 已实用"幻觉，暴露的三大系统性问题（policy drift / role interference / risk aversion）是未来研究的关键方向

### Video2GUI
- **Title**: Video2GUI: Synthesizing Large-Scale Interaction Trajectories for Generalized GUI Agent Pretraining
- **Institutes**: Peking University
- **Source**: [link](https://arxiv.org/abs/2605.14747)  📰 HF Daily ⬆️ 143   **📒 论文笔记**: [[2605-Video2GUI]]
- **核心**: 从 5 亿 YouTube 视频元数据中用 coarse-to-fine filtering 自动挖掘 GUI 教程，提取 1270 万条交互轨迹（覆盖 1500+ 应用）构建 WildGUI 数据集。Topology-aware sampling + calibrated refinement 生成自然 multi-turn 轨迹（implicit intent 而非 over-specified instruction）。在 Qwen2.5-VL 和 Mimo-VL 上预训练后，BFCLv3 +15%、MCP-Atlas +8.6%、τ²-Bench / VitaBench +6%。
- **锐评**: **规模和自动化流程是真贡献，但数据质量的黑箱让人不安**。1270 万轨迹 + 1500 应用确实是目前最大的 GUI 数据集，coarse-to-fine filtering（metadata → video quality → GUI tutorial identification → trajectory extraction）的四阶段 pipeline 设计合理。**Topology-aware sampling 是亮点**——按 action graph 拓扑结构采样而非均匀采样，保证了轨迹的 diversity 和 naturalness，这比 VideoAgentTrek 的暴力抽取聪明。Calibrated refinement 生成 implicit intent query（"帮我做 X"而非"点击按钮 A 然后选择选项 B"）也符合真实用户交互模式。**但三个硬伤**：(1) **数据质量完全是黑箱**——false positive rate、噪声轨迹占比、grounding 错误率一概不提，5 亿视频筛到 1270 万轨迹的 funnel 每一步损失多少、为什么损失？不知道。(2) **应用分布极度倾斜但不承认**——1500 应用听着多，但肯定是少数热门 app（Chrome / Excel / Photoshop）占了大头，long-tail 应用可能只有个位数轨迹，论文完全不给分布统计。(3) **Grounding 鲁棒性未验证**——UI 元素在版本更新、动态布局、不同分辨率下会漂移，一次 misgrounding 就能让长任务崩盘，但论文连个跨版本 robustness 实验都没做。**数字上 BFCLv3 +15% 亮眼**，但其他 benchmark 只给了相对提升、不给绝对数字，典型的"报喜不报忧"。跟 85 环境的 baseline 比是 5 倍环境数，但性能提升只有 1.2-1.5 倍，说明数据规模的边际收益在递减。**如果数据集真开源且质量过关，对社区有巨大价值；但如果只是把脏活自动化了一遍然后堆个大数字，那就是用算力掩盖思考**。
- **Rating**: `3` 🔥，规模 + 自动化 pipeline + topology-aware sampling 是真贡献，但数据质量黑箱、应用分布倾斜未披露、grounding 鲁棒性未验证三大问题让人无法判断这 1270 万轨迹的真实价值

### OmniGUI
- **Title**: OmniGUI: Benchmarking GUI Agents in Omni-Modal Smartphone Environments
- **Institutes**: 未明确标注（arXiv preprint）
- **Source**: [link](https://arxiv.org/abs/2605.18758)  📰 HF Daily ⬆️ 16   **📒 论文笔记**: [[2605-OmniGUI]]
- **核心**: 首个 step-level omni-modal GUI benchmark，每个 action step 同时提供 image + video + audio 三模态输入。709 episodes / 2,579 steps 覆盖 29 app，按多模态依赖度分为 AV-Critical / AV-Supportive / AV-Present 三档。最强模型 Gemini 3.0 Pro 仅 63.6% step EM、33.4% episode SR。发现两大问题：(1) 51% Prejudice Rate——正确预测但未 grounded in retrieved cues，(2) Cross-modal interference——纯静态任务上提供完整多模态输入让 Gemini 2.5 Flash 性能下降 9.1%。
- **锐评**: **问题设定填补关键空白，但 Prejudice Gap 的发现是核心价值**。Step-level synchronous multimodal input 确实是现有 benchmark 的盲区——OSWorld / ScreenSpot 只用 screenshot，VideoWebArena 把 audio/video 当 pre-task context，都无法评估"此刻此秒"的多模态感知。**51% Prejudice Rate 是最狠的发现**——一半的"正确答案"不是因为模型真看懂了 audio/video，而是靠 language prior 猜对的，这个 Clever Hans 效应比 cross-modal interference 更致命。Holistic-Grounding Rate 仅 0-33.5% 说明模型几乎不会主动整合多模态 cues，而是优先依赖单一模态（通常是 text）。**但评测协议有硬伤**：(1) **Teacher-forcing 让数字失真**——每步给 ground-truth history，33.4% SR 是"理想条件"下的成绩，真实 autonomous rollout 时 cascading error 会让成功率更惨，但论文完全没评估 error recovery。(2) **数据规模偏小**——709 episodes 分到 29 app 后每个平均 24 episodes，分到 7 failure-mode categories 后统计显著性存疑。(3) **Failure analysis 太浅**——只给了 Prejudice / Confabulation / Integration-failure / Holistic-grounding 四个 rate，没分析"哪类 audio cue 最容易被忽略""cross-modal interference 的具体 pattern 是什么"。**方法论贡献清晰**：Prejudice Rate / Confabulation Rate / Integration-failure Rate / Holistic-grounding Rate 四个 sample-level metric 可以迁移到其他 multimodal benchmark，这比单纯报 accuracy 有诊断价值。
- **Rating**: `3` 🔥，首个 step-level omni-modal GUI benchmark + 51% Prejudice Gap 的发现暴露了 MLLM 的 Clever Hans 效应，但 teacher-forcing 协议让评测结果与真实部署严重脱节，数据规模偏小且 failure analysis 不够深入

### Process Rewards with Learned Reliability
- **Title**: Process Rewards with Learned Reliability
- **Institutes**: 未披露（arXiv 页面无机构信息）
- **Source**: [link](https://arxiv.org/abs/2605.15529)  📰 HF Daily ⬆️ 52   **📒 论文笔记**: [[2605-BetaPRM]]
- **核心**: 现有 PRM 只输出单一 reward score，downstream 方法必须把不完美的 step-level 预测当可靠信号用。BetaPRM 用 Beta 分布同时预测 step-level success probability 和该预测的 reliability，通过 Beta-Binomial likelihood 从 Monte Carlo continuations 学习 belief。基于 learned reliability 提出 Adaptive Computation Allocation (ACA)：高 reward + 高 reliability 时提前停止，低 reliability 时追加计算。在四个 backbone、四个 reasoning benchmark 上，ACA 在保持或提升 accuracy 的同时减少 token 使用 up to 33.57%。
- **锐评**: **核心 insight 扎实——"PRM 应该知道自己不知道"这个需求一直存在但没人系统性解决**。Beta-Binomial 建模比直接回归 success ratio 优雅（后者把有限样本的随机性当真实信号），learned reliability 让 downstream 方法能区分"模型有把握的高分"和"模型瞎猜的高分"。**ACA 是 reliability 信号的最佳应用 demo**——在 Best-of-N 场景下，高 reliability 时提前停止避免浪费、低 reliability 时追加计算提升质量，accuracy-token tradeoff 优于 fixed-budget baseline。**但三个地方可以更深**：(1) **Reliability calibration 没验证**——Beta 分布的 variance 真的反映了预测不确定性吗？需要 calibration plot（predicted uncertainty vs. empirical error）证明，否则"learned reliability"可能只是 overconfident 的另一种形式。(2) **ACA 的 threshold 选择是启发式**——什么时候"reliability 够高"可以停？什么时候"reliability 太低"需要追加？论文没给 principled 的 threshold selection 方法，ablation 也没探索 threshold 敏感性。(3) **只在 Best-of-N 上验证了 ACA，其他 PRM 应用场景（如 MCTS、RL training）的价值未探索**——reliability 信号在 exploration-exploitation tradeoff 中能起什么作用？在 RL reward shaping 中如何用？这些都是自然的 follow-up 但论文没提。**数字上 33.57% token 节省很亮眼**，但 ablation 显示 ACA 的增益主要来自"提前停止高 reliability 的好解"而非"追加计算低 reliability 的差解"（Table 4 中 adaptive budget 的 improvement 不如 early stopping 明显），说明 ACA 更像是"efficiency trick"而非"quality improvement"。
- **Rating**: `3` 🔥，Beta-Binomial 建模 step-level uncertainty 是扎实贡献，ACA 证明了 reliability 信号的实用价值（33.57% token 节省），但 reliability calibration 未验证、threshold 选择启发式、应用场景局限在 Best-of-N 三个问题限制了方法的深度

### When Vision Speaks for Sound
- **Title**: When Vision Speaks for Sound
- **Institutes**: USC, UCLA
- **Source**: [link](https://arxiv.org/abs/2605.16403)  📰 HF Daily ⬆️ 147   **📒 论文笔记**: [[2605-WhenVisionSpeaksForSound]]
- **核心**: 揭示 video-capable MLLM 的 audio-visual Clever Hans 效应——模型依赖视觉 cues 推断或幻觉 acoustic 信息，而非验证 audio stream。提出 Thud 框架，用三种 counterfactual audio edits（Shift 测时序同步、Mute 测声音存在、Swap 测 audio-visual 一致性）系统性诊断。发现 SOTA 开源和闭源模型（Google、OpenAI）都存在此问题。提出 two-stage alignment recipe：intervention-derived preference pairs 教 audio verification + event-level general video preferences 防止 over-specialization，10K 样本让平均性能在三个 intervention 维度上提升 28 个百分点。
- **锐评**: **这是 2026 年多模态理解可信度研究的标杆**。Clever Hans 效应的命名精准——模型"看起来懂 audio"但实际只是在 exploit visual-acoustic correlation，Thud 的三种 intervention（Shift / Mute / Swap）设计优雅且互补（时序 / 存在 / 一致性三个维度正交）。**最有价值的不是发现问题本身（audio grounding 弱早有人怀疑），而是提供了 systematic diagnosis framework + scalable fix**。Intervention-derived preference pairs 是亮点——不需要人工标注"哪些 audio cue 重要"，直接从 counterfactual edits 中自动生成 preference data，这个 pipeline 可以迁移到其他 modality alignment 问题（如 tactile / depth）。**但三个地方可以更深**：(1) **10K 样本的 intervention 分布没说清楚**——Shift / Mute / Swap 各占多少？不同 intervention 的 preference signal 强度一样吗？需要 ablation 证明三种 intervention 的独立价值。(2) **Event-level general video preferences 的作用模糊**——说是"防止 over-specialization"，但 Table 中 w/o general preferences 的 ablation 缺失，无法量化这个 regularization 的必要性。(3) **只在 synthetic corruption 上验证了鲁棒性，real-world audio-visual misalignment（如网络视频的 audio desync、dubbed content）的泛化性未测**。**28 个百分点提升很炸裂**，但 baseline 是未经 audio alignment 训练的原始模型，跟专门做 audio-visual learning 的方法（如 ImageBind、LanguageBind）比如何？论文没给。
- **Rating**: `3` 🔥，系统性诊断 audio-visual Clever Hans 效应 + intervention-derived preference pairs 提供了 scalable alignment recipe，但 intervention 分布、general preferences 的作用、real-world misalignment 泛化性三个问题需要更深入探索

### CutVerse
- **Title**: CutVerse: A Compositional GUI Agents Benchmark for Media Post-Production Editing
- **Institutes**: 未披露（arXiv 页面无 affiliation 信息）
- **Source**: [link](https://arxiv.org/abs/2605.19484)  📰 HF Daily ⬆️ 20   **📒 论文笔记**: [[2605-CutVerse]]
- **核心**: 首个专业媒体后期制作 GUI agent benchmark，覆盖 Premiere Pro / Photoshop / After Effects 等 7 软件的 186 任务。VM 环境 + 纯视觉反馈 + 无特权 API 强制 agent 面对与人类相同的认知约束。Milestone 分解评估发现最佳 agent（Claude）仅 45.1% 任务成功率，程序性操作（启动 / 导出）100% 但核心编辑任务崩盘，音频编辑 milestone SR 92.9% 但任务 SR 仅 33.3%，暴露长时域组合失败。

### Active Learners as PRP Rerankers
- **Title**: Active Learners as Efficient PRP Rerankers
- **Institutes**: Universidad de Buenos Aires, Microsoft
- **Source**: [link](https://arxiv.org/abs/2605.14236)  📰 HF Daily ⬆️ 96   **📒 论文笔记**: [[2605-ActiveLearnersAsPRPRerankers]]
- **核心**: 将 Pairwise Ranking Prompting (PRP) 重排序重构为 active learning from noisy pairwise comparisons。指出 sorting 假设（transitive / full permutation recovery）与 PRP 现实（noisy / order-sensitive / intransitive judgments）不匹配，truncated sorting 无法产生可靠 top-K。提出 Pion，用 active rankers 替代 sorting，引入 randomized-direction oracle（单次 LLM call per pair，position bias 转为 zero-mean noise）。在 call-constrained 场景下改进 NDCG@10 per call。
- **锐评**: **问题重构有洞察——PRP 用 sorting 是 category error，noisy pairwise comparisons 应该用 active learning 处理**。Sorting 追求 full permutation 但 PRP 只需要 top-K，这个 mismatch 导致 call budget 浪费在不重要的 pair 上。**Randomized-direction oracle 是优雅设计**——不需要 bidirectional call（省一半成本），通过随机化把 systematic position bias 转为 zero-mean noise，unbiased aggregate ranking 不需要额外代价。**但三个地方不够深**：(1) **Active ranker 的选择是黑箱**——论文说"active rankers 是 drop-in replacement"，但具体用了哪个 active learning algorithm（UCB / Thompson Sampling / 其他）？不同 algorithm 的 exploration-exploitation tradeoff 如何？完全没说。(2) **只在 NDCG@10 上验证**——PRP 的其他应用场景（如 Best-of-N selection、preference learning）的泛化性未测，而且 NDCG@10 只看 top-10 排序，tail 部分的质量如何（这对某些应用很重要）？不知道。(3) **Noise model 的假设未验证**——randomized-direction 把 position bias 转为 zero-mean noise 的前提是"正反两个方向的 bias 对称"，但 LLM 的 position bias 可能不对称（如"总是偏好第一个选项"），这种情况下 randomization 无法消除 bias，但论文没讨论。**NDCG@10 per call 的改进是实用贡献**，但缺少与其他 noise-robust ranking 方法（如 Thurstone-Mosteller model、Bradley-Terry with uncertainty）的对比，无法判断 active learning 的独特价值在哪。
- **Rating**: `3` 🔥，PRP 重构为 active learning 有洞察，randomized-direction oracle 优雅且省成本，但 active ranker 选择黑箱、应用场景局限 NDCG@10、noise model 假设未验证三个问题限制了方法的深度

- **Institutes**: Tsinghua University, Renmin University

- **核心**: 现有 RLVR 的 policy-gradient update 隐式充当 token-gradient vectors 上的线性判别器，但 centroid construction（advantage-weighted averaging）被高频 formatting tokens 主导，稀疏但判别性强的方向被稀释。DelTA 提出 discriminative token credit assignment，估计 token coefficients 来放大 side-specific directions、压制 shared / weakly discriminative ones，让 effective side-wise centroids 更 contrastive。在 7 个 math benchmark 上，Qwen3-8B-Base 和 Qwen3-14B-Base 分别超最强 same-scale baseline 平均 3.26 和 2.62 点，code generation / 不同 backbone / out-of-domain 评估进一步验证泛化性。

- **Rating**: `3` 🔥，discriminator view 的理论分析深刻，discriminative token credit assignment 方法合理，7 benchmark 一致性增益 + 泛化验证扎实，但计算成本未量化、缺少与更强 baseline 对比、interpretability 不足三个问题限制了方法的完整性

### OSCAR
- **Title**: OSCAR: Offline Spectral Covariance-Aware Rotation for 2-bit KV Cache Quantization
- **Institutes**: UIUC, Penn State, AWS AI
- **Source**: [link](https://arxiv.org/abs/2605.17757)  📰 HF Daily ⬆️ 62   **📒 论文笔记**: [[2605-OSCAR]]

- **Rating**: `3` 🔥，首个 text-space optimizer for agent skills，validation-gated acceptance + bounded edits 让 skill evolution 有纪律性，52 cells 全部 best or tied + transfer 实验证明方法鲁棒，但 optimizer training cost 未量化、validation score 设计黑箱、任务泛化性未测三个问题限制完整性

### RTPurbo

- **Institutes**: Nanjing University
- **Source**: [link](https://arxiv.org/abs/2605.16928)  📰 HF Daily ⬆️ 87   **📒 论文笔记**: [[2605-RTPurbo]]
- **核心**: Long-context inference 受限于 full attention 的 quadratic cost。现有 efficient alternatives 要么依赖 native sparse training 要么依赖 heuristic token eviction，造成 efficiency / training cost / accuracy 的 undesirable tradeoff。RTPurbo 发现 full-attention LLMs 已经 intrinsically sparse，可以用 minimal adaptation 转为 highly sparse models。三个观察：(1) 只有小部分 attention heads 真正需要 full long-context processing；(2) Long-range retrieval 由 low-dimensional subspace 主导，16-dim indexer 就能高效检索 relevant tokens；(3) Useful token budget 是 query-dependent，dynamic top-p selection 比 fixed top-k 更合适。基于此提出 RTPurbo：只对 retrieval heads 保留 full KV cache，引入 lightweight token indexer for sparse attention。Exploiting intrinsic sparsity，RTPurbo 仅需 few hundred training steps 就能 sparsify。在 long-context benchmarks 和 reasoning tasks 上，RTPurbo 保持 near-lossless accuracy，同时在 1M context 下实现 up to 9.36x prefill speedup，约 2.01x decode speedup。

- **Rating**: `2` 👀，intrinsic sparsity 的发现有价值，few hundred training steps 的 adaptation cost 低，9.36x prefill speedup 炸裂，但 indexer dimensionality 启发式、任务泛化性未测、top-p threshold 黑箱三个问题限制完整性

- **核心**: 尽管 ASR 和 large audio-language models 快速进展，real-world environments 的 robust recognition 受限于"acoustic robustness bottleneck"——models 在 severe、compositional distortions 下 lose acoustic grounding 并产生 omissions / hallucinations。Mega-ASR 是 unified ASR-in-the-wild framework，combines scalable compound-data construction with progressive acoustic-to-semantic optimization。引入 Voices-in-the-Wild-2M，覆盖 7 classic acoustic phenomena 和 54 physically plausible compound scenarios，训练 Mega-ASR with Acoustic-to-Semantic Progressive Supervised Fine-Tuning 和 Dual-Granularity WER-Gated Policy Optimization。在 adverse-condition ASR benchmarks 上显著优于 prior SOTA（VOiCES R4-B-F: 45.69% vs 54.01%，NOIZEUS Sta-0: 21.49% vs 29.34%）。在 complex compositional acoustic scenarios 上，Mega-ASR 相比 strong baselines 实现 over 30% relative WER reduction。
- **锐评**: **Acoustic robustness bottleneck 的识别精准——severe distortions 下 models lose acoustic grounding 是 ASR 部署的核心痛点**。Voices-in-the-Wild-2M（7 phenomena + 54 compound scenarios）的 physically plausible simulation 比 naive augmentation 更接近 real-world。**Progressive acoustic-to-semantic optimization（先 acoustic grounding 再 semantic understanding）+ Dual-Granularity WER-Gated Policy Optimization 的设计合理**。**VOiCES 45.69% vs 54.01% + NOIZEUS 21.49% vs 29.34% 是显著改进**，而且 30% relative WER reduction on compositional scenarios 证明方法对 complex distortions 鲁棒。**但三个地方不够深**：(1) **Voices-in-the-Wild-2M 的 simulation fidelity 没验证**——physically plausible 不等于 realistic，simulation 和 real-world recording 的 distribution gap 多大？需要 real-world validation。(2) **只在 adverse-condition benchmarks 上验证**——clean speech 的性能如何？Progressive optimization 会不会牺牲 clean-speech accuracy？这个 tradeoff 对 deployment 很重要但论文没给。(3) **Computational cost 没量化**——Dual-Granularity optimization 和 compound-data training 增加了多少训练时间和 inference latency？对 real-time ASR 是否可接受？
- **Rating**: `2` 👀，acoustic robustness bottleneck 识别精准，Voices-in-the-Wild-2M 设计合理，progressive optimization 有效，VOiCES 和 NOIZEUS 显著改进，但 simulation fidelity 未验证、clean-speech tradeoff 未测、computational cost 未量化三个问题限制完整性

### Anti-Self-Distillation
- **Title**: Anti-Self-Distillation for Reasoning RL via Pointwise Mutual Information
- **Institutes**: 未披露（arXiv 页面无机构信息）
- **Source**: [link](https://arxiv.org/abs/2605.11609)  📰 HF Daily ⬆️ 190   **📒 论文笔记**: [[2605-AntiSelfDistillation]]
- **核心**: On-policy self-distillation（student 被 pull toward copy of itself conditioned on privileged context）在 math reasoning 上增益不一致。Pointwise mutual information analysis 追溯失败到 privileged context 本身：inflates teacher confidence on tokens already implied by solution（structural connectives / verifiable claims），deflates on deliberation tokens（"Wait" / "Let" / "Maybe"）that drive multi-step search。提出 Anti-Self-Distillation (AntiSD)，ascends divergence between student and teacher rather than descending it，reverses per-token sign 并 yields naturally bounded advantage in one step。Entropy-triggered gate 在 teacher entropy collapses 时 disable term，completing drop-in replacement for default self-distillation。跨 5 models（4B to 30B）on math reasoning benchmarks，AntiSD 达 GRPO baseline accuracy in 2 to 10× 更少 training steps，improves final accuracy by up to 11.5 points。
- **锐评**: **PMI analysis 是核心贡献——揭示 privileged context 本身是问题根源（inflates structural tokens / deflates deliberation tokens），这个 insight 比单纯提出 AntiSD 更有价值**。Ascend divergence rather than descend 是 counterintuitive 但 well-motivated 的设计，entropy-triggered gate 让方法 self-adaptive。**2 to 10× 更少 training steps + up to 11.5 points accuracy improvement 是显著增益**。**但三个地方让这篇论文的价值打折扣**：(1) **Baseline 选择有问题**——只跟 GRPO 比，没跟其他 self-distillation variants（如 STaR / ReST）比，无法判断 AntiSD 的独特价值。(2) **只在 math reasoning 上验证**——其他 reasoning 任务（code / logic / commonsense）的泛化性未测，PMI analysis 揭示的问题可能是 math-specific 的（因为 math 有 strong structural patterns）。(3) **Entropy-triggered gate 的 threshold 选择是启发式**——什么时候 teacher entropy "collapses"？Threshold 怎么定？Ablation 没探索 threshold 敏感性。整体来说，PMI analysis 有 insight，但 method 的 novelty 和 generality 都有限。
- **Rating**: `1` 💤，PMI analysis 有 insight（privileged context 是问题根源），AntiSD 设计 counterintuitive 但 motivated，2-10× 更少 steps + 11.5 points 增益显著，但 baseline 弱（只跟 GRPO 比）、任务泛化性未测、gate threshold 启发式三个问题让价值打折扣
