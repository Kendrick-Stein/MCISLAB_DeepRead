## 论文点评

### Molmo2
- **Title**: Molmo2: Open Weights and Data for Vision-Language Models with Video Understanding and Grounding
- **Institutes**: Allen Institute for AI (Ai2), University of Washington
- **Source**: [link](https://openaccess.thecvf.com/content/CVPR2026/html/Clark_Molmo2_Open_Weights_and_Data_for_Vision-Language_Models_with_Video_CVPR_2026_paper.html)  📄 CVPR 2026   **📒 论文笔记**: [[2606-Molmo2]]
- **核心**: Ai2 的 Molmo 续作，用 9 个全新自建数据集（human+自家模型协作，明确零 proprietary VLM 蒸馏）+ 三阶段训练 recipe，做出 open-weight/open-data 类里 SoTA 的视频/图像 VLM。真正的记忆点不是理解能力，而是把 image pointing 的坐标范式扩到视频时空维度（video pointing + tracking），用统一的纯文本坐标格式（归一化 x,y + timestamp + object ID）接进 LLM。video counting、tracking 显著超 Qwen3-VL，部分 pointing 任务甚至压过 Gemini 3 Pro。
- **锐评**: 这是一篇「诚实的工程论文」，而工程做得够扎实就有价值。最大的贡献不在某个 SoTA 数字，而在于给开源社区一块**没被 GPT/Gemini 蒸汁污染**的干净地基——这句话看似口号，但配上全开的 data+weights+code+recipe 才有分量，多数号称 open 的 VLM 都在偷偷蒸馏。真正的技术亮点是把 grounding 从 2D 拉到时空：video tracking 56.2 vs 41.1 J&F 这种量级的差距不是 tuning 能刷出来的，是范式带来的。但硬伤也很清楚：(1) 消融自己承认联合训练有 tradeoff——Point-Only/Tracking-Only 专用模型在各自任务上更强，VideoPoint 即便上采样仍更难学，「一个模型全包」是花了代价的，别把 grounding 当白给；(2) tracking 的 J&F 是靠外挂 SAM-2 把 point 转 mask 算出来的，端到端产物仍是 point 不是 mask，跟专用分割模型比 J&F 有点田忌赛马；(3) 「超 Gemini 3 Pro」的 pointing 数字，作者自己都说 grounding 评测的帧数/prompt setup 没全公开——诚实值得加分，但也意味着这个对比是 setup-dependent 的，别当铁证；(4) 10 分钟以上 ultra-long video 落后于最佳 open-weight，而这恰是长录像/监控这类真实场景的命门，归因于「开源长视频数据+算力不够」——理由成立，但短板就是短板。总体是真·可复现的稀缺贡献，不是刷榜灌水。
- **Rating**: `3` 🔥 ，fully-open + 无蒸馏 + video grounding 填空白，大概率成为开源视频理解/定位的新基线，值得作为地基读。

### Vera: 用"环境状态证据"给 agent 安全测试正名
- **Title**: Safety Testing LLM Agents at Scale: From Risk Discovery to Evidence-Grounded Verification
- **Institutes**: AntGroup, Zhejiang University, Fudan University, Alibaba Group, Hunan Institute of Advanced Technology, Deakin University, Tsinghua University
- **Source**: [link](https://arxiv.org/abs/2607.01793)  📰 HF Daily ⬆️ 7   **📒 论文笔记**: [[2607-VeraSafetyTesting]]
- **核心**: Vera 是一套自动化、可扩展的 LLM agent 安全测试流水线：先从 ~800 篇论文自动构建"风险×攻击×环境"三层 taxonomy（124/77/30），再组合生成 1600 个带确定性 Python verifier 的可执行 safety case，最后在 12 容器 Docker 沙箱里让一个自适应控制 agent（≤10 轮、可篡改工具返回）去攻击目标。最关键的设计是 evidence-grounded verification——判定"是否真的违规"用环境状态优先、工具记录其次、文本响应垫底的非对称层级（state⊳tool⊳resp），失败直接判 0、成功必须对照环境证据确认，以此消除 false positive。在 Claude Code / Codex / Hermes / OpenClaw 上多通道攻击成功率 93.9%。
- **锐评**: 问题 formulation 是真好——把"不安全请求/尝试动作/意图陈述 ≠ 已实现违规"当成靶心，用可执行 verifier + 环境状态接地来度量后果，这是相对 R-Judge 和 prompt 级 refusal 评测的实质进步，不是又一个刷榜 benchmark；几个数字也有信息量：multi-channel 对 Claude Code 反而 −2.1pp（暴露其有稳健工具结果过滤），而 Codex/OpenClaw 靠工具通道注入涨 4~6pp，一刀切开了"只防用户消息、不防工具通道"的行业通病；benign 70.5% 被拿来当测试用例质量的隐式指标也很诚实。但硬伤同样明显：**93.9% 这个 headline 被 setup 放大**——攻击者是多轮自适应、最多 10 轮、还能改工具返回的控制 agent，ASR 高到 90%+ 更像"任务难度/攻击预算标定偏易"而非目标脆弱性的可比刻度，横向没法拿这个数字比谁更安全；1600 个 LLM/程序生成的 verifier"遇报错就重新生成"却没给人工 ground-truth 的召回/精度，验证器自身正确性这条信任链没被独立审计；OpenClaw 低分同时归因于"策略保守"（更安全）和"基础设施故障"（评测噪声）两个相反方向却不拆开，58% 的 benign ESR 说明结果里混了大量执行失败；guard-model 章节"在 Vera 上微调再在 Vera-Bench 上 +30pp F1"属循环论证，真正有价值的 R-Judge 61.7% 只报了单一 accuracy。跟已有 injection/red-teaming 工作的本质区别在于把攻击面从屏幕/fine-print 扩到 MCP 工具返回通道、并坚持以执行后果判定——这套 verification 思路值得后续借鉴，但 90%+ ASR 应读作"当前 coding/tool agent 在工具通道注入下普遍脆弱"的定性信号。
- **Rating**: `2` 👀 ，evidence-grounded verification 的问题定义和工程完成度值得追，但 90%+ ASR 是预算堆出来的定性结论、非可比刻度，verifier 正确性与框架归因两处未审计。

### Ego2Web：把"看懂现实"缝进"操作网页"
- **Title**: Ego2Web: A Web Agent Benchmark Grounded in Egocentric Videos
- **Institutes**: Google DeepMind, UNC Chapel Hill
- **Source**: [link](https://openaccess.thecvf.com/content/CVPR2026/html/Yu_Ego2Web_A_Web_Agent_Benchmark_Grounded_in_Egocentric_Videos_CVPR_2026_paper.html)  📄 CVPR 2026   **📒 论文笔记**: [[2606-Ego2Web]]
- **核心**: 提出一个 500 样本的 benchmark，强制 web agent 先从第一人称视频里定位任务线索（拿起的零食、车标、动作），再去 Amazon/YouTube/Maps 等真实网站执行操作，把 web agent 从"纯数字界面执行器"逼成"物理感知 + 数字行动"的串联任务。配套 Ego2WebJudge 把 egocentric visual evidence 塞进 LLM-as-a-Judge。最强 baseline（Browser-Use + Gemini-3-Flash）人工 SR 也只有 58.6%，论文据此宣称 visually grounded web execution 还有大空间。
- **锐评**: 这篇最有说服力的不是 leaderboard，而是那组 visual input ablation：无视觉 4.4% → detailed caption 23.6% → raw video 48.2%，Knowledge Lookup 从 39.1% 直接跳到 75.0%。这才是 benchmark 立得住的证据——它真的在考视觉 grounding，text caption 替代不了 temporal / fine-grained perception，任务没退化成又一个网页导航测试。Failure analysis 也诚实：54% 的失败是 Object Misidentification（36%）+ Temporal/Action 误解（18%），瓶颈在上游感知而非浏览器操作，这个判断对 GUI agent 方向比多刷一个 SOTA 有用。但硬伤同样明显：leaderboard 是被污染的——Claude/GPT-5.4 在 computer-use 模式下读不了 raw video 只能吃 caption，Gemini 能吃 dense video，于是"Gemini 最强"里混了模态接口优势和 agent 本身能力，跨 agent 对比根本不是同一条起跑线，作者自己也承认却照样并排排名。其次 benchmark 本体是 Qwen3-VL 生成 caption → GPT-5 生成 instruction → 人工验收，这条 LLM 造题链的 task bias、annotator agreement、单样本成本、网站长尾分布主文一律没量化，500 样本撑不起"覆盖真实物理-数字长尾"的暗示。再者 live website 评测听着真实，CAPTCHA / auth / session error 已经进了失败因素，却没有系统量化 website drift 带来的方差——想当长期 leaderboard 或训练 reward 就得先解决可复现性。Ego2WebJudge 84.0% Avg AR 也别包装成"自动评估解决了"，16% disagreement 还在。
- **Rating**: `2` 👀 ，problem formulation（目标来源绑定到 egocentric video）和 visual-input ablation 都漂亮，值得 GUI/web agent 方向追；但 leaderboard 模态混淆 + LLM 造题 + 500 样本让它够不上必读的奠基级。

### MergeVLA：把"可合并性"当架构属性来设计的 VLA
- **Title**: MergeVLA: Cross-Skill Model Merging Toward a Generalist Vision-Language-Action Agent
- **Institutes**: UQMM Lab, The University of Queensland
- **Source**: [link](https://openaccess.thecvf.com/content/CVPR2026/html/Fu_MergeVLA_Cross-Skill_Model_Merging_Toward_a_Generalist_Vision-Language-Action_Agent_CVPR_2026_paper.html)  📄 CVPR 2026   **📒 论文笔记**: [[2606-MergeVLA]]
- **核心**: 论文先做诊断：把多个单任务 VLA expert 直接 model merging 会掉到近 0 成功率（OpenVLA 全参 TA 合并 0.0%，VLA-Adapter TA/TA+mask 也 0.0%）。它把失败拆成两个机制——VLM 的 LoRA update 在不同任务上占用互斥 channel（4 个 LIBERO 任务 selfish ratio 约 75%），以及 action expert 里 from-scratch 训练的 self-attention 把 task bias 沿层扩散到深层。对症下药：task-specific mask 保留合并后有用的 LoRA 参数、去掉 self-attention 只留 cross-attention 的 action expert、深层保留少量 unmerged expert head、再加一个 training-free test-time router。结果 LIBERO 合并后 TIES 90.2%、LIBERO-Plus OOD 合并 62.5%（对照 VLA-Adapter 合并只有 10.8%）。
- **锐评**: 诊断部分是真功夫，比大多数"我又刷了个 VLA benchmark"的论文有信息量得多——把 merging 失败定位到 LoRA channel 互斥 + self-attention 扩散，且用 selfish ratio 75% 和逐层参数距离爆炸给了实证 grounding，这是能改变 mental model 的东西。但标题里的"model merging / generalist agent"有明显话术成分：最终产物根本不是一个无条件单一权重，而是共享主干 + 每任务 mask + 每任务 expert head + 一个在 t=0 把每个 masked VLM variant 都跑一遍来选路的 router。这本质是 training-free routed MoE，只不过 backbone 大部分权重共享——"merging"是包装，"routing"是里子，overhead 随任务数 M 线性增长这点论文自己也承认了。硬伤在鲁棒性证据的选择性：RoboTwin 跨 embodiment + 跨 task 时只留 final block 的话 HANDOVER BLOCK 直接 0.0%，必须加深到 H(L-2→L) 才救回 70.7%，说明这套 routing 在真正困难的 action-space 冲突下很脆；而 router 的 value-vs-key ablation 里 Object 任务在 Only-K 和 K&V 下都是 0.0%，只有 Only-V 才 89.7%——设计判断虽被数据支持，但也暴露 router 对子空间选择极度敏感、离鲁棒还很远。最没底的是 real-world：SO101 只在摘要甩一个 90.0% 总成功率，主文连任务级拆分都没有，failure taxonomy 也缺席，真机部分基本无法审。跟已有工作的本质区别是：它不追更强的 merging algorithm（TA/TIES/WUDI 换着用差异很小，89.7%~90.2%），而是改架构让 specialization 局部化——这个 framing 是对的，但也正因此，"合并算法"在这篇里几乎不是矛盾的主变量。
- **Rating**: `2` 👀 ，诊断扎实、framing 诚实，但"merging"实为轻量 routed specialization 且跨 embodiment/真机证据偏薄，属值得追的前沿而非奠基。

### RynnWorld-Teleop：用生成式机器人做"数字遥操作"采数据
- **Title**: RynnWorld-Teleop: An Action-Conditioned World Model for Digital Teleoperation
- **Institutes**: DAMO Academy, Alibaba Group
- **Source**: [link](http://arxiv.org/abs/2607.06558)  📄 arXiv   **📒 论文笔记**: [[2607-RynnWorldTeleop]]
- **核心**: 把机器人遥操作数据采集里的"真机"换成生成式 world model——操作者的 21-joint hand-pose 流经 depth-aware 骨架渲染，驱动一个 Wan-I2V DiT 实时合成机器人 egocentric 视频。关键工程点是 distribution-aligned patch embedding fusion（把 control latent 归一化到视频 latent 分布再零初始化小系数相加）和 causal 蒸馏（KV cache + causal mask），把双向模型压到 40+ FPS。用 human egocentric 数据（VITRA+EgoDex）预训练、1,800 条真机 demo 域适配。合成数据训练的 π₀ 能零样本迁移真机（Block Pushing 82.86%），作为增强数据把 π₀.₅ 的 Lid Placement 从 42.86% 拉到 62.86%。
- **锐评**: 想法确实好看——world model 当 data engine + 实时闭环反馈，40 FPS 的 action-conditioned 生成对比同类 2–10 Hz 是硬本事，两个 ablation 也干净（additive vs concat FVD 585 vs 1191；去掉 human 预训练 FVD 585→2598 且 object permanence 直接崩，effector/apple 消失）。但三处站不住：(1) **"替代真实机器人"是标题党**——Stage 2 仍吃 1,800 条真机 MoCap 数据，且作者自认跨 embodiment 要 per-platform fine-tuning，本质是窄任务分布内的数据放大器，不是机器人替代品。(2) **headline 是两个模型拼的**——最亮的质量（FVD 550）来自 2.8 FPS 双向版，最亮的速度（40 FPS）来自 FVD 1226、比 SFT 差 2.2× 的 causal 版；操作者真正用的是后者，"高质量又实时"从来不同时成立。(3) **n=35 下大半提升在噪声里**——每 trial 值 2.86%，Dual Picking 94.29→97.14 就是 1 条 trial，Block Pushing 100→97.14 反而倒退 1 条；四任务里唯一稳健的信号是 Lid Placement 增强 +7 trials，而它恰好是绝对成功率最低（~63%）的精细任务——说明合成数据只在 policy 数据最饥饿处见效，精细操作本身仍没解决。t-SNE 分布"高度重合"的自证也偏软，真机 policy 才是唯一硬指标。
- **Rating**: `2` 👀 ，扎实的 world-model-as-data-engine 工程节点、实时性有真价值，值得追踪；但单 embodiment / 4 任务 / 35 trials 的评测撑不起"取代真机采数"的普适 claim，离奠基还远。

### BRAID：给统一多模态模型的 RL 补上图像那半条梯度
- **Title**: Bridging Interleaved Multi-Modal Reasoning as a Unified Decision Process
- **Institutes**: Nanjing University, Tencent Youtu Lab, Shanghai AI Laboratory, Tsinghua University, Zhejiang University, University of Washington, CUHK, ANU
- **Source**: [link](https://arxiv.org/abs/2607.03748)  📰 HF Daily ⬆️ 5   **📒 论文笔记**: [[2607-BRAID]]
- **核心**: 现有 UMM 的 RL 只训文本步骤、把图像生成降级为 supervised surrogate，policy gradient 传不到图像分支。BRAID 把交错「文-图-文」推理建成两层 MDP，算一个 trajectory-level advantage，同时喂给文本（GRPO clipped）和图像去噪路径（转成 soft reward 塞进 DiffusionNFT loss），让 RL 首次贯穿异构模态；再用 VLM judge（GPT-5.2）给中间图像打四维分做 dense turn-level reward。BAGEL-7B 上 7 个 benchmark 平均 +5.73，65.19 反超 GPT-4o 的 62.46，V*Bench +10.76、SAT +14.00。
- **锐评**: 立论找得准——「图像分支不吃 policy gradient」这个割裂点是真痛点，两层 MDP 让 advantage 一致地流进 diffusion denoising 是 conceptually 干净的补法，而且 ablation 讲了真话：去掉图像 RL（65.19→62.10）比去掉 VLM judge reward（→62.68）掉得更狠，主收益确实来自「让图像也可微分优化」而非那套花哨的四维 process reward，claim 与证据自洽，这点比多数灌水强。但硬伤同样明显：其一，「7B 反超 GPT-4o」是被 process reward 用 GPT-5.2 当 judge 撑起来的——训练信号本身来自一个比 GPT-4o 更强的闭源模型，这个 headline 数字要打对折读。其二，CV-Bench 3D −1.24 是七项里唯一退步，叠加 CV-Bench 2D 仅 +2.73，暴露收益偏向「找细节/放大 ROI」而非真几何空间推理——和标题里「spatial reasoning」的招牌名不副实。其三，最该打的直接对手「text-only RL 的 UMM」没做成对齐训练强度的独立 baseline，只用 ablation 顶替。其四，全部结论压在 BAGEL-7B 单 backbone、120 steps、固定 interleaving pattern 上，scaling 与泛化一概没答。方向对，执行到位，但仍是 proof-of-concept，不是能照搬的配方。
- **Rating**: `2` 👀 ，把 RL 打通到图像分支的 formulation 有真价值、ablation 诚实，值得追；但 judge 依赖更强闭源模型 + 3D 退步 + 单 backbone 让它够不上奠基级。
