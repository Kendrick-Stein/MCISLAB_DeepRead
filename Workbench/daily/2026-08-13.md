### Agent Skills Can Be Harmful
- **Title**: Agent Skills Can Be Harmful: An Empirical Study of Skill-Induced Failures in LLM Agents
- **Institutes**: Huazhong University of Science and Technology, Microsoft Research, University of Illinois Urbana-Champaign
- **Source**: [link](https://arxiv.org/abs/2608.11888)  📄 arXiv   **📒 论文笔记**: [[2608-HarmfulSkills]]
- **核心**: 用 differential analysis 把"skill 有害"从轶事变成可计数证据：target run 与 reference run 配对，固定 task、verifier、framework、model、repo state、input data，只变 skill setup，在 SkillsBench + SWE-Skills-Bench 上确认 307 例 skill-induced failures（125 functional + 182 efficiency）并建 taxonomy。两个反直觉发现：functional failures 里明显不相关的 skill 只占 1.6%，86/125 来自"看似相关"的 skill 让 agent 错误实现或遗漏任务必需元素；efficiency 回归的大头不是 prompt 变长（context overhead 仅 46 例）而是行为改变——skill 把 verification checklist 和 implementation pipeline 升格为强制作业（Excessive Procedure 114/182）。附带的自动归因工具 SkillTriage 在 functional failures 上 exact subcategory 88.8%。
- **锐评**: 这篇的价值在于问对了粒度。SkillMemoryBudget 和 ContinualSkillBench 都是聚合层面的证伪（"模块平均不划算"/"收益其实是 ICL 的"），本文补上了缺的那一环：单例级因果归因——具体哪个 skill、以哪种机制搞坏了哪次运行，配对口径可复核，这是方法论贡献而非又一篇 benchmark 灌水。Finding 1 是全文最锋利的一刀：APM 仅 2/125 意味着靠 embedding 相关性检索来筛 skill 市场基本是安慰剂，真正的杀手是语义上"对口"但默认值与任务冲突的 skill——这直接判了"检索相关 skill 就安全"这条隐含假设的死刑。EV 67 + HIP 30 的机制发现也扎实：Guard/Verify 式清单会被 agent 无条件执行，简单任务上纯属烧钱。但硬伤同样明确：全部 307 例出自单一 model（Claude Opus 4.6）+ 单一 framework（OpenCode），结论是否随模型能力平移完全未知；root-cause 靠人工 group consensus 且无 inter-rater agreement，而 SkillTriage 的 taxonomy 正出自同一批标签，88.8% 里有多少是自我一致性、多少是独立验证，说不清；182 例 efficiency 的口径悬在作者自选的 T=2.0 阈值上；20,664 是评估前的比较空间不是失效数，别被 25 倍唬住。最要命的是没放 code/dataset，307 例攥在手里，别人连复核都做不了——一篇讲"归因要可复核"的论文自己不可复核，讽刺拉满。
- **Rating**: `3` 🔥 ，配对归因口径填上了 skill 生态可靠性研究的单例级空白，"相关性筛不掉风险"一条足以改变 skill library 的设计假设，单模型外推性是唯一但不小的折扣。

### StellaVLA
- **Title**: StellaVLA: In-Context Structured Demonstration for Generalizable Vision-Language-Action Models
- **Institutes**: 未列出（arXiv HTML 无 affiliation）
- **Source**: [link](https://arxiv.org/abs/2608.11671)  📄 arXiv   **📒 论文笔记**: [[2608-StellaVLA]]
- **核心**: 针对 VLA 的 OOD 崩溃，test time 按指令 embedding 检索一条最相近的 expert demo，用 off-the-shelf VLM 加确定性 verbalizer 把它全自动压成结构化文本前缀（task plan + sub-goal 关键帧描述 + verbalized 3D 位移），注入 Qwen3-VL-4B + OpenVLA-OFT 式 MLP action expert。训练时 L1 action 回归与自回归语言监督（λ=0.3）双头并行，推理时语言分支整个剥离、单次前向出 action chunk，demo 前缀 KV cache 复用把时延压到 91ms（若推理时真去自回归解码语言是 3177ms，36 倍）。VLA-Arena overall 0.63 居榜首（π0.5 0.44），LIBERO 98.8%，LIBERO-Plus zero-shot 85.1%，真机 in-distribution 85%。
- **锐评**: 这篇的承重件不是 SOTA 表，是两组 ablation。Table 5 的三段对照（correct demo 98.8 → no demo 62.4 → wrong demo 44.9）干净地证明性能真来自 demo conditioning 而非参数记忆，且不回避 "检索错比不给更糟" 这个部署风险；Table 7 的 text-only 98.8/84.4 几乎持平 image+text 98.8/85.1、而 image-only 掉到 92.9/75.7，直接坐实起作用的是语言化的运动结构而不是 demo 像素——这是 verbalized 3D motion 设计的硬证据，比大多数 "structured prompt" 论文的自说自话强一个档次。方法本身简洁：检索 + 前缀 + 双头，没有新增可训练检索器。与 [[2608-InContextVLA]] 从相反的注入位置（监督侧+上下文侧 vs 输入侧）收敛到同一结论——语言对低层控制的价值在训练期塑形与输入结构化，不在推理时生成——这个跨论文 pattern 现在有两个独立数据点了。但三处要扣分。第一，abstract 把 LingBot-VLA 0.22 与 π0.5 并列称 "strong prior models"，而 0.22 是 Table 2 全部 baseline 里最低的（OpenVLA-OFT 0.39、Evo-Depth 0.41 都比它高），典型的选择性对照放大差距观感；好在对 π0.5 的 +0.19 本身是实的。第二，也是最要命的：全文卖 "in-context test-time adaptation"，但主要评测的检索池就是训练 demo 池，"插入一条全新任务的 demo、零权重更新" 这个最有想象力的用法一个实验都没做，真机 OOD-L2（unseen task）只有 1.9/4 的进度分——所谓 test-time adaptation 目前只被验证为 retrieval-augmented conditioning。第三，no-demo 62.4% 远低于无 demo 训练的 StarVLA-OFT（LIBERO 96.6%），模型把大量任务知识外包给了上下文通路，检索基础设施成了单点故障，而纯语言检索对 "同指令不同布局" 天然失配，wrong-demo 44.9% 就是这个风险的价签。另外 Qwen3-VL 自动生成的分段与 sub-goal 全程无人工质检、无噪声敏感性分析。
- **Rating**: `3` 🔥 ，ablation 证据链在 VLA 论文里罕见地完整诚实，"注入优于生成" pattern 的第二个独立数据点，尽管 test-time adaptation 的招牌用法还欠一个实验。

### G0.5
- **Title**: G0.5: One Autoregressive Stream for Robot Reasoning and Action
- **Institutes**: Galaxea
- **Source**: [link](https://arxiv.org/abs/2608.11739)  📄 arXiv   **📒 论文笔记**: [[2608-GalaxeaG05]]
- **核心**: Galaxea 对主流 "预训练 VLM + 独立 flow-matching action expert" 配方发起正面进攻：单个 decoder（Qwen3.5 2B 初始化）在共享 vocabulary 上用单一 next-token cross-entropy 同时生成 CoT 与离散动作码，靠 cross-embodiment RVQ action tokenizer（27 维统一动作空间）、原生四类 CoT 流和 ViT 内插时空 attention 的 visual memory 撑起 foundation 规模。七个 regime 全线领先：真实机同数据同算力微调 76.7% vs π0.5 的 53.3%，BEHAVIOR Challenge 一个 post-training epoch 就超挑战赛冠军，DROID 零样本 82.5%。更要害的是机制论据：AR head 暴露精确 token log-prob，GRPO 免 SDE 重构直接可用，且优化更快更稳。
- **锐评**: 这是 AR vs flow-matching 之争里少见的打法干净的一仗——5.4 节把三个模型钉在同数据、同 16 H20、同 wall-clock、同控制栈下微调，76.7% vs 53.3% 的 23pp 差距真正可归因于架构，这种 apples-to-apples 纪律在 VLA 论文里近乎绝迹；BEHAVIOR 用第三方 metric、1 epoch 超冠军，是预训练先验的硬通货。但 Conclusion 里有一处被证据当场戳穿的 overclaim：声称 zero-shot 语言跟随超过 "post-trained π0.5"，而自家 Fig 10 白纸黑字写着 π0.5 在 50H post-training 后 LF 68.8% > G0.5 零样本的 65.6%——该说法只在 1H/10H 规模成立，写进 Conclusion 就是把边界条件吞了（Evidence Ledger C15 判 contradicted）。同样的修辞手法出现在 abstract：Bridge 上只引 π0.5 的 57.1% 作陪衬，绝口不提实际次优 Xiaomi-Robotics-0 的 79.2%，87.3% 的观感优势被人为放大了 22pp。仿真榜的证据力也别高估：LIBERO 领先 0.2pp、RoboTwin 1.1pp，都是饱和 benchmark 上的噪声级差距，真正有区分度的只有真实机、BEHAVIOR、DROID 三块。最有信息量的反而是 failure case：半透明白色抽屉上 60% vs π0.5 的 90%，贴个橙色 marker 就回 100%——离散 action token 化在精细视觉伺服上可能天然弱于连续 head，论文把锅甩给预训练数据分布而不做机制分析，是全文最偷懒的一段。CoT 的推理时增益在单阶段任务只有约 1.6pp（近噪声），只在长程 stage-conditioned 场景才立得住；2B 单一 size 无 scaling 曲线，AR 逐 token 解码的延迟代价也没在正文给出实测数字。
- **Rating**: `3` 🔥 ，同数据同算力的架构对照 + GRPO likelihood 接口论据把 "AR 路线红利是结构性的" 从口号变成了可检验命题，Conclusion 的 zero-shot overclaim 和选择性对比是污点但不掀翻主论证。

### ComBodied Agents
- **Title**: ComBodied Agents: a New Paradigm of Human-Centric Agentic AI
- **Institutes**: Mila / Université de Montréal 与 A*STAR 牵头，共 16 机构（含 Tsinghua、NUS、Oxford、Cambridge、NTU 等）
- **Source**: [link](https://arxiv.org/abs/2608.10915)  📰 HF Daily ⬆️ 176   **📒 论文笔记**: [[2608-CombodiedAgents]]
- **核心**: 22 位作者、16 机构联署的 position paper，提出 Combodied（Companion + Body）范式：把人的 evolving state 与 agency 作为建模、干预与评估的一等对象，断言 Digital Agent（软件状态变换）与 Embodied Agent（物理状态变换）都没覆盖这块。框架是四 capability 闭环——Human-State Perception、Longitudinal Memory、Personal World Model、Intervention Planning and Delivery——干预在 consent/safety/reversibility 硬约束的 admissible set 上做 Pareto 选择，action space 固定 10 类。配套提议 8 模块的 CombodiedBench，scenario-centered、把 agency preservation 与 task completion 并列为 outcome。全文无实现、无数据、无代码。
- **锐评**: 作为 position paper，形式化部分是同类中少见的干净：human-state transition 显式含 a^user 与外生项（承认 agent 干预对人非决定性）、效用保持向量不 scalarize、安全约束做成 admissible set 而非 reward penalty——比满大街的 "RLHF for wellbeing" 表述严谨一个档次；自我限界也诚实（明说 HDT 不可达、causal identification 假设难满足、长程外推只配当 exploratory scenario）。但硬伤同样明确。其一，整个范式成立与否押在 Personal World Model 上，而 PWM 要在个体级稀疏、非实验性观察数据上学 intervention-conditioned dynamics，论文把困难列了一遍却没给任何可行路径——当前形态接近不可证伪的宏观框架。其二，Table 1 的 12 类 taxonomy 是作者自建的先验分类学，strawman 味道重：说 Computer-Use Agents "may automate without human-state awareness" 是把设计范围差异包装成缺陷，范式边界全靠 declarative 划线而非实证。其三，对人状态的感知与适时干预在 affective computing 与 mobile health 的 JITAI 脉络里积累了十几年，本文的增量本质是把这些翻译成 agentic AI 词汇并接上闭环架构，机制层面没有新东西。CombodiedBench 无数据无代码，agency preservation、calibrated reliance 这些关键 metric 连可操作化定义都没有——对照同期 [[2608-MacaronV1]]（实打实的系统 + 自建 benchmark + 全文划 evidence boundary），一个交付数字，一个交付词典，高下立判。真正值得留的是两点：PWM 与 world model 文献的接口同构（把建模对象从环境换成人，功能契约仍是 action-conditioned trajectory distribution），以及 agency preservation 作为一等 metric 对 computer-use agent oversight 研究的借鉴。松散联盟型署名，CombodiedBench 大概率停在蓝图。
- **Rating**: `2` 👀，词表和形式化值得借，但 blueprint 不落地就只是词表——等有人真做出一个 PWM 再回头看。

### CoEvolution Survey
- **Title**: Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design
- **Institutes**: HKUST, UIUC, CUHK, HKU, Peking University
- **Source**: [link](https://arxiv.org/abs/2608.10299)  📰 HF Daily ⬆️ 122   **📒 论文笔记**: [[2608-CoEvolutionSurvey]]
- **核心**: 把 co-evolution——至少两个 evolving units 相互施加 adaptive pressure、持续重塑彼此后续演化——作为 survey 的中心纳入标准，而非像既有 self-evolving surveys 那样按单 agent 内部组件罗列。全文统一形式化为演化算子 Ω 作用域的渐进扩张：Stage 1 Agent-Agent（环境固定，agent collective 内耦合）、Stage 2 Agent-Environment（task/feedback/interaction 三个子空间进入更新）、Stage 3 Meta（Ω 本身被自生成的 revision process Γ 修订）。附带 Figure 4 跨论文 static-vs-evolving 证据汇总，挑战节给出 dynamic evaluation、scaling、safety & governance 三条。
- **锐评**: 真正值钱的是两件小事：Appendix A 拿判别标准与 self-play / open-endedness / meta-evolution 等十个相邻概念逐一划界——在这个术语被污染到人人自称 "co-evolve" 的领域，这是实际贡献；以及 Figure 4 的 matched 对比 + 归一化轨迹，survey 肯给证据而不只给分类树，罕见。与 vault 里两篇竞品（Gao et al. 的组件轴、Fang et al. 的 optimiser 轴）确实是正交切法，互补不冗余。但硬伤同样清楚：其一，"首个以 co-evolution 为中心轴"这条 claim，Ledger 只验证了"论文这么说"，而本 vault 对 Xiang et al. 2026 的记录显示那篇标题就叫 environment-driven co-evolution——把它打成 "subtheme" 至少在 agent-environment 这一半上站不住，Appendix B 的对比表有自利裁剪之嫌。其二，Stage 3 拿得出手的例子只有 RQGM 一个，PromptBreeder/MemEvolve 全被作者自己承认是 single-entity precursor——所谓"三阶段"实为两个文献簇加一个愿景，taxonomy 的压轴章是空的。其三，"演化自由越大越接近终极形态"的方向性叙事与自家 safety 节的失控警告正面相撞，文中不处理这个张力，等于叙事上想要 open-endedness、结论上又要 rollback to verified states，两头都占。另注意 Figure 4 的跨 benchmark 聚合未报告负面案例纳入比例（笔记标注为推测），幸存者偏差未排除；且全文无配套 repo/paper-list（Ledger C10 核实），2026 年的 survey 交这种作业，可用性打折。对我们的实际价值在 Stage 2：interaction-space 一节（POET/ADR/WebEvolver）正好是 world model 与 environment-evolution 方向的定位地图，而 GUI agent 的 harness-environment 共演在该框架下几乎无覆盖——这个空白比论文本身更值得记下。
- **Rating**: `2` 👀 ，Appendix A 的概念划界与 Stage 2 地图值得收藏，但第三阶段是一篇论文撑起的空中楼阁、"首个"claim 经不起 vault 内部证据的对照。

### SkillZip
- **Title**: SkillZip: Evaluation-Free Skill Compression for Self-Evolving Agents by Discovering Reusable Structure
- **Institutes**: Alibaba Group, Zhejiang University, Duke University
- **Source**: [link](https://arxiv.org/abs/2608.11079)  📰 HF Daily ⬆️ 12   **📒 论文笔记**: [[2608-SkillZip]]
- **核心**: 自进化 agent 的 skill 文本 5 轮膨胀约 5.2×，冗余的本质是 repeated representation（同一 invariant 被复述进多个分支）而非无关内容，所以低频 exception 不能按出现频率删。SkillZip 把压缩形式化为 typed MDL：先解析出 typed contract（triggers/workflow/tool contracts/scoped rules），再在 hard coverage constraint 下做确定性 min-cost covering，全程不接触任务、rollout、reward、verifier。结果：平均压缩 31.2%（evaluation-guided 的 SkillReducer 仅 9.2%），score 0.577 vs 未压缩 0.570，0 rollouts、3.5× 提速；continual 的 Zip-on-Write 把 16 轮膨胀从 2.5–3.7× 封顶到 1.6–1.9× 且精度不降。
- **锐评**: 问题诊断是本文最值钱的部分——"evaluation-guided 压缩只能修好被 eval set 观测到的分支，却照样丢掉没被测到的 guard"直击结构盲区，Cor. IV.2 把 rare-rule preservation 做成 by-construction 而非碰运气，解释（LLM 抽取）与优化（确定性求解）分离、失败模式收敛到 under-compress 的工程纪律也干净。但三处必须泼冷水：一，保证是 parser-relative 的，整条 pipeline 的风险从 optimizer 平移到了 structural parser，而 parser 召回率主文没有任何直接评测——被漏解析的语义连 coverage constraint 都保护不了；二，31.2% vs 9.2% 的头条数字有 regime 错配水分（SkillReducer 的设计目标是 public skill debloating，被拉来压 evolved skill），0.577 vs 0.570 也只该读作"没压坏"而非提升；三，无 component ablation、无公开代码（附录只有 intended repository 布局）、单一 evolver 三个 benchmark，"哪个设计贡献了多少"全是黑盒。更深一层的尴尬来自本 vault 的旁证：膨胀前提量化在 SkillOpt 上，而 SkillOpt 自己的论文报告 median 2.5 个 accepted edits、~920 token 的紧凑 artifact——bloat 幅度多大程度是 evolver 配置的产物，本文没拆；且 [[2608-ContinualSkillBench]]（ICL≈Seq）和 [[2606-SkillMemoryBudget]]（budget-matched vanilla 全胜）刚刚双面质疑了"skill library 净值为正"这个前提，SkillZip 是在给一个价值存疑的资产做精装修——不过话说回来，压缩恰好是对 token 预算批评唯一正面的回应方向，RQ5 的"round-1 启用封顶 1.9×、round-8 才启用追不回（2.6×）"是全文最有运维价值的发现：冗余防住比事后清除便宜。
- **Rating**: `2` 👀 ，形式化干净、问题选得准，但 parser 召回未测、无 ablation 无代码，压缩对象的净值又正被同期工作双面证伪——等 repo 和 parser 评测落地再加码。

### Latent-to-4D
- **Title**: Beyond Pixels: From Video Priors to 4D Worlds
- **Institutes**: ReLER, CCAI, Zhejiang University
- **Source**: [link](https://arxiv.org/abs/2608.10744)  📰 HF Daily ⬆️ 123   **📒 论文笔记**: [[2608-LatentTo4D]]
- **核心**: 把共享同一 Wan VAE 的 video DiT 的最终去噪 latent 当作通往显式 4D 的可复用接口：L4AR 网络用固定 trilinear resampling + 3D conv 把 latent 对齐到 4RC 初始化的 decoder token grid，frame-wise 与 global attention 交替精炼，直接输出 per-frame camera + 世界系几何，绕过 RGB 解码和重建级联。只训 alignment + rank-16 LoRA + heads（1,143 clips），单一 checkpoint 免调服务 Wan2.1-14B/1.3B/Wan2.2-I2V 三个 DiT；Text4D-200 上 DINO-F1 比 matched same-latent Wan+4RC 级联高 2.88–3.45 点，I4D-200 高 5.81 点。
- **锐评**: 这篇最值钱的不是架构而是对照设计——matched same-latent cascade 固定 video prior，把变量干净地隔离到接口本身（latent 直连 vs decode 成 RGB 再重建），比 4D 生成领域常见的"和三个不同 prior 的 baseline 混比"诚实得多；两个 text DiT 上 57.01 vs 57.09 的免调转移也确实支撑了"接口可复用"。但三处 evidence boundary 必须点破。其一，"VAE-family-level 可插拔"实际是 **Wan-family-level**：全部证据在单一 Wan VAE 权重内（作者在 Conclusion 自陈），跨 CogVideoX/HunyuanVideo 未测，VAE 换版本 checkpoint 即失效——所谓"可复用接口"的边界恰好就是那份 VAE 权重。其二，主表全是 DINO-F1 这类 projection-based appearance proxy，作者自己承认不建立 metric accuracy；真正的 cm 级 metric 评估只出现在 7-Scenes/NRGBD 的 ablation 里（重建数据、非生成场景），所以"+5.81"到底是几何更准还是投影观感更讨 DINO 喜欢，论文没有分离。其三，1.3B 和 14B latent 的 DINO-F1 几乎打平，既可以读成方法对上游 latent 质量鲁棒，也可以读成这个指标压根对 latent 质量不敏感——后一种解释会连带削弱主表的说服力，论文未做区分。另外，绕过 RGB decode 与独立 reconstructor 本应是效率卖点，主文却不给 inference 速度对比，可疑地安静。跟 RynnWorld-4D（RGB-D-Flow 投影式 4D 喂 policy）比，本文走的是显式几何生成路线，本质区别在于把 4D 能力从 generator-level 定制上移为 VAE 层面的可插拔模块——这个 problem reformulation 是干净的，但目前只在一个 family 里验证过一次。
- **Rating**: `2` 👀，接口重构的 formulation 干净、对照设计诚实，但证据被单一 VAE family 和 appearance proxy 指标双重圈死，且与我们 agent/embodied 主线只有 world-model 层面的弱连接。
