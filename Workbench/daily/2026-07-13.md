本周高分区两条主线：一是 **world model 井喷**（RynnWorld-4D 把生成式 world model 推到 projective 4D、AlayaWorld 做实时可玩视频世界），二是 **agentic RL 的训练侧**（SAO 用单 rollout 异步绕开 GRPO 的 group 依赖、Beyond Static 想把静态评测换成仿真环境）。最有价值的其实是两篇"打假"论文：Video-Oasis 用共识投票揭穿主流视频 benchmark 55% 的题根本不用看视频、SOTA 剔除捷径后近乎随机；Gemma 4 tech report 里真正可复用的是端侧效率 recipe 而非被包装出来的"性能跃迁"。

### SAO：单 rollout 异步 agentic RL
- **Title**: Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning
- **Institutes**: Tsinghua University, Z.AI
- **Source**: [link](https://arxiv.org/abs/2607.07508)  📰 HF Daily ⬆️ 14   **📒 论文笔记**: [[2607-SAO]]
- **核心**: Agentic 任务 rollout 长度方差大，同步 RL 要等最慢的 straggler，GPU 大量空转；而 GRPO 的 group 采样天然与异步不兼容（一个 group 必须凑齐才能算 group-relative reward）。SAO 干脆每个 prompt 只采一条 rollout、生成完即训，用一个训练好的 value model（critic）+ GAE 替代 group baseline，并复用 rollout 阶段的 log-prob 做双侧 token-level importance sampling（DIS，越界 token 直接 mask 而非 clip）。配上 K=2 的 critic 快更新、frozen-attention 正则、Skip-Observation GAE。结果 AIME2025 97.3% vs GRPO 84.2%、SWE-Bench Verified 29.8% vs 27.0%，且能稳训 1000 步而 vanilla GRPO 160 步就崩，已部署训 GLM-5.2（750B-A40B）。
- **锐评**: 问题 formulation 抓得干净——"group 采样与异步训练不兼容"是 first-principles 层面的观察，不是工程 trick，回归 actor-critic 换异步友好性的思路自洽；稳定性对比（GRPO 160 步崩 vs SAO 1000 步稳）配 explained variance / gradient norm 的动力学证据，比只晒终点指标扎实，running-mean baseline 79.8% vs 97.3% 的 ablation 也把功劳干净地钉在 value model 上。但硬伤明显：一篇标榜 **asynchronous** 的工作，异步系统本身（rollout 怎么 stream、staleness 怎么界定、吞吐 vs on-policy 的权衡）只有一句"完成即训"，最该展开的 infra 全是黑箱——实际做实的是"single-rollout + 稳 critic"，异步更像动机而非贡献。更别扭的是：全篇只在 Qwen3-30B-A3B 一个 backbone 上验证，作者自认"未必迁移到小模型/dense reward"，却把卖点吊到 GLM-5.2 750B 上不给该规模任何数字，最有分量的证据反而缺席。本质是把"凑 group"的复杂度平移到"训一个好 value model + value pretraining 解 cold-start"，是否真比 GRPO 系省心，存疑。
- **Rating**: `3` 🔥 ，来自 GLM 团队、观察到位且已上大模型生产线的实用工作，值得进 agentic-RL 训练方法对比表，但 async infra 缺席 + 单 backbone 让它够不上"必读"。

### Video-Oasis
- **Title**: Video-Oasis: Rethinking Evaluation of Video Understanding
- **Institutes**: Sejong University, NAVER Cloud
- **Source**: [link](https://arxiv.org/abs/2603.29616)  📰 HF Daily ⬆️ 55   **📒 论文笔记**: [[2603-VideoOasis]]
- **核心**: 造了个诊断套件 Video-Oasis，沿"去视觉 / 破时序 / 查歧义"三条轴、用 5 个模型共识投票去审计 14 个主流视频理解 benchmark。结论很扎心：严格共识下 55% 的题目根本不需要看视频（仅凭问题+选项、语音、或单帧就能答对），宽松阈值下更是高达 92.7%。剔除这些捷径样本重构出真正 video-native 的评测集后，SOTA 集体跳水——随机基线 25.6%，Gemini-2.5-Pro 也才 46.7%，Video-R1 只有 26.3% 基本等于蒙。oracle grounding 对照进一步锁定：真正的瓶颈是时序定位而非答案生成。
- **锐评**: 这是一篇"把皇帝没穿衣服喊出来"的诊断论文，问题选得极准，比 99% 刷 +0.5% 的 video-LLM 灌水有价值得多。最漂亮的一刀是 oracle grounding 的隔离实验：在 Video-Oasis 难题上 35.0%→50.8%（+15.8），在捷径题上 78.0%→80.8%（+2.8），干净地证明"看不看得懂视频"卡在时序定位，这比 main table 信息量大。硬伤也很明确：整个"捷径"的定义是自举的——用当代一批模型的能力边界去判定什么算捷径，模型一升级判定就漂移，55% 不是绝对真值而是"2026 年这批模型眼里的 55%"；作者自己也承认 caption/shuffle 测试会漏保留时序线索、产生假阳假阴，却没给误判率。更该被追问的是：过滤后 51% 样本挤在 Temporal Dynamics & Tracking，所谓"video-native"实际被悄悄窄化成"时序密集题"，这到底是揭示了视频理解的本质，还是只是揭示了 tracking 类题目的本质？方法上零创新，纯 benchmark hygiene，但这活儿本就该有人干。
- **Rating**: `3` 🔥 ，evaluation 类里少见的诚实且量化到位，"55% 捷径 / SOTA 近随机"是能改变领域刷榜风气的数据点，只可惜捷径定义的自举性与类别失衡让结论差一口气封神。

### Gemma 4：开源权重原生多模态的一次工程性跃迁
- **Title**: Gemma 4 Technical Report
- **Institutes**: Google DeepMind
- **Source**: [link](https://arxiv.org/abs/2607.02770)  📰 HF Daily ⬆️ 59   **📒 论文笔记**: [[2607-Gemma4]]
- **核心**: Google DeepMind 发布新一代开源权重、原生多模态（文本/图像/音频）模型家族，覆盖 2.3B–31B 的 dense 与 MoE 变体，并引入 thinking mode 和一个 encoder-free 的统一 12B 架构（直接吃 raw audio/image patch）。相对 Gemma 3 27B，文本推理（MMLU-Pro 67.6→85.2、AIME 20.8→89.2）、多模态和长上下文（RULER@128k 66.0→96.4%）全线大幅跳升，LMArena 上 31B 拿到 1451 Elo，号称可比 10× 更大的模型。报告的另一半篇幅是端侧效率工程：KV cache 减 37.5%、音频量化 footprint 减 78%、MTP 投机解码 + 词表聚类。
- **锐评**: 作为一份"技术报告"它诚实地暴露了自己更像产品发布而非研究。最刺眼的问题是 benchmark 对比全程不对等——拿开了 thinking mode 的 Gemma 4 去打不带 thinking 的 Gemma 3，AIME 20.8→89.2、Codeforces 110→2150 这种从地板到天花板的跳升里，thinking + 后训练贡献和架构贡献被彻底搅在一起，全文没有一个"同数据、开/关 thinking"的干净 ablation，读者根本无法判断新架构本身值几分。其次是选择性对比：几乎不与 Qwen3 / Llama 4 / GPT/Gemini 在自报 benchmark 上正面对表，只在 LMArena Elo 上侧面比，而 Rank 43 恰恰说明"rival frontier"是营销措辞。训练数据只给"web/code/图像/音频"六个字，token 数、配比、来源全无，可复现性为零。最有 insight 的 encoder-free 统一架构只上了 12B 一档，却没给"统一 vs 外挂 encoder"同规模对照，本该做 ablation 的地方偏偏空着。真正的硬货其实在效率工程那一块（KV/QAT/MTP、完整内存 footprint 表），那才是可复用的部署 recipe——可惜它被包装成了"性能跃迁"的注脚。
- **Rating**: `3` 🔥 ，开源权重的强端侧多模态基座、效率 recipe 有实用价值，但作为研究 insight 稀薄、对比避重就轻，值得下载权重、不值得照抄结论。

### RynnWorld-4D
- **Title**: RynnWorld-4D: 4D Embodied World Models for Robotic Manipulation
- **Institutes**: Alibaba DAMO Academy
- **Source**: [link](https://arxiv.org/abs/2607.06559)  📰 HF Daily ⬆️ 89   **📒 论文笔记**: [[2607-RynnWorld4D]]
- **核心**: 把生成式 world model 从 2D 视频推进到 "projective 4D"——即同步预测 RGB + Depth + Optical Flow，用相机模型隐式承载几何而不碰体素/NeRF。架构是 Wan 2.2-TI2V-5B 扩成三分支 DiT，每 3 层插一个共享 KV 的 Joint Cross-Modal Attention，在 254.4M 帧伪标注视频上三阶段训练，再冻结取 block-15 隐状态蒸馏出 flow-matching policy。结果：world model 的 Depth δ₁ (0.610) 近乎翻倍 4DNeX (0.327)，6 个真机双臂灵巧任务里赢 5 平 1，超过 π₀/π₀.₅。
- **锐评**: 工程扎实、ablation 诚实（去掉跨模态融合 δ₁ 从 0.610 塌到 0.245，去掉 4D 预训练 AEPE 从 0.170 崩到 0.729，JA 确实是命脉），但 headline 叙事被自家数字打脸——RGB imaging quality 0.635 反而**输给纯 2D 的 Wan-2.1 (0.684)**，说明"加 depth/flow"并没让生成变好，几何优势本质是"多监督了两个头"，而不是"4D 表征范式的胜利"。更硬的问题是整条链路的几何 ground truth 全是 Depth Anything 3 + DPFlow 的**伪标注**，δ₁/AEPE 是在和伪标对齐，不是真实几何精度。真机只有 6 任务、单一硬件，Hand-over 上 π₀/π₀.₅ 双双 0% 这种极端结果让人怀疑 baseline 有没有调到位。9 Hz、890ms 前向、egocentric-only 都是明说的天花板。跟 TesserAct/4DNeX 的区别在于"投影式 4D + 生成式预训练 + 特征蒸馏 policy"打通闭环，方向对，但离真正的 4D 想象式规划还远。
- **Rating**: `2` 👀 ，DAMO 出品的扎实系统工作，几何指标和真机结果有料，但"4D 更好"的核心 claim 被 RGB IQ 反超和伪标注 grounding 削掉一半，是值得跟不必跪的增量。

### UI-MOPD
- **Title**: UI-MOPD: Multi-Platform On-Policy Distillation for Continual GUI Agent Learning
- **Institutes**: Tsinghua Shenzhen International Graduate School, Xiaomi, HIT Shenzhen, Zhejiang University, Peng Cheng Laboratory
- **Source**: [link](https://arxiv.org/abs/2607.04425)  📰 HF Daily ⬆️ 68   **📒 论文笔记**: [[2607-UIMOPD]]
- **核心**: 跨平台 GUI agent 联合训练时，桌面（鼠标键盘）和移动端（点击滑动）的交互习惯互相污染，naive 混训会灾难性遗忘。本文先分别 SFT 出 desktop/mobile 两个 32B expert teacher，再做 platform-conditioned 的 on-policy distillation——8B student 自己采 rollout，桌面 rollout 只对齐桌面 teacher、移动 rollout 只对齐移动 teacher，用 reverse-KL + adaptive masking 约束。最终 8B student 在 OSWorld 38.2% / MobileWorld 12.0%，两端平衡且保住了 grounding 能力，明显好过 model merging（TIES 在 MobileWorld 直接崩到 0%）。
- **锐评**: 问题 formulation 干净，把"跨平台联合训练"从"堆数据"重构成"运行时按平台路由 teacher"，这一刀切得漂亮，本质区别就在于 merging 在参数空间静态融合（信息互相覆盖），它在 rollout 分布上做条件蒸馏——像用外部 environment label 当 gating 的 MoE。但硬伤很扎眼：**最关键的 ablation 直接缺席**——没有去掉 platform-conditioned routing 的对照，增益到底来自"路由"还是"on-policy"本身，全靠读者脑补，adaptive KL masking 和 reverse-KL 也一个都没单拆。数字层面 MobileWorld 12.0% 弱到尴尬，桌面/移动 38.2 vs 12.0 的鸿沟说明移动端根本没被"解决"；zero failure-case 分析，连自家 TIES merge 归零这种异常都不解释。还有个隐藏地雷：整套方法预设部署时 platform label 恒可得，标签一缺路由就失效——"multi-platform"招牌下其实只有两个平台，web 泛化只字未验。工程扎实、思路对症，但离"讲清楚为什么 work"还差一组 ablation。
- **Rating**: `2` 👀 ，对症的干净设计，但缺 routing ablation + 移动端数字太弱，可参考不必追。

### LaMem-VLA: VLA 的双 latent 记忆
- **Title**: Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation
- **Institutes**: Nanjing University of Science and Technology, Zhejiang University, National University of Singapore
- **Source**: [link](https://arxiv.org/abs/2607.07608)  📰 HF Daily ⬆️ 51   **📒 论文笔记**: [[2607-LaMemVLA]]
- **核心**: 针对 VLA 只从当前观测预测动作的 Markovian 短视偏差，把历史经验重构成 "context-native latent memory token"，直接编织进 VLA 的 embedding 序列参与 self-attention，而不是像 MemoryVLA 那样当作 policy-side 外部记忆库在推理之后消费。系统由 curator（分 short 视觉 / long 语义双 vault）、seeker（top-K 检索）、condenser（压成定长 token）、weaver（注入序列）四件套组成，backbone 是 7B Prismatic VLM + 300M 扩散 action expert。SimplerEnv-Bridge 均值 73.9%、LIBERO 五套件均值 97.6%，长程套件相对 MemoryVLA 涨 1.4–2.4 分。
- **锐评**: 有一处真值钱的对照——"记忆进 native embedding 空间" vs "policy-side 条件化" 直接给出 71.9→73.9 的可验证增益，这不是口号而是把范式主张落成了数字，比大多数堆架构的 VLA 记忆论文诚实。但硬伤扎眼：**全仿真、零真机**，一篇通篇讲"长程记忆帮助真实操作"的论文却对 sim-to-real dynamics gap 只字未碰，作者自己都承认，claim 与证据严重不匹配。其次组件全是常规件（transformer former、mean pooling、cosine top-K），novelty 完全押在 orchestration 上，离散 top-K 还不可微、端到端打折。收益曲线也不硬——K>8、token 数偏大都掉点，甜点窄；相对最强 baseline MemoryVLA 的 LIBERO 整体只 +1.1，主要靠长程套件撑，SimplerEnv 的 Stack Cube 仅 41.7% 暴露长程稳健性天花板。跟已有工作的本质区别就一句话：记忆从"外挂"挪进"native token"——想法对，但没真机就只是半个故事。
- **Rating**: `2` 👀 ，范式主张干净且有可验证的 latent-native 增益，但纯仿真 + 常规组件 + 窄甜点让它停在"值得一看"而非"重要"。

### AlayaWorld
- **Title**: AlayaWorld: Long-Horizon and Playable Video World Generation
- **Institutes**: Alaya Lab (Shanda)
- **Source**: [link](https://arxiv.org/abs/2607.06291)  📰 HF Daily ⬆️ 85   **📒 论文笔记**: [[2607-AlayaWorld]]
- **核心**: 从 LTX-2.3 微调出一个可实时游玩的交互式 video world model，720p/24fps、约 1 秒 chunk 自回归生成，支持自由导航加 combat/施法/召唤等开放动作。工程上把四大难题各配一个模块：3D cache 渲染加 AdaLN 注入做相机控制、chunk 级 prompt-switching 做动作切换、"空间 3D cache + 压缩帧历史 + loop-closing" 双记忆做 revisit 一致性、error bank 注入漂移做长时程稳定、DMD few-step 蒸馏做实时。号称能撑一分钟 rollout 且支持多风格渲染。
- **锐评**: 系统集成度确实不低，双记忆加 error bank 这套组合对 revisit 一致性和长程漂移是务实设计，思路没毛病。但作为一篇"paper"它硬伤刺眼：**全程零定量评估**——没有 benchmark、没有消融、没有一个和 baseline 的量化对比，所谓"优于代表性交互世界模型"全靠自选 demo 说了算，这在 world model 已经有 VBench/一致性指标可用的当下毫无借口。更像 shanda 的产品 teaser 而非研究：核心模块 navigation follow GEN3C、history 压缩 follow Frame Preservation、蒸馏用 DMD，方法论上是成熟组件的拼装，本质新意有限；静态 3D cache 对动态物体的表示是明摆着的软肋却只字未提。最诚实的一句话写在论文里——"完整技术细节、实验结果和代码 mid-July 发布"，也就是说现在这版什么都还没给。85 个赞买的是"可玩世界"的想象力，不是证据。
- **Rating**: `2` 👀 ，方向够热、工程拼装合理，但零量化评估加代码未放，属于只能先 mark、等 mid-July 完整版回填的 teaser。

### AgenticAI-Supervisor：Agentic RL 的仿真环境平台
- **Title**: Beyond Static Evaluation: Building Simulation Environments for Scalable Agentic Reinforcement Learning
- **Institutes**: 未标注（arXiv 页面与正文均无 affiliation）
- **Source**: [link](https://arxiv.org/abs/2607.05773)  📄 arXiv   **📒 论文笔记**: [[2607-AgenticAISupervisor]]
- **核心**: 提出 AgenticAI-Supervisor——一个 API/UI 驱动的 RL Gym 平台，把"环境创建"与"可扩展执行"解耦：MCP 有状态工具模拟器负责搭场景，容器化无状态 sandbox 负责并行 rollout。奖励侧用 outcome（multiset 比对终局状态）/ constraint adherence（negative check + side-effect detection + output fidelity）/ trajectory efficiency 三维 reward shaping，并靠状态级校验对抗 reward hacking。作者观察到：仅用 outcome reward 时，约 40% 被正向强化的 episode 存在 constraint misrepresentation、约 3.8% 存在 fabrication。全文只有一个 Customer Support Agent 的定性 case study，无任何成功率/曲线/baseline。
- **锐评**: 典型的"平台预告冒充论文"。问题 framing 没错——outcome-only reward 会被 hack，这是真痛点，那两个诊断数字（40% / 3.8%）也确实是能抄进 intro 的弹药。但硬伤是致命的：它只证明了病，完全没证明药——上了 constraint adherence 之后那 40% 降到多少？没有。case study 只有一张工具清单（Refund/Replacement/Security Lock）加一句"能强化合规工作流"，零指标、零 baseline、零 ablation。Computer Use、automated "stumping"、edge-case generation、no-code 界面、uncertainty-aware reward 全塞进 future work，等于自认当前只是骨架。跟 EnvFactory / MobileGym / WebGym / DreamGym 这些已有 agent RL 环境更是只字未提对比，读不出增量。multiset equality 当 outcome 判定在多合法解任务上一碰就碎。无机构署名、无开源、无可复现细节，claim 和证据的匹配度基本为零。
- **Rating**: `1` 💤 ，方向对但通篇是 vision level 的系统描述，连自家 reward shaping 的药效都没测，除了 40%/3.8% 两个病理数字外没有任何可信证据。
