## 论文点评

### VISTA-Gym / VISTA-R1
- **Title**: Scaling Agentic Reinforcement Learning for Tool-Integrated Reasoning in VLMs
- **Institutes**: Virginia Tech, Emory University, KAUST, Georgia Tech, Cisco, TAMU, UT Southwestern Medical Center, Eigen AI
- **Source**: [link](https://openaccess.thecvf.com/content/CVPR2026/html/Lu_Scaling_Agentic_Reinforcement_Learning_for_Tool-Integrated_Reasoning_in_VLMs_CVPR_2026_paper.html)  🎓 CVPR2026   **📒 论文笔记**: [[2606-VISTAGym]]
- **核心**: VLM 做"thinking with images"（多步调视觉工具推理）一直缺一个能规模化训练的环境，本文直接把基建造了出来：VISTA-Gym 统一 7 类任务 / 13 数据集 / 26 个工具成 Gymnasium 式 RL 环境（可验证 reward + Ray Actor 常驻 GPU 的 VLM-as-tool 微服务），再用 SFT warmup + GRPO 在线 RL 训出 VISTA-R1。8B 模型在 11 个推理密集 VQA benchmark 上全平均 72.48（底座 InternVL3-8B 是 65.79），带工具比同尺寸开源 baseline 高 9.51%–18.72%，2B 能打 8B baseline、8B 能打 38B。最有信息量的发现是反直觉的：朴素给 base VLM 加工具反而掉点，工具是 distractor，必须 RL 强化推理才能解锁 TIR。
- **锐评**: 这篇的真价值不在 +X% 而在两处：一是切中了"视觉 TIR 没有训练环境"这个真空白，Gym 化的工程设计（可验证 reward、`reset()/step()` 接口、工具热插拔）是能被别人复用的；二是消融干净地解耦了 reasoning vs tool-use——w/o Reasoning 骤降到 48.40，直接证明"给工具不教推理等于白给"，这比 main table 值钱。但硬伤也明确：**标题两个词都在 overclaim**。"Scaling"最大才 8B，谈不上 scaling；所谓 general visual reasoning，13 个数据集清一色 chart/geometry/math/diagram，本质是"带视觉外壳的符号求解"，离 GUI/具身/开放世界一步没迈。SFT 轨迹靠 GPT-5 生成候选、Qwen3-235B 加密 rationale，双重蒸馏还讲"自举"叙事，站不住。最要命的对比口径问题：baseline 大多 evaluated without tool access（理由是"给工具会掉点"），所以那 9.51%–18.72% 有一部分是"对手不会用工具"送的分，不是纯方法增益。另外 gains 明显 task-dependent——commercial VLM 收益小，说明这套东西更像给 small open VLM 补课，不是通用配方。
- **Rating**: `3` 🔥，"环境即贡献"的路数在视觉 TIR 上是真空白，加上"工具不配 RL 反而有害"这个可迁移 insight，值得跟进——尽管 title 的两个关键词都没兑现。

### Long-Horizon-Terminal-Bench
- **Title**: Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading
- **Institutes**: Tencent HY LLM Frontier, University of Maryland, University of Georgia, NUS, HK PolyU 等
- **Source**: [link](https://arxiv.org/abs/2607.08964)  📰 HF Daily ⬆️ 48   **📒 论文笔记**: [[2607-LongHorizonTerminalBench]]
- **核心**: 46 个长时程终端任务（复现实验、SLAM 修复、EDA、交互游戏等），每题拆成带权重的 graded subtasks 给 dense reward 和 partial credit，取代 Terminal-Bench 式的二值判分。任务规模凶残：平均每 run 9.8M tokens、239 episodes、88.9 分钟，比 Terminal-Bench 2 高一个量级。17 个 frontier model 里最强的 Grok 4.5 在 R≥0.95 下 pass@1 仅 28.3%，全体均值 6.4%；782 个 run 中 62.8% 拿到 partial reward 但在二值判分下会被全部记零。
- **锐评**: 核心论点立得住——[0.85, 0.95) 区间的 near-miss（68 个）比通过（50 个）还多，二值判分在这个难度下确实把整个中间地带压成噪声；hidden stress verifier + "gold solution 必须拿满 1.0" 的 grader 自检设计也是同类工作里少见的认真。但执行层面毛病一堆：46 题 × pass@1 单次 run，1 题就是 2.2 个百分点，6.5% 和 4.3% 两档之间只差一道题，不报方差还敢排名，中下游座次基本是掷骰子；难度只用 DeepSeek-V4-Pro 一个模型校准，任务被筛成"对 DeepSeek 难"；79% 的失败是 90 分钟 timeout，benchmark 相当程度上在测 serving 速度而非能力上限，Grok 4.5 的头名成色因此存疑，偏偏 budget ablation 一个没做。更难看的是正文自相矛盾：abstract 说 nine categories、§2.4 说 21 个；Figure 4 的 732 个未通过 run 和 Figure 6 的 660 个对不上；v1 到 v2 四天内 headline 从"最佳 15.2%"改成"28.3%"。GPT-5.3 单独换 Codex harness 还顺手破坏了受控比较。真正有价值的遗产不是 leaderboard 而是那套 subtask-level dense reward 基建——拿去当 agentic-RL 训练环境比当评测榜有用。
- **Rating**: `2` 👀，dense reward 判分基建值得借鉴，但单 run 无方差的排名、单模型难度校准和满篇对不上的数字暴露了赶工痕迹。

### MAG
- **Title**: MAG: A Web-Agent Benchmark and Harness for Multimodal Action and Guide Generation
- **Institutes**: Independent、University of Chinese Academy of Sciences、Monash University、Pusan National University、Shenzhen University of Advanced Technology
- **Source**: [link](http://arxiv.org/abs/2607.10079v1)  📄 arXiv   **📒 论文笔记**: [[2607-MAG]]
- **核心**: 瞄准 Digital Adoption Platform 场景，首次把 web 任务执行和"每步写一句用户能跟着做的指南"合并成一个联合评测任务：基于 WebArena 6 个 live 站点构建 581 个任务，每步标注 screenshot + Set-of-Mark / 像素坐标两种 grounding 的 action + 人工校验的 guide 句，用 GGS（guide 分数被任务成功 gate 住）联合打分。frontier 模型最高只有 GPT-5.5 的 37.4% SR；开源 9B 用注入 GPT-5.5 缓存轨迹的 GRPO 从 SFT 的 6.9% 提到 13.2%。附带两个有用的实证结论：grounding 偏好是模型特异的（Gemini 用 SoM 比坐标高 13.8 个点，GPT-5.5/Claude 无所谓），以及不注入 expert 轨迹的 plain GRPO 十次尝试全部 stall。
- **锐评**: Formulation 是真空缺——"会做"和"会教"此前确实没人联合测，GGS 的 gating 设计也堵死了靠流畅废话刷 guide 分的路子，这点给足认可。plain GRPO 十连败的 negative result 和 pass@6 +6.9（证明 RL 加的是能力不是采样集中）是全文最诚实的部分。但硬伤同样扎眼：guide 这半壁招牌用**单参考 BLEU/ROUGE** 评，只测 n-gram 重合不测可跟随性，措辞不同但同样正确的指南直接被压分——benchmark 的核心指标撑不起核心 claim；GGS 里 γ=0.4 意味着成功任务配垃圾指南也保底 0.4 分，"Guide Tax" 的量级一半是指标设计出来的。任务全部源自 OpAgent 的成功 demonstration，分布天然偏向"已有 agent 能解"，且 6 个 WebArena 站点到真实商业网页（DAP 的实际战场）零迁移验证，motivation 和 evidence 之间有一条明缝。最后，"GRPO nearly doubles SR" 拿 SFT 的 6.9% 当基线而非 base 的 8.1%，且那 13.2% 靠的是 GPT-5.5 轨迹蒸馏——RL 皮，distillation 骨，长程 >9 步 9B 照样 ≤2% 全线崩溃。
- **Rating**: `2` 👀 ，问题提得新、负结果诚实，但 guide 评测撑不住招牌、站点覆盖撑不住 motivation，参考其 grounding 对比和 expert-injection 经验即可。

### Towards GUI Agents (Diffusion Grounding)
- **Title**: Towards GUI Agents: Vision-Language Diffusion Models for GUI Grounding
- **Institutes**: Arizona State University, AWS Agentic AI
- **Source**: [link](https://openaccess.thecvf.com/content/CVPR2026/html/Kumbhar_Towards_GUI_Agents_Vision-Language_Diffusion_Models_for_GUI_Grounding_CVPR_2026_paper.html)  🎓 CVPR2026   **📒 论文笔记**: [[2606-TowardsGUIAgents]]
- **核心**: 第一个系统验证 discrete diffusion VLM 能不能做 GUI grounding 的工作：把 LLaDA-V 8B 适配成 single-turn action + bbox 文本生成，核心设计是 hybrid masking——先用 linear masking 学 action type 和 anchor `(x1,y1)`，再在 anchor 条件下用 full deterministic masking 预测 box extent `(x2,y2)`，显式利用 bbox 的几何层级。zero-shot LLaDA-V 在 Mind2Web 上 SSR 为 0，7K fine-tune 后到 80.67，加 cropping + OCR annotation 到 83.31，扩到 120K multi-domain 数据后跨 benchmark 平均 SSR +17-20 points。Hybrid 相对 linear masking 在四个 benchmark 上稳定 +1.3~+6.1 SSR，Mind2Web 上 83.9 小胜 Qwen2.5-VL 7B 的 81.9。
- **锐评**: 值得肯定的是诚实——问题切得窄（single-turn grounding，不装完整 agent），zero-shot 0 分照报，latency 代价一个不藏，这在 CVPR 的 GUI 论文里算稀有品质。真正的 insight 也具体：bbox 坐标不是平坦 token 序列，anchor→extent 有依赖结构，随机 masking 几乎不会自然产生"anchor 可见、extent 被 mask"的训练情形，所以要手动造这个 phase——这条对做 grounding 输出结构化的人有直接参考价值。但硬伤同样明确：**diffusion 的核心卖点（parallel decoding）被 hybrid masking 亲手废掉了**——引入 conditional sequentiality 后 latency 冲到 5.44s，是 Qwen2.5-VL 7B（1.10s）的 5 倍；而换来的准确率除了 in-domain 的 Mind2Web，其他全线溃败：VisualWebArena 67.5 vs Qwen2.5-VL **3B** 的 88.9（连 3B 都打不过），ScreenSpot-Web-Icon 63.1 vs 85.4。也就是说这套方法在 accuracy 和 latency 两个维度上双输给 AR baseline，"Towards GUI Agents" 的标题明显透支了内容——它证明的是 feasibility，不是 viability。作者把差距归因于缺 grounding-specific pretraining，合理但未验证，而这恰恰是判断该路线有没有前途的关键实验。无代码、无 multi-step 评估，复现全靠文字描述。
- **Rating**: `2` 👀 ，一次诚实且信息量足的 feasibility probe，anchor/extent 结构化建模的洞察值得记住，但方法本身双输 AR baseline，diffusion GUI grounding 的故事还立不起来。

### Memoir
- **Title**: Dream to Recall: Imagination-Guided Experience Retrieval for Memory-Persistent Vision-and-Language Navigation
- **Institutes**: Shanghai Jiao Tong University
- **Source**: [link](https://doi.org/10.1109/tpami.2026.3679426)  🏛 TPAMI（OpenAlex）   **📒 论文笔记**: [[2603-Memoir]]
- **核心**: 面向 memory-persistent VLN（agent 在同一环境连续 episode 中越走越熟），Memoir 把 model-based RL 的 imagination 改造成检索 query：language-conditioned contrastive world model 想象未来导航状态，去 viewpoint 级双记忆库（环境观测 + 历史行为轨迹）里选择性取记忆，替代 GR-DUET 式全量记忆图注入。IR2R unseen 上 73.3 SPL，比最强 baseline GR-DUET 高 5.4 个点，tour 级 t-nDTW 高 12 个点，同时训练提速 8.3x、推理显存降 74%。判别式 world model 只做 state-observation 匹配、不做像素重构，是让 world model 在 VLN 里真正可用的务实选择。
- **锐评**: 框架是好框架，但标题卖的那个 "dream" 恰恰是全文最弱的环节——ablation 摆得很诚实：imagination-based 检索 73.46 SPL，朴素 state-based 72.85，净增益 0.61 个点；真正的收益来自"选择性检索 + 行为记忆"本身（vs 全量注入 69.98）。更扎心的是全量记忆居然输给随机检索（70.34），说明 GR-DUET 的记忆访问机制本来就是负优化，主 baseline 的软弱放大了提升幅度；换到 tour 更短的 GSA-R2R，优势立刻缩水到 +2.5 SPL，收益对 benchmark 结构的依赖暴露无遗。失败分析也自曝了本质：world model 分不清 "nearest to the desk"，两个语义相似的 bedroom 就能骗过它——所谓想象其实还是语义匹配，oracle 93.4 vs 实际 73.3 的 20 点鸿沟就是账单。加上整套系统焊死在 MP3D 离散视点图上，离真机器人还隔着一整个 sim-to-real。但必须承认：8.3x 训练加速和 74% 显存下降是结构性红利，"world model 降级用作检索 query 而非直接规划"的容错思路，比结果数字更值得偷师——这套范式搬到 GUI/web agent 的 experience memory 上几乎是现成的。
- **Rating**: `2` 👀 ，检索式记忆访问 + 行为记忆的框架和效率收益值得跟，但招牌的 imagination 只值 0.6 个 SPL，故事讲得比证据大。

### ABot-AgentOS
- **Title**: ABot-AgentOS: A General Robotic Agent OS with Lifelong Multi-modal Memory
- **Institutes**: AMAP CV Lab（Alibaba 高德）
- **Source**: [link](http://arxiv.org/abs/2607.10350v1)  📄 arXiv   **📒 论文笔记**: [[2607-ABotAgentOS]]
- **核心**: 高德给机器人造的 "Agent OS" 中间层：上层是 verification-aware 分层 harness（主 LLM 做 scene-conditioned 规划 + Skill Runner 子代理隔离执行 + runtime/skill/finish 三级验证 + edge-cloud 双 LLM routing），底层是把视频、对话、egocentric 流统一进一张 typed graph 的 lifelong multi-modal memory，外挂一个 failure-driven self-evolution loop——从失败 trace 诊断问题、生成受约束 JSON DSL 补丁、过双重 gate（target 增益 ∧ 回退容忍）后才跨 split 生效。自建 UE5 benchmark EmbodiedWorldBench 上 TSR 61.96% vs ReAct 49.97%；memory 侧 LoCoMo 87.5（超 Mem0 85.6、贴脸人类 87.9），EgoLifeQA 65.4 只用 1 帧打爆用 50 帧的 EGAgent-Gemini2.5Pro（57.5）。
- **锐评**: 名字叫 "Robotic Agent OS"，全文零真机实验——agent 能力只在自建仿真考卷上评，唯一 baseline 还是裸 ReAct，自己出题自己考且只打赢了稻草人，所谓 embodiment-generalization gap 一个字都没验证。全文真正的信息量藏在它不想让你盯着看的 Table 9：OpenEQA 8 个 split 的 self-evolution 全程提了 16+ 个候选 asset，只有 1 个存活，三个过了 candidate gate 的又被 stack 确认回滚，三个 benchmark 总增益 +0.4~1.2——这是"防 misevolution 的保守 gating 到底吃掉多少演化收益"的第一手实证：安全是安全了，但基本不长肉，比 survey 里写的 Endure/Evolve 张力尖锐得多（与 [[2509-Misevolution]] 线索直接互文）。memory 的价值边界也暴露无遗：凡 full context 塞得下的场景全面挨打（Mem-Gallery 88.6 vs full-context 92.6、NExT-QA 76.5 vs direct QA 81.9），只有 EgoLife 级时长才翻盘，而论文对这个 crossover point 避而不谈。组件清一色现成货（ReAct + subagent 隔离 + graph RAG + model routing），训练 pipeline 只讲故事不放结果，reward engine "60%→90% human alignment" 和隐私 gating ">99%" 都无从验证。要夸的也得夸到位：EgoLife 65.4@1 frame 是真硬的数字，说明 graph memory 对超长 egocentric 流的结构化压缩确实有效；把 full-context 上界和全部失败 trace 诚实摆上台面，比大多数工业报告体面。
- **Rating**: `2` 👀，gated self-evolution 协议设计 + Table 9 "演化几乎不长肉"的负面实证值得 self-evolving 线索的人一看，系统本身是工程集成而非方法创新。

### LoRA-VLA 工业微调实证
- **Title**: On the Efficiency of LoRA Fine-Tuning for Vision-Language-Action Models in Industrial Robotic Manipulation
- **Institutes**: Technische Hochschule Nürnberg Georg Simon Ohm, Siemens AG, Fraunhofer IIS
- **Source**: [link](http://arxiv.org/abs/2607.10172v1)  📄 arXiv   **📒 论文笔记**: [[2607-LoRAVLA]]
- **核心**: 在 UR5e + 4 个精密装配任务上，对 π₀（flow-matching VLA）做了一次干净的 LoRA 消融：rank 从 8 扫到 256、非对称容量分配、vision encoder 全调/LoRA/冻结三档。结论是 r=32 均匀分配 + SigLIP 全量微调即持平 Full Fine-Tuning（ATP 0.74 vs 0.76，p>0.05），静态 VRAM 从 36.2 GiB 降到 10.8 GiB，RTX 4090 可训。最有信息量的发现是 vision encoder 不能省：只挂 LoRA 掉到 0.43，冻结直接崩到 0.14——embodiment adaptation 的瓶颈在视觉 domain shift，不在语义或动作层。
- **锐评**: 这是一篇没有 novelty 但有实验纪律的论文，而后者在 VLA 圈里更稀缺——报告显著性检验、95% CI、还做了 FFT ΔW 的 SVD intrinsic rank 分析，并且诚实地把矛盾摆在台面上（intrinsic rank 高达 1400+ 但 r=32 就够，只能推测剩余谱能量是噪声）。硬伤也很实在：单平台单架构，结论对 OpenVLA 系或 discrete-token VLA 一个字都迁移不了；每任务只有 20 rollouts，"FFT 无显著优势"这个核心 claim 很可能只是统计功效不足测不出小效应，作者自己都承认；α=r 的 scaling convention 在大 rank 下会 gradient collapse，所谓 r=32 饱和可能是超参伪影，rsLoRA 一个对照都没跑就下结论。另外 10.8 GiB 只算参数 + optimizer states、不含 activation memory，"消费级 GPU 可训"的口径给自己留了后门。最可惜的是没有 per-task 拆分，bearing press-fit 和 pick & place 难度天差地别，全被 ATP 平均抹掉了。
- **Rating**: `2` 👀 ，工程参考价值扎实（"SigLIP 全调 + 其余 r=32 LoRA"的 recipe 可以直接抄），但单平台 + 低统计功效让它停留在"一个可信的数据点"而非结论。
