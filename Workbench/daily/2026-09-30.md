## 论文点评

### 一个模型管四域，联合 RL 实际只训两域
- **Title**: MintAct: A Unified Visual Agent for Digital Environments
- **Institutes**: Apple
- **Source**: [arXiv](https://arxiv.org/abs/2609.22083) 📄 arXiv **📒 论文笔记**: [[2609-MintAct.md]]
- **核心**: 用同一套 Qwen3-VL 参数覆盖 UI 定位、手机／桌面／网页导航和视觉工具调用，各域仍由专用 prompt 指定动作集。训练先做分阶段 SFT，再把各域 RL specialist 的成功轨迹蒸馏回单模型，最后仅在手机与桌面上联合 RL。异步训练的关键设计是控制真正进入优化器的有效 trajectory groups 的域配比，避免吞吐与组过滤把训练分布悄悄带偏。8B 模型在 OSWorld-Verified 得到 48.9，超过主表中的 Qwen3-VL-8B 33.9 与 EvoCUA-8B 46.1，但 AndroidWorld 和 Online-Mind2Web 都不是主表最优。
- **锐评**: 最值得抄的是在消费端控制有效样本比例，问题抓得准，比泛泛喊“统一 agent”有含金量。但 quota、backpressure 和异步校正都没有独立消融，不能把最终涨分自动记到这些设计头上。联合 RL 后桌面从 43.1 涨到 48.9，手机却从 68.1 掉到 67.0，“不损失 specialist 能力”经不起逐项核对；四域共享参数也不是四域联合在线训练。更该补的是复现说明：正文写 64 groups、两域各半，附录却列 mini-batch 48 与 25%／75%，单位和对应实验没交代；外部 baseline 是否全部同配置重跑也不清楚，表内领先还不能写成公平对照下的方法胜利。
- **Rating**: `2` 👀，多域 GUI agent 的训练配方值得精读，但核心工程设计缺独立验证，统一能力的收益与代价仍需逐域算账


### 拆掉视觉编码器，先别急着宣布胜利
- **Title**: How Far Are We from Removing the Visual Encoder? Scaling Laws for Encoder-Free Multimodal Pretraining
- **Institutes**: CASIA、UCAS、Tencent Foundation Model Department
- **Source**: [arXiv](https://arxiv.org/abs/2609.35457) 📰 HF Daily ⬆️ 54 **📒 论文笔记**: [[2609-EncoderFreeScaling.md]]
- **核心**: 在共享数据、11 档 MoE decoder 和视觉 token 粒度的设置下，对比预训练视觉编码器与直接输入像素的多模态预训练。无编码器方案的多模态 loss 随算力下降更快，也更需要把预算分给模型容量；纯文本 scaling 基本不变。但整个主要实测区间内，它达到相同多模态 loss 仍更费算力。所谓约 6.1×10²¹ FLOPs 追平，是建立在固定编码器大小、共享 loss 下界等假设上的外推，尚未真正训到交叉点验证。
- **锐评**: 值钱的是成对控制实验把“去掉编码器要付什么代价”量化了，不能把这份账单读成架构胜利宣言。正文只计 decoder FLOPs；补上视觉前端后，两者 scaling 指数从 0.378 对 0.300 收窄到约 0.378 对 0.362，“下降更快”有多少优势，明显依赖记账口径。33B 模型的下游均分仍是 51.2 对 57.7，同 loss 还需要约 1.25 倍 decoder FLOPs/token，组件更少远不等于部署更省。GUI 子集也没实测追平，更没有闭环操作成功率；attention 与专家路由的相关性只能提供机制线索，撑不起因果证明。
- **Rating**: `2` 👀，是值得读的 VLM 规模化成本研究，但追平仍靠外推，离替换现有视觉前端的实证还差关键一步


### 通用 VLM 会抓东西了，但还得靠整套脚手架
- **Title**: MotorMind: Scaffolding General Vision Language Models for Zero-Shot Robot Manipulation
- **Institutes**: University of Illinois Urbana-Champaign
- **Source**: [arXiv](https://arxiv.org/abs/2609.38078) 📄 arXiv **📒 论文笔记**: [[2609-MotorMind.md]]
- **核心**: 冻结通用 VLM，让它输出带毫米距离、旋转角度的中层动作，再由确定性 Controller 执行，配合规划、监控、核验和记忆形成闭环。系统仍依赖多视角几何、机器人状态反馈和专用控制接口；zero-shot 指不训练目标任务 policy。LIBERO-PRO 的基础／扰动成功率为 66.7%／53.8%，明显超过本文受评 zero-shot baseline 的最好结果 13.3%／19.2%。真机的 95% 来自 120 次小范围放置与人工干扰试验，另测的语义任务为 17/20，不能把两类结果混成通用操作可靠性。
- **锐评**: 把动作接口收窄、执行后核验、失败后重规划，这套工程组合确实把冻结模型的能力用出来了；去掉重规划后成功率从 66.7% 掉到 36.7%，恢复机制值得认真看。但优势并未被隔离到中层动作或异步调度上，“五角色”本身不构成方法胜利。扰动任务平均要 248.5 秒，fine-tuned π0.5 只需 6.8 秒且成功率更高；省训练不等于省成本。更刺眼的是 π0.5 的 fine-tuned／zero-shot checkpoint 说明对不上、评测配置计数也不一致，主比较的复现边界必须补清；stove 压力测试还漏判部分指令条款，这项成功率需要打折读。
- **Rating**: `2` 👀，闭环操作的工程路线值得借鉴，但速度、对照透明度与有限任务覆盖，让广泛可靠性仍停留在待证阶段
