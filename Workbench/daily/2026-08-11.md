### JEPA-WAM
- **Title**: JEPA-WAM: Learning Vision-Language-Action Policies with Joint-Embedding World Modeling
- **Institutes**: 未标注（匿名化残留）
- **Source**: [link](https://arxiv.org/abs/2608.09381)  📄 arXiv   **📒 论文笔记**: [[2608-JEPAWAM]]
- **核心**: 在 frozen V-JEPA 2.1 表示空间里做 latent world modeling：把当前帧与未来帧沿时间维 stack 后联合编码（借 tubelet=2 保持 24×24 patch grid）作为 stop-gradient 预测目标，用共享的 Qwen2.5-0.5B predictor 同时做 transition prediction 和 flow-matching action 生成，推理时整条 prediction 分支直接扔掉、零开销。0.5B、无 robot-policy pretraining 在 LIBERO-Plus 拿 79.2%（该组别最好）；同一监督作为辅助 loss 嫁接到 π0.5，从 84.5% 提到 86.3%。真机双臂 5 任务上 π0.5+JEPA OOD 84.7% vs 72.5%。
- **锐评**: 这篇的好在于克制：核心贡献就是"预测目标怎么选"一件事——joint current–future target 保留 patch 级对应，而不是压成几个 global latent 或复用视频生成器的中间特征——然后用 Table 4 把每个选择都对照掉了（joint 79.2 vs future-only 77.3、破坏 patch 对应掉到 74.7、把预测表示直接喂 action expert 暴跌到 73.1）。Full-hidden 掉 6.1 个点这一条是全文最有信息量的数字，直接否定了"把预测的未来喂给 policy"这条流行路线。π0.5 transfer 里 action tokens 被 mask 不能 attend future tokens 的隔离设计也干净——增益只能来自 backbone 被监督塑造，机制归因没有含糊。但别被平均分骗了：79.2 的领先几乎全靠 Camera 扰动列撑起来，Language 扰动只有 68.2，被 ResVLA（88.5）和 RoVLA（92.9）按在地上打——0.5B LM 加 language-agnostic 的 target，这个短板是结构性的，作者自己在 Limitations 里也认了。更扎心的是 RoboTwin Random：Clean 上 +9.2 个点的辅助监督，到强 domain randomization 下只有 37.2→37.5，等于没用——说明这套 transition 监督买到的是 camera/viewpoint 鲁棒性，不是 appearance 鲁棒性，宣传时别混为一谈。工程边界也得点名：code "Coming soon"、affiliation 是匿名化残留的占位符、基线全是 2026 同期工作且训练设置可比性未核对、δ 逐 benchmark 手调（31/50）不报敏感性、真机每任务 10 rollouts。方法是真的好，但目前每个数字都只能信论文自己的口径。
- **Rating**: `3` 🔥 ，问题选得准（预测目标的结构 + 监督怎么进 backbone）、方法简洁到部署零开销、ablation 逐项可归因，是 latent WAM 这条线上少见的干净工作——尽管 language 短板和不可复现状态意味着结论要等 code 和正式版再落锤。

### World Tokens
- **Title**: World Tokens: Enhancing Embodied Policies with Training-Time World Modeling
- **Institutes**: JIUTIAN Research, Zhongguancun Academy
- **Source**: [link](https://arxiv.org/abs/2608.09730)  📄 arXiv   **📒 论文笔记**: [[2608-WorldTokens]]
- **核心**: 把 VLM 特征经 Perceiver 式 World Adapter 压成 256 个 world tokens，训练时同时充当 future-video denoiser 的条件和 action expert 的**唯一** visual-language 入口——排他路由逼着 world modeling 监督写进 policy 真正消费的表征，部署时整个 video 分支直接扔掉。结果：2B backbone、无 embodied pretraining，SIMPLER 表内最优（WidowX 71.5 / GoogleRobot 82.1），LIBERO 平均 98.2，真机 59.4%→76.0%，推理 61.85 ms/chunk 仅为 π0.5 的 1.1×。
- **锐评**: 这篇的价值不在数字在机制。"加个辅助 video loss" 是烂大街的做法，本文真正的贡献是回答了它为什么经常不 work：只要 action expert 还能绕开被监督的表征直接吃 VLM 特征，video 目标就跟 action 目标打架而非塑造它——VLM bypass ablation（94.1 vs full 97.0）把这句话钉死了。更妙的是 Canny 首帧那个负结果：RGB anchor 让 denoiser 走外观捷径，成绩（91.5）掉到比完全不做 world modeling（95.0）还低，"辅助任务设计不当是净伤害"这一条比主表任何数字都有信息量。但账也要算清楚：其一，"best reported on SIMPLER" 只相对自家对比表内 baseline 成立，且 SIMPLER 上压根没跟保留 video 分支的 WAM 方法对比——"训练期蒸馏 world modeling 是否牺牲了推理期 world model 的上限"这个最该回答的问题被绕开了；其二，LIBERO 上它并非最优（Cosmos Policy 98.5、DiT4DiT 98.6 都更高），延迟-性能 Pareto 论证还混了跨硬件数字，不算干净；其三，WidowX stacking 只有 32.0%，接触密集任务上 world tokens 明显没帮上忙，真机又只测了 4 个同构抓放、单平台 96 trials；其四，无代码发布，K=256、λ_w=5 全无 sweep，Canny anchor 是作者自认的 hand-design。方法本身是"简洁、可移除、机制可检验"的好品味，但 claim 的包装比证据大了一号。
- **Rating**: `3` 🔥 ，排他路由 + 反捷径 anchor 给"world model 当训练信号为何 work / 何时 break"提供了罕见的可检验机制解释，ablation 链完整，值得精读——尽管 SOTA 表述注水、无代码。

### HyMeS
- **Title**: Skills in Weights, Memory in Code: Hybrid Learning for Memory-Dependent Robot Manipulation
- **Institutes**: Northwestern University, University of Minnesota, Stanford University
- **Source**: [link](https://arxiv.org/abs/2608.09410)  📄 arXiv   **📒 论文笔记**: [[2608-HyMeS]]
- **核心**: 论点是 memory 逻辑是离散组合式的，塞进 weight space 学是错配——于是把 motor skill 留给 flow-matching fine-tune 的 π0.5（此后冻结），memory 策略交给 coding agent（Opus 4.8）在 code space 用 rollout trace + stage verdicts 迭代改程序（无梯度、无 expert label）。推理时 symbolic memory 选出 stage constraint，梯度注入冻结 VLA 的 velocity field 做 steering，PACE（proprio OR VLM 多帧、k-of-w 投票）验证 stage 完成后回写 memory，形成双向闭环。RoboMemArena 12-task 上同权重下 CSR 52.5→66.2、TSR 41.3→60.1，超 PrediMem 4.5/14.5 点；SO-101 真机 TSR 25.7→57.1。
- **锐评**: 好的部分很硬：demonstration 预算随可复用 motor skill 数扩展而非随 history 配置组合数爆炸，这是对端到端 memory-augmented VLA 的结构性一击，不是又一个 memory token 变体；相对 VLS 一系 reactive steering 的实质增量是 memory 条件化 + verified 回读的双向闭环，occlusion 类是最有信息量的数字——PrediMem 的 memory 反把 π0.5 拖下水（CSR 38.3 vs 50.4），HyMeS 不掉点，"unreliable memory 有害、verified transition 兜底"有了直接证据；P^(0)→P* 的 +18.4 TSR 也证明 heuristic learning 不是装饰。但主对比的 evidence boundary 必须点破：12-task protocol 是作者从 RoboMemArena 自行修正筛选的口径，PrediMem 是作者复评而非其发表的 26-task 结果，且"保留 π0.5 有技能却因缺 history 失败的任务"这一筛选标准天然圈定了 memory 注入最容易得分的地盘——赢 4.5 点 CSR 在这个口径下不算压倒性。counting 类 CSR 输 PrediMem 12 点（60.3 vs 72.2）暴露 steering 不是免费午餐，guidance 会干扰早期 motor 执行。更隐蔽的假设是 heuristic learning 开发阶段吃 benchmark 的 stage-wise ground-truth verdicts，仿真里免费、真实场景哪来？真机部分对此语焉不详。VLM 周期 query + coding agent 的推理成本一个数字都没给，每任务 10–20 episodes 的样本量也撑不起单任务结论。机制本身是 Eureka/Voyager 一脉的 LLM 程序迭代，novelty 在接进 denoising 内部而非编排层。
- **Rating**: `3` 🔥 ，问题拆分干净、occlusion 反例与 ablation 都打在点上，是"冻结 VLA + 可执行 memory"谱系里目前耦合最深的一点——尽管主对比建在作者自建口径上，方法论价值已经立住。

### WorldSimProbe
- **Title**: WorldSimProbe: Diagnosing Simulator Faithfulness in Action-Conditioned World Models for Embodied Manipulation
- **Institutes**: Peking University、EvoPhys AI、JD Joy Future Academy、University of Sydney、HKUST、Beijing Institute of Technology
- **Source**: [link](https://arxiv.org/abs/2608.09298)  📄 arXiv   **📒 论文笔记**: [[2608-WorldSimProbe]]
- **核心**: 把 "world model 能不能当 simulator" 从审美问题改写成契约核查：supplied action 必须诱导对应 agent motion（action-realization），environment response 必须被 realized motion 物理支持（interaction-response）。据此造了五个 controlled probe suite、18,608 个实例（RoboTwin/ManiSkill/LIBERO），每个 intervention 都有 simulator 里真实执行过的 counterfactual reference，对 6 个开源 ACWM 做诊断。结论不留情面：action 响应普遍衰减（LingBot-VA 的 failure threshold 是 simulator 的 7.48 倍，Cosmos-3-Nano 高达 35.6 倍）、contact hallucination 是 grounding 失败的主形态、interaction primitive 上 shake 六模型几乎全灭（0.0–1.2）。顺手还证明了 VLM rollout judge 在 OOD controls 上判 91.7% positive 而人类只判 42.2%。
- **锐评**: 这是 benchmark 论文该有的样子——不是又堆一个 aggregate score，而是先写清楚被测对象的定义性义务（契约两条件），再逐环节造可干预、有 simulator ground truth 的探针，失败能定位到环节。最狠的两刀都砍在同行身上：一刀是 T3 的 early/late policy checkpoint 设计，证明即便是 task-directed 轨迹，执行风格不熟就退化 10.8–16.1 分——所谓 "action-conditioned" 很大程度是 scene-conditioned motion prior 的复读；另一刀是 evaluator validity 那节，750 条人工标注直接给所有拿 VLM/IDM 评 action-following 的 benchmark 判了缓刑（IDM 误差被证明是 inverse-model decoding failure 而非 fidelity 信号，这个归因做得干净）。shake 0.0–1.2、false contact 38.6 这类跨模型共享的结构性坑，比排名本身值钱。但 evidence boundary 必须点破：ρ=−0.433 的 mismatch-degradation 曲线和 late/early 分析都只在 RoboTwin 上报告，跨平台是否成立是外推；downstream 验证只有单个 RoboTwin task，作者自己都只敢叫 controlled case study，"benchmark 排序预测下游效用" 这句话目前撑不起普适 claim；摘要说 code and data available，附录里其实是将来时承诺，复现性暂记账上。另外每个模型都在各平台 in-domain fine-tune 过——这是对 ACWM 最友好的设定下测出的惨状，通用 pretrain 模型 zero-shot 只会更难看，可惜没测。
- **Rating**: `3` 🔥 ，契约式 formulation + simulator-grounded counterfactual + evaluator 自证有效性三件套齐全，且 VLM-judge 偏乐观的发现对整个评测生态有外溢价值；扣分项（单平台机制分析、单 task downstream）是范围问题不是方法硬伤。

### WorldTrace
- **Title**: Addressable Memory for Video World Models
- **Institutes**: NVIDIA, Princeton University, University of Toronto, Vector Institute
- **Source**: [link](https://arxiv.org/abs/2608.07408)  📰 HF Daily ⬆️ 7   **📒 论文笔记**: [[2608-WorldTrace]]
- **核心**: 把 video world model 长时程 visual persistence 崩坏的根因从"存不下"重构为"存了读不出"：rollout 超出训练 horizon 后 temporal RoPE 的 query-key offset 越界，快频分量相位随机化，KV cache 里的记忆变得不可寻址；naive 在已旋转空间平均压缩还会因 phase cancellation 二次损坏内容。解法是 training-free 的两件套——给 summary slot 按 rank 分配固定 in-distribution virtual position，key 在 canonical（未旋转）空间压缩、读取时单次旋转到位。两个写入器分工：Field 连续时间组平均保 coherence（N=48 TempSSIM 相对 +15.5%），Landmark 冻结 scene-entry 帧 verbatim 保 recall（自建 LoopBench ABA +19.5%，N=256 仍守住 0.989）。
- **锐评**: 这篇的价值在诊断不在方法——"记忆在 cache 里但 attention 读不到"这个 addressability 视角配上逐频率的相位分析（训练 offset 上限 5 时 f≥10 分量是语义载体，offset=30 时最快三个分量相位已绕 3π）是真正的第一性原理工作，Table 1 把 position 轴单独隔离出 +5.9%~+13.8% 的干净 ablation，"MemRoPE 换上更好的 position 反而变差"这个负结果比大多数正结果有信息量：position 和 content 写入必须在同一 offset 分布下共同设计。但评测侧硬伤不小：LoopBench 是自建自测，PAC 用 CLIP 相似度对照模型自己 first-visit 生成的帧打分——自己出题自己改卷，对"几何一致但外观漂移"是否敏感成疑；更难看的是同一 ABA 配置的绝对 PAC 在不同表格间大幅漂移（sliding window 在 Table 3/4/8 分别为 0.723/0.540/0.837）且论文不解释口径，headline 的 +19.5% 和 0.989 来自不同协议、不可混用。主结果压在单一 1.3B 蒸馏游戏模型上，14B LingBot 验证只在附录且 Field 在其上基本失效；Field 对 recall 几乎不帮忙（PAC 约 0.4-0.6）、Landmark 靠 cosine-spike 阈值 τ 加 FIFO 逐出这种启发式，说明"该记住什么"仍靠手工选 writer，NMF 统一视角目前只是留了接口。
- **Rating**: `3` 🔥 ，addressability 诊断 + position/content 必须联合设计的负结果是可迁移到所有 RoPE 长上下文生成的机制级洞察，评测口径混乱和自建 benchmark 扣分但盖不住诊断的成色。

### StreamArena
- **Title**: StreamArena: Toward Continuous, Interactive, and Long-Horizon Agentic Streaming Video Understanding
- **Institutes**: The Hong Kong University of Science and Technology, Xiaohongshu Inc., The University of Hong Kong, The Chinese University of Hong Kong
- **Source**: [link](https://arxiv.org/abs/2608.05703)  📰 HF Daily ⬆️ 15   **📒 论文笔记**: [[2608-StreamArena]]
- **核心**: 小时级 audio-visual 流的 open-ended benchmark：243 个平均 88.8 分钟的完整视频、3,646 个双时间戳人工验证 QA，联合评测 real-time perception、historical retrospection、tool use、proactive interaction 四种能力，动机直指"短片段 + 多选题可被只看最后 4 帧的 baseline 打平"这一失效模式（该诊断引自 Shen et al. 2026，本文未自证）。配套的 StreamMind 用 frontend 交互 worker + backend 异步记忆构建（层级事件 + 实体图 + key frames）的两层架构，在 streaming 系统里四项全第一，并在同 backbone 对照下把 pooled latency 降 66.2%、保留 89.7% accuracy。
- **锐评**: benchmark 一侧是真功夫：open-ended 生成封掉选项先验，query/evidence 双时间戳把 evidence-to-query gap 变成可分层的实验变量，ASR-only 只拿 30.5%（RTP 上 4.2%）证明字幕捷径确实被堵死；Appendix C.1 把"所有号称 streaming 的 baseline 其实都在 query-triggered replay 下评测、跨题不保留状态"这件事挑明，是给整个领域做了一次 harness 审计，比排行榜本身值钱。系统一侧就要泼冷水了：StreamMind 挂着 Qwen3.5-397B MoE，baseline 全是 3B–8B，"四项第一、提升 53.7%–228.1%"是容量 + harness 双重混杂下的数字——作者自己都声明不把增益全归因架构，转述时就别再吹了。Tool +228.1% 是 17.1→56.1 的低基数魔术，且 accuracy 不验证工具是否真被调用；Pro 11.6 vs 人类 91.5，proactive 实质上还是没解决的问题。再叠加 78% 中文音轨 + Gemini 3.1 Pro 单 judge 二值判分、全部数字单次 run 无方差，结论的有效域比表面窄不少。最诚实也最有价值的发现反而是失败面：HR 从 L2 到 L4 崩 63.4%，作者论证这不是容量问题而是"未来 query 未知时的 retention 决策"问题——这才是留给后人的真正机制题，而 StreamMind 本身只是无可学习组件的工程编排，没碰它。另外声称 Apache-2.0 放代码，但目前抓不到可解析的 repo URL，复现暂时只能听故事。
- **Rating**: `3` 🔥 ，benchmark 设计 + harness 审计对 streaming 评测领域是结构性贡献，值得读；但 StreamMind 的"四项第一"要打上容量混杂的折扣读。

### ZO-SelfEvolve
- **Title**: Beyond the Capability Boundary: Zeroth-Order Optimization for Self-Evolving LLM Agents
- **Institutes**: Beijing Institute of Technology, Shenzhen MSU-BIT University, Alaya Lab
- **Source**: [link](https://arxiv.org/abs/2608.09292)  📄 arXiv   **📒 论文笔记**: [[2608-ZerothOrderSelfEvolve]]
- **核心**: 直击 self-evolving agent 的死穴——难例上 agent 采不出正确 trajectory，rejection sampling 没料可筛，RL 在全失败时 reward 同为常数、梯度精确归零（论文给了推导）。解法是换信号来源：给每个难例挂 instance-specific LoRA，加 Gaussian 扰动跑 rollout，用 answer perplexity loss（gold answer tokens 上的连续 NLL）的差分做零阶梯度估计，在参数空间随机搜索出成功 trajectory，再入 buffer 做 SFT 闭环。配套 parallel perturbation（共享 backbone 计算，单例推理 656s→305s）和 tool-call 缓存压成本。GAIA 上 Qwen-3-8B 达 47.5%，controlled 同配置下碾压 ReAct（23.3%）和 ARPO（38.8%）。
- **锐评**: 这是少见的把范式失效机制说清楚再动手的工作：ĝ_RL=0 的推导 + Table 6 的 23/50 vs RL 16/50 vs first-order 7/50，证据链和 claim 是对得上的；answer perplexity loss 的 ablation（BERT/LLM-Judge loss 在难例上根本不收敛）也说明这个连续 surrogate 是真使能件而非装饰。但三处不能放过：**其一**，"requires no annotated trajectories"是文字游戏——不需要 trajectory 标注，但每一步都离不开 gold answer y，方法天然锁死在有参考答案的 QA 型任务上，对环境 reward 驱动、无 gold answer 的 GUI/computer-use 场景直接失灵；**其二**，perplexity 信号有明显的捷径漏洞：检索到含答案字符串的页面就能压低 loss，buffer 又接纳"loss 够低但答案错误"的 trajectory，false positive 监督污染训练集的风险论文没做任何检查；**其三**，每个难例 30 轮 × K 次 rollout，优化后仍约 305s/轮，per-instance 成本决定了这套东西在万级训练集上不可行，论文对 scaling 只字未提。另外 Table 1 里 WebDancer（31.0%）、SimpleDeepSearcher（36.9%）是 paper-reported 跨 backbone（Qwen-2.5-7B vs Qwen-3-8B）的数字，拿来撑"SOTA"叙事水分不小，真正干净的对比只有 ReAct 和 ARPO。还有一个作者没答的问题：instance-specific LoRA 发现的能力全靠 SFT 蒸馏回主模型，蒸馏损失多大不知道——Table 2 的 28.3% vs 20.4% 只证明难例 trajectory 有训练价值，没证明蒸馏无损。
- **Rating**: `3` 🔥 ，机制诊断（难例梯度归零）和信号来源替换（参数空间 ZO 搜索）是 self-evolving 路线上真正的范式级贡献，gold answer 依赖和 per-instance 成本是清晰但不致命的边界。

### SimWAM
- **Title**: SimWAM: A Simple World Action Model for End-to-End Autonomous Driving
- **Institutes**: Huazhong University of Science & Technology、Dongfeng Research & Development Institute
- **Source**: [link](https://arxiv.org/abs/2608.07468)  📰 HF Daily ⬆️ 22   **📒 论文笔记**: [[2608-SimWAM]]
- **核心**: 把 video generation 从推理路径整个砍掉、只当训练信号：Wan2.2-5B 初始化的 video expert 与轻量 action DiT 做 joint flow matching co-training，isolated attention mask 让未来帧 token 和 action token 都只看当前观测、互不可见，训练完直接丢掉 video 分支，推理只跑一个自含 planner。再叠一层 Flow-GRPO 式 RL（G=8、只动 rank-32 LoRA）优化 NAVSIM PDM reward。单前视相机在 navtest 拿 91.5 PDMS，超过 imagine-then-act 的 DriveWAM（90.1）/DriveLaW（89.1），A100 上 10 步采样 518 ms，零样本迁移 nuScenes（L2 0.96 m、collision 0.04%）。
- **锐评**: 这篇的价值不在 91.5 这个数，而在 Table 3 那三个几乎一样的数：isolated 90.3 ≈ bidirectional 90.2 ≈ action→video 90.1——让 action 显式 attend 未来帧一分不涨，等于宣判 imagine-then-act 路线推理时那套"想象"是白烧的算力，video 先验的全部收益经由共享观测表征就能传完。这是对整个 WAM 家族的结构性打脸，比又刷一个 SOTA 值钱得多；Table 2 的归因也干净（action-only 86.6 → +video 90.3 → +RL 91.5），主要收益明明白白来自 co-training。但毛病同样具体：其一，"substantially lower latency" 只有 Figure 1 一张散点图撑腰，全文没给任何基线的数值延迟，而自己的 518 ms 对实车部署本身就不体面，5 步 297 ms 的质量代价还语焉不详——延迟是你的核心卖点，却是全文证据最虚的地方；其二，RL 直接优化 PDM reward、评测又是 PDMS，+1.2 里多少是开车变好、多少是拟合 metric 族没有独立指标交叉验证，零样本 nuScenes 上 L2 0.96 m 输给 DriveVA 的 0.84 m 已经露出不一致的马脚；其三，mask ablation 0.2 的差距大概率就是噪声，正确的叙事是"零代价换可丢弃性"，论文却没把这层说透。另外全部结论建立在单前视 + NAVSIM 闭式评测上，多相机、真闭环下是否保持是开放问题。本质上这是把 video prediction 降格为 representation learning 的辅助任务——想通这一点，"mask 拓扑不影响精度"就毫不神秘了。
- **Rating**: `2` 👀 ，驾驶域偏离主线，但"推理时想象不必要"这个结构性结论若在 manipulation WAM 上复现（对照 vault 里走自适应生成的 AdaWAM），整个 imagine-then-act 路线的开销论证都要重写——值得盯后续。
