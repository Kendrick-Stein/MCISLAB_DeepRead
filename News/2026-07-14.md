### NVIDIA Nemotron 开放 agent 训练数据（Data for Agents）
- **source**: [HuggingFace Blog](https://huggingface.co/blog/nvidia/open-data-for-agents)
- **what**: NVIDIA 把 Nemotron 系的开放数据栈打包亮相：Nemotron-CC v2（增强 Common Crawl 预训练语料）、Nemotron-CC-Math v1（190M 合成数学）、Nemotron-Personas（10 国、按真实人口统计构建的合成 persona）、Privasis-USA（医疗/金融/法律合成隐私记录）、Post-Training v3 Prompt Atlas（百万级 post-training 样本的交互式可视化），合计超 10T 预训练 token。构建主打合成数据：混合真实工作流、人类反馈、模型轨迹与模拟用户，明确面向 agentic 训练——tool calling、多步推理、**failure recovery 与异常处理**。
- **so-what**: 与我们跟的 web agent 训练基建线索直接相关（参见 [[2026-07-08-WebAgentTrainingInfra-Pulse]]）：工业界正在把"agent 训练数据"当成独立资产开源，且明确提出 agent 工作流数据的质量标准是"任务多样性 + 失败覆盖"——这与 WebSynthesis/AgentSynth 一路的合成轨迹思路互相印证。caveat：博客零 benchmark 数字，数据对下游 agent 能力的实际增益未验证，属于"值得盯 dataset card，不值得引为证据"。
- **action**: 关联 [[2026-07-08-WebAgentTrainingInfra-Pulse]]；后续若出配套 tech report 再入队 digest

### UST × Anthropic："physical AI" 的实际含义
- **source**: [Anthropic News](https://www.anthropic.com/news/ust-claude)
- **what**: UST 与 Anthropic 签为全球首级合作伙伴，2 万工程师接入 Claude；标志性场景是芯片设计验证平台 iDEC 用 Claude Code 读原理图/引脚配置、自动生成并运行回归测试、对比实时设备数据与数字孪生找固件问题，验证周期从 4 天缩到 48 小时。
- **so-what**: 注意这里的 "physical AI" 是营销语义——指嵌入设备工程流程的 AI（芯片/汽车/设备验证），**不是** embodied robotics，与我们的 Embodied AI 方向无直接关联。真正的数据点是：coding agent（Claude Code）作为通用执行器被嫁接进 EDA/固件验证这类高度结构化的专业工作流，且给出了 50-70% 的周期压缩数字——agent 落地的高价值场景可能长在"有 verifier 的专业工作流"里，而非开放网页。公关稿成分高，数字无独立验证。
